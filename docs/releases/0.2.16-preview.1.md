# irori 0.2.16 preview 1 — skills with a long description load

- A skill's `description` may be up to 1024 characters, the Agent Skills
  limit, instead of 400. Skills written for another CLI with a 541–625
  character description were left out of the list in 0.2.15.
- A description longer than 1024 characters no longer leaves the skill out.
  irori cuts it to 1024 characters for the picker and for the agent, as Codex
  does, keeps the instructions whole, and marks the skill 要確認 in Schema
  settings with the length it found. The skill form edits the whole
  description and saves up to 1024 characters.
- A skill that cannot be read is named under the composer with the reason,
  such as `description: Invalid input: expected string, received undefined`,
  instead of only its folder.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `tests/skills.test.ts`
covers a 625- and a 1024-character description, characters outside the BMP
counted once, a longer description cut with the instructions kept, a skill
with one listed beside the others, and failure messages that read as
`key: reason` rather than Zod's JSON. Not tried with the mtd vault's own skills.
