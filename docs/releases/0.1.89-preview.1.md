# irori 0.1.89 preview 1 — A terminal in irori mode, and home from anywhere

**ターミナル** in the bottom bar now works in irori mode. It used to start a
shell in the last hibachi, out of sight behind irori mode. irori mode (and
the routines and irori agent screens) now has its own terminal: a drawer
under the screen that starts in the irori agent's folder. It keeps running,
hidden, while a hibachi is on show, and is there again on return. In a
hibachi the button still opens that hibachi's terminal. Ctrl+` follows the
same rule.

The home button (choose a workspace) can be pressed from anywhere. An unsaved
note is saved first. If agents are running or a terminal is open, irori asks
before it stops them and goes home; cancelling leaves everything running.

## Verification

`npm run build`, `npm test` and the Electron UI suites pass. The terminal
smoke opens irori mode's terminal from the bottom bar, writes a Japanese file
into the irori agent's folder through the keyboard, visits a hibachi and
returns to the same running shell, then goes home from irori mode through the
confirmation. The overview smoke cancels going home while agents run. A host
test checks the shell starts in the irori agent's folder and refuses it
before the folder exists. Not tried with Windows or macOS.
