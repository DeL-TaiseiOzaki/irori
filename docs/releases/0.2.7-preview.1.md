# irori 0.2.7 preview 1 — files of any size

Files dragged in from the file manager, or chosen with **Add file…**, now come
into a vault whatever their size. Until now irori refused files over 100 MiB
and asked for them to be copied in another way.

- A large file is copied piece by piece, and the status bar shows how far the
  copy has come.
- If a copy fails, the partial file is removed. Closing irori during a copy
  leaves a short file behind.
- irori still shows PDF, Office and image files up to 100 MiB itself; a larger
  one opens in its own application.
- Up to 2,000 files can still be brought in at once.

## Verification

`npm run build`, `npm run format:check` and `npm test` pass.
`explorer-ui-smoke` drops a 120 MiB file onto a connected folder in the real
Electron app and compares every byte of the copy.

Not tried on Windows or macOS, or with a drop from a real file manager.
