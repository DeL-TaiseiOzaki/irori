# irori 0.1.57 — routines

A routine is a job you define once and start with a button: it runs programs
and instructs agents, in order. It is how irori gathers what you keep in other
tools, such as mail and chat, into your hibachis, and how any other job you
repeat can be written down.

## Routines

- **A routine is a folder** with `routine.yaml` and the files its steps use:
  in the irori agent's folder (`routines/<name>/`) for jobs that span
  hibachis, or in a hibachi (`.irori/routines/<name>/`) to travel with it.
  Each step either runs a program or instructs an agent:

  ```yaml
  name: Mail triage
  steps:
    - run: fetch.js
    - agent: irori
      hibachis: all
      access: full-access
      prompt: |
        Put each mail in $IRORI_WORK/inbox into the hibachi it concerns.
  ```

- **irori mode → ルーティン** lists the irori agent's routines and your
  hibachis', with the agent panel beside them. **実行** starts one and **停止**
  stops it; nothing starts a routine by itself, and nothing runs while irori is
  closed.
- **You review a routine before it first runs on your device**, and again
  after anything in its folder changes: the first time every file is shown,
  later the lines that changed. A routine an agent wrote or a pull brought in
  waits for your review the same way.
- **Programs:** `.js` files run with irori itself as Node after you add
  **JavaScript** (in the routine's row or the settings; nothing is downloaded).
  Other programs and commands come from your `PATH`. A step that prints
  `{"continue": false}` last ends the run with nothing to do, before any agent
  is asked.
- **Agents:** an agent step is an ordinary run of that hibachi's agent, or of
  the irori agent with the hibachis handed to it, shown in its conversation.
  Its permission requests and questions also appear in the routine's step. It
  starts a new session each time and leaves your own conversation with that
  agent where it was. A report that begins with `[FAILED]` fails the step.
- **Each run is recorded on your device:** every step's result and output, the
  agent step's conversation, and the files each hibachi's Git status shows
  changed. A run cut short by quitting or a crash shows as **不明** and is not
  run again.

Secrets for programs, Python and a skill that teaches the irori agent to write
routines come next.

## Installing

**Windows 11 x64:** download `irori-0.1.57-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.57-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.
