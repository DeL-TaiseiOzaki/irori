# irori 0.2.72 preview 1 — Shipped code no longer names irori-templete

- irori behaves exactly as in 0.2.71. Only source comments change.
- Comments in the shipped code that described irori-templete — that it states
  the folder index rule, its layout and one of its decisions — now cite irori's
