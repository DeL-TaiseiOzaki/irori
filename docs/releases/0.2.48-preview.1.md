# irori 0.2.48 preview 1 — the explorer follows the open file

- The Knowledge and Contents lists follow the file open on the page. However
  it was opened (a path in an agent's reply, a note's link, search, a tab or
  the backlinks), the folders above it open, a folded section unfolds and its
  row comes into view, selected.
- This happens once each time another file comes up: a folder closed
  afterwards stays closed while the same file stays open. Focus stays on the
  page.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `links-ui-smoke` now
follows a note's link into a closed folder below 40 notes and checks that the
folder opens and the file's row is selected and in view, then closes the
folder and folds the Knowledge section, follows the link back up and checks
that the section unfolds on the new file while the closed folder stays closed.
Without the change the first of these checks fails. `explorer-ui-smoke` no
longer opens a renamed folder by hand: the file on the page is inside it, so
the explorer opens it again and selects the file.
