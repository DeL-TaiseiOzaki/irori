# irori 0.1.96 preview 1 — Attachments, dictation and clearer questions

The chat with the irori agent and the hibachi agents takes files and your voice,
and shows an agent's questions as choices. Decided in ADR 032.

- **Attach files.** Use the paperclip, drop files on the message box or paste
  an image. Claude Code, Codex, OpenCode and Pi see images as pictures; every
  CLI is told where each file is. Files can be sent without any words.
  Up to 10 files of 25 MB each per message.
- **Speak instead of typing.** The microphone starts macOS 音声入力 or Windows
  voice typing in the message box. irori records nothing itself.
- **Questions as choices.** Each option shows what it means, with the question's
  header. Several choices show as checkboxes, and 「その他」 takes your own
  answer. A single choice is answered by picking it. Requests from MCP servers
  are now shown too, through Claude Code or Codex.

Sent files show in the conversation as thumbnails or names. They are kept on
this device and deleted with their conversation.

## Verification

`npm run build`, `npm test` and the Electron UI suites pass.

- Protocol fixtures check that Codex gets `localImage` and Claude Code gets an
  image block and the file's folder. They also check that questions keep their
  headers, descriptions and previews, and that a Codex MCP form is answered with
  typed content.
- Attachment storage tests cover safe names, the size limit, discarding, pruning
  and deletion with the conversation.
- The harness smoke picks a file and pastes an image, sends them without words,
  and checks Pi receives the image. It also answers an OpenCode question with
  checkboxes.

Not tried with a real CLI, macOS dictation or Windows voice typing.
