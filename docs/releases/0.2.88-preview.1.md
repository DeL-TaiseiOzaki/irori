# irori 0.2.88 preview 1 — The session board

- A new column left of the agents' columns lists the workspace's conversations
  as small cards, in the lanes 要対応, 実行中, 完了 and 開いている, however many
  run. Each card names the conversation, its vault or the irori agent, what was
  asked and what the agent is doing now; a click shows it in a column
  ([ADR 069](../decisions/069-session-board.md)).
- Work a conversation handed on shows under its card: a hand-off to a vault
  agent with a solid frame, and a CLI's own sub-agent (Claude Code, Codex,
  OpenCode, Pi's extension, Hermes Agent) with a dashed one, both in the
  sub-session colour.
- The board is on by default. 表示 → 画面に出すもの → **セッションボード** takes it
  off the window.

## Verification

`npm run build` passes. On a Linux machine under Xvfb, `npm test` and
`npm run test:ui` pass except where `main` fails the same way there: the system
trash in `explorer-ui-smoke` and SSH key permissions in `ssh-config` and one
`remote-hosts` test. A
new smoke, `scripts/session-board-ui-smoke.ts`, runs Pi protocol fixtures side
by side and checks each lane, a sub-agent's card and its frame, opening a
conversation from its card and the setting. No real CLI was run, so the
sub-agent tools of Claude Code, Codex, OpenCode and Hermes Agent are recognised
from their recorded protocol, not from a live run. Not tried on macOS or Windows.
