# irori 0.2.22 preview 1 — less room at a note's sides

- Settings has 左右の余白 (Side margins). Standard keeps the reading column as
  before; Small widens it to 1000px; Minimal fills the stage, leaving room only
  for the editor's block handle. The page's properties widen with the body.
- The choice is kept on the device and travels with the environment saved to
  GitHub.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `tests/settings.test.ts`
covers the default for a record without the choice, a choice kept across other
writes and a restart, and the values a renderer may store.
`scripts/properties-ui-smoke.ts` chooses Minimal and Standard in Settings and
measures the page's width and the properties' alignment with the body. Not
tried on macOS or Windows.
