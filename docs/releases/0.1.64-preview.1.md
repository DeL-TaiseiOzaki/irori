# irori 0.1.64 — choose the language on the startup screen

- The startup screen offers the other interface language in its footer, named
  in that language: **English** while irori shows Japanese, **日本語** while it
  shows English. Until now the language could only be changed from the rail's
  settings, which appear after a workspace is open, so a first launch could
  only be read in Japanese.
- The choice is the same device setting as the one in **設定 / Settings** and
  applies at once. The suggested workspace name follows it until it is edited.

See [ADR 011](../decisions/011-interface-language.md).

## Verification

The Electron language suite now switches to English on the startup screen,
checks that no Japanese interface text is left there (the 日本語 button is
marked as Japanese and expected), switches back, and then runs the existing
in-workspace checks.

Installed Windows and macOS builds were not tested. No preview is published
until this branch is merged and the native release jobs succeed.
