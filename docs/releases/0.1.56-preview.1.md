# irori 0.1.56 — labels and values

0.1.55 removed most of irori's helper paragraphs. This release goes further:
what stays on screen is labels and values, errors are one short sentence, and
a confirmation before a destructive action keeps one clause about the result.

## What changed

- **The hibachi agent composer** no longer shows a line describing the access
  setting.
- **会話と接続** shows the CLI and its version, and a reset button when there is
  a conversation to reset. The CLI's description, the untested-version note and
  the conversation-state sentence are gone; an error still shows when the CLI
  cannot be found.
- **新しい会話** is a toggle button; the sentence and undo button below it are
  gone.
- **Errors** from Git, GitHub, Google Drive, updates, notes and the terminal
  say what failed and drop the "check … then try again" tail. The GitHub CLI
  keeps its one next step (`gh auth login`, `gh auth status`).
- **Tooltips** that repeated a visible label are gone. Icon-only buttons keep
  their name.
- **Buttons, headings, labels and placeholders** are shorter. For example,
  **Push を実行** → **Push**, **会話の継続をリセット** → **会話をリセット**,
  **グラフ（オントロジー）** → **グラフ**, **ノートの名前と場所** → **名前と場所**,
  **Google アカウントを追加** → **アカウントを追加**, and **指示（Markdown）**
  → a label that screen readers still hear. The empty stage's welcome heading
  is gone.
- **Duplicates** are gone: the save state shown twice, a connection's access
  shown in its state and again beside it, and a Drive upload error repeating the
  pending count shown next to it.
- **送信待ち** is now the one name for changes waiting to reach Google Drive
  (it was also called 送信準備).

Behaviour is unchanged.

## Installing

**Windows 11 x64:** download `irori-0.1.56-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.56-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.
