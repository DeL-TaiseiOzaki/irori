# irori 0.1.52 — faster Google Drive files

Opening a file in a connected Google Drive folder no longer downloads the whole
file each time.

## Google Drive files

- A file in a connected Drive folder is kept on this device once read, so
  opening it again, and the regular re-read while it is open, comes from this
  device. A file changed in Drive is still fetched anew.
- This applies to editable and read-only connections alike. Each connection
  keeps up to 2 GiB of files it read, for 7 days. Changes waiting to upload are
  never removed to make room.
- The first open of a file still downloads it.

## Installing

**Windows 11 x64:** download `irori-0.1.52-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.52-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.
