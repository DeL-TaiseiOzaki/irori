# irori 0.2.38 preview 1 — diagrams and footnotes as pages show them

- A `mermaid` code block shows its diagram. **Edit** shows the code.
- Footnotes (`[^name]`), wiki links (`[[page|label]]`, `![[embed]]`) and
  callouts (`> [!note] Title`) show as a page would, not as the Markdown
  source. Click one to edit what you wrote. The file keeps it exactly as
  written.
- A short code block is no longer stretched to the height of a page.
- When you select text, the toolbar with bold and link now also has a
  **comment** button. It opens the comment box beside the passage, with the
  passage quoted, so you no longer go to the note bar to comment.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. The new
`markdown-ui-smoke` opens a note with a footnote, a Mermaid flowchart, wiki
links, a callout and a short code block. It checks how each one shows, edits
the footnoted paragraph by clicking it, and checks the saved text.
`comments-ui-smoke` comments from the selection toolbar. It checks that the
box opens beside the passage with its field focused, and that the comment is
saved with its quote.
