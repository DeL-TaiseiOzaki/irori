# irori 0.2.91 preview 1 — Security hardening, cleanup of retired/broken paths, and core simplification

- **Security hardening**:
  - Strengthened Git and agent configuration approvals (`protocol.ext.allow`, `config.worktree`, continuation lines, Codex/Antigravity/OpenCode tool hooks, and symlink target digests).
  - Added canonical path-boundary checks (`path-guard`), bounded IPC `DeviceSettings` maps (`layouts`, `skillAudiences`) and dropped-folder depth, enforced `handedScopes` and confirmations in `AgentSetup`, hardened `SchemaHookRunner` (full `apply_patch` file checks, symlink resolution, metadata URL blocking, `IRORI_COMMAND` hiding), replaced regex wildcard matching in `ssh-config` with linear-time matching, tightened SSH vault-host wire/socket auth, and strengthened Office viewer DOM/style sanitization.
- **Hollowed/broken fixes and retired Drive cleanup**:
  - Removed retired Google Drive leftovers (`CloudRecovery`, `src/cloud/leftovers.ts`, and migration UI paths; [ADR 023](../decisions/023-retire-drive-sign-in.md) amended).
  - Fixed UI/CSS and behavior regressions: replaced `window.prompt` in `PageProperties` with inline input, fixed `FindScope` visibility checks and `AgentColumn` cleanup/tab-revision updates, wired `SchemaDialog` file opening and remote lock checks, scoped `New Note` creation to the target vault, and fixed SSH vault-host reconnect/version-replacement status (`host.running || host.waiting`).
- **Core simplification**:
  - Consolidated `DeviceSettings` schemas into `src/domain/settings.ts`, shared JSONL process streaming (`src/agents/json-lines.ts`), shared `OPENCODE_CONFIG_CONTENT` helpers (`src/agents/opencode-config.ts`), and unified `SerialQueue` / `local-json` usage.

## Verification

`npm run build`, `npm run format:check`, and `npm test` ran on Linux (`tests/security-hardening.test.ts`, `tests/simplify-core.test.ts`, `tests/connections.test.ts`, `tests/local-folders.test.ts`, `tests/schema-settings.test.ts`, `tests/release-policy.test.ts`, and `tests/releases.test.ts` pass; full suite had two host-environment failures on the shared development machine: `ssh-config` file permissions and `remote-hosts` `pgrep` matching an unrelated host `sleep 30`). `npm run test:ui` could not run on the headless development machine and is verified in pull request CI. Not tried on macOS or Windows.
