# irori 0.3.5 preview 1 — Astryx's controls

The next stage of bringing in [Astryx](https://github.com/meta/astryx)'s
design ([ADR 076](../decisions/076-astryx-design-system.md)): the rest of
irori's everyday controls take Astryx's parts.

- **Checkboxes and switches** are Astryx's. A setting's title still turns its
  switch when pressed.
- **Choices of views** are Astryx's segmented control: Files | Changes in a
  vault, Changes | History in Git, irori mode's layouts and agents, the
  routine editor's Form | YAML, and how a repository is added. With the
  keyboard, an arrow key now moves to the next choice and chooses it.
- **Shortcut keys, counts and running marks** are Astryx's: a key shows ⌘ on
  macOS and Ctrl elsewhere.
- **Empty pages** use Astryx's empty state: Git not set up, no Git repository,
  no ontology, and a workspace with no vault.
- **Text fields and selects** keep their places and labels, and take Astryx's
  input look: a clear border, an accent ring while you type, a faint ring
  under the pointer.

## Verification

- **UI smokes.** 42 of the 43 pass. They now find view choices as radios and
  check that an arrow key moves the choice. The one left stops at the system
  trash, which that host lacks; it fails the same way on earlier versions.
- **Screens.** All 36 screens in hearth, light and dark were rendered and
  looked at.
- **CI.** The pull request's CI runs the whole set, `npm test` and
  `npm run build` on its own machines.
