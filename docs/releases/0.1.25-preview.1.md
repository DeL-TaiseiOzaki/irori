# irori 0.1.25 — Windows and Mac preview, ObsidianUI controls

The view switches and the main buttons now show where you are and respond when
pressed, using ObsidianUI's Magnet Tabs and Arrow Fill Button in irori's own
light and dark colours. An installed 0.1.24 or earlier on either platform is
offered this by **更新を確認**. 0.1.23 and 0.1.24 were not published on their
own, so an update from 0.1.22 also brings what they added, summarised below.

## What changed

**View switches show where you are.** The note/source-control, changes/history
and folder/clone switches gain a moving selection marker and a hover
background. Arrow keys move focus; Enter or Space activates the focused choice.

**Primary actions respond with a fill and an arrow.** The registration and
workspace submit buttons, and the welcome screen's new-note button, use Arrow
Fill Button.

**Reduced motion follows the operating system.** Turning it on, including while
irori is open, makes the new indicators and button transitions immediate.

The components are local, MIT-licensed adaptations; they need no network access.

## Also in this preview, from 0.1.23 and 0.1.24

**A lighter package** (0.1.23). The package no longer carries the directories of
libraries that are already bundled into the application — about 90 MB that
nothing loaded. Their licences now travel as one generated file,
`dist/third-party-notices.txt`, inside the application.

**A graph index the knowledge base carries** (0.1.24). In a knowledge base
written as an Open Knowledge Format bundle, **オントロジー** offers
**グラフ索引を作成**: irori builds `Knowledge_Base/ontology/` from the pages'
`type`, `title` and `relations`, the same bytes on every device, and says when
the index is behind the pages. A knowledge base that declares its own CSV pair
in `.irori/ontology.json` behaves as before.

Details: [0.1.23 notes](0.1.23-preview.1.md), [0.1.24 notes](0.1.24-preview.1.md).

## Installing

**Windows 11 x64:** download `irori-0.1.25-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.25-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. The button appears only just after an
attempt to open the app, so if it is missing, open irori again and return to
that pane. Later launches behave normally.

## Verification

The published files are the artifacts of the CI run for the commit named under
**Exact package** below, unchanged except for their download names. Each package
job launches the packaged application from a different path and exercises SDK
imports, save/undo/redo, native clipboard image paste, the CSV graph, Japanese
note and terminal file saves, private drafts, recoverable note deletion after
restart, single-instance ownership, one search and bundled rclone. On macOS 26 it
first verifies the bundle and the copy inside the disk image. Tests use
disposable data and do not run a real model turn.

For this change, behaviour tests and all fourteen Electron UI suites pass on
the merged code, including keyboard view switching, repeated activation, a
disabled submit, reduced motion changed while the app is open, and light and
dark rendering.

## Remaining boundaries

Passing CI is not acceptance on an installed device. Installation, Japanese
input, real CLI accounts, Git operations and Google connections still need device
trials on Windows and the Mac. The new controls cover the view switches and the
buttons named above; search and the editor keep their existing interactions.
