# irori 0.1.25 — Windows and Mac preview, ObsidianUI controls

This preview adopts ObsidianUI's Magnet Tabs and Arrow Fill Button in the desktop
workspace, using irori's light and dark palettes.

## What changed

- **View switches show where you are.** The note/source-control, changes/history
  and folder/clone switches gain a moving selection marker and hover background.
  Arrow keys move focus; Enter or Space activates the focused choice.
- **Primary actions respond with a fill and arrow.** The registration and workspace
  submit buttons, and the welcome screen's new-note button, use Arrow Fill Button.
- **Reduced motion follows the operating system.** Turning it on, including while
  the app is open, makes the new tab indicators and button transitions immediate.

These are local, MIT-licensed component adaptations. The application carries all
code and styling; using the controls requires no network access.

## Verification and boundaries

Production build, format check, 204 behavior tests (197 passed, seven
platform/tool-gated skips) and all fourteen Electron UI suites passed locally. The UI coverage exercises registration, keyboard view switching,
form submission, note editing and live reduced-motion settings. Package builds and
installed-device acceptance on Windows and Apple silicon remain separate checks.

This adoption covers the controls above; search and the editor retain their
existing interactions. A command palette is not included.

See [distribution and installation](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/DISTRIBUTION.md)
for preview installation and platform requirements. ObsidianUI's MIT attribution
is included in the application's third-party notices.
