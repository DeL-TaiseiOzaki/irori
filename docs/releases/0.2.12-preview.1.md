# irori 0.2.12 preview 1 — the CLI's own commands and skills

Type `/` in the agent's box to see what the CLI offers in this folder: Claude
Code's commands and skills, or Codex's skills with `/compact` and `/review`.
Choose one with the arrow keys and Enter, or keep typing to narrow the list.

- On Codex, `/compact` summarizes the conversation, `/review` reviews the
  uncommitted changes (or follows the words after it), and `/skill` or
  `$skill` uses that skill. They used to arrive as plain words.
- Claude Code runs `/name` itself, as in its terminal.
- OpenCode, Pi and Hermes Agent show no list.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. Protocol fixtures check
the lists, Codex's compaction, review and skill items, and the list in the
real Electron app. Not tried with a real Claude Code or Codex session.
