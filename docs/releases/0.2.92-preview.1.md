# irori 0.2.92 preview 1 — The session board at the right

- The session board now stands right of the agents' columns, at the window's
  edge, in a vault's dock and in irori mode. A card's panel opens to the board's
  left ([ADR 069](../decisions/069-session-board.md)).
- As before, 表示 → 画面に出すもの → **セッションボード** turns it off or on; the
  place is now named **エージェントの列の右**.

## Verification

`npm run build` and `npm test` pass. On Linux under Xvfb,
`scripts/session-board-ui-smoke.ts` checks the board stands right of the agent
column, the panel opens left of the card, and dragging the board's handle left
widens it; `window-items-ui-smoke.ts` checks the setting's place. Not tried on
macOS or Windows.
