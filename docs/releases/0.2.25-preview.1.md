# irori 0.2.25 preview 1 — routine secrets in the saved environment

- **設定 → アカウント** shows a passphrase field when this device keeps routine
  secrets. **環境を保存** with a passphrase of 12 characters or more saves them
  too, sealed with that passphrase in `irori-settings/routine-keys.json`.
  Without one, the secrets stay on the device as before.
- **環境を復元** lists the saved secrets. Enter the passphrase to add the ones
  this device lacks; they are sealed again with this device's key. A secret
  already here keeps its value, and a wrong passphrase stops the restore
  before anything is cloned.
- The values are never written in plain form, sent to GitHub or shown in the
  window, and the passphrase is not stored
  ([ADR 047](../decisions/047-routine-secrets-in-the-environment.md)).

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/environment.test.ts` saves on one device and restores on another and
checks that neither a value, the device's sealed form nor the passphrase
reaches the settings repository, that a wrong passphrase clones nothing, and
that a changed name list or an oversized scrypt cost is refused.
`scripts/account-ui-smoke.ts` does the same through the window. The OS key is a
reversible stand-in there; not tried with a real Keychain, DPAPI or secret
service.
