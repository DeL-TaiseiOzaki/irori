# irori 0.2.10 preview 1 — A file manager's menu on every file

Every file and folder in a vault's panel now has a right-click menu, in every
layer, as in Explorer or Finder ([ADR 036](../decisions/036-explorer-as-file-manager.md)).

- **Open**, then what the layer allows (new items, **Rename**, **Move**,
  **Delete**), then **Copy path** and **Copy relative path**, then **Show in
  Finder** (Explorer, file manager).
- **Copy path** puts the full path on this computer on the clipboard; **Copy
  relative path** the path from the vault's root, with `/`.
- Read-only rows, Schema files (instructions, skills, rules) and the vault beside
  have the menu too, with what applies to them. The **⋯** button on a row opens
  the same menu.

## Verification

`npm run build`, `npm run format:check`, `npm test` and `npm run test:ui` pass.
`explorer-ui-smoke` copies a folder's relative path and a file's full path from
the menu and reads them back from the clipboard. On the CLI test desktop, a
knowledge note and the Schema's `AGENTS.md` showed the menu and copied their paths.

Not tried on Windows or macOS.
