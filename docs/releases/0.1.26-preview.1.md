# irori 0.1.26 — Keep note references and recover connections

Renaming a note keeps the person's line marks and the Open Knowledge Format
references that point to it. Broken generated graphs and transient Drive
connection failures have a recovery path. This preview also prepares cloud
send records for exact account binding; Google access remains read-only.

## What changed

- Note moves update Markdown body links and the frontmatter's relation/source
  references, preserving comments and unrelated metadata. Existing person-line
  marks survive both moves and link rewrites.
- **GitHub から取得** receives shared person-line notes on the first clone.
  If that additional fetch fails, the checkout is retained and the registration
  screen explains how to retry. Git-detected renames are followed when reading
  the recent shared authorship history.
- Graph generation checks all output sizes before writing. A damaged or
  previously oversized generated module can be regenerated from its pages in
  the ontology panel. Explicitly declared CSV tables are still never replaced.
  Decomposed Japanese filenames open through their actual local spelling.
- A healthy Drive mount recovers from a transient status error. A mount that
  has already disappeared no longer traps normal shutdown when its absence can
  be independently confirmed.
- New send preparations retain the exact account and shared-drive identity.
  Changed destinations and old unbound preparations are refused by the delivery
  engine; retained source versions remain available for recovery.

## Verification and limits

Regression tests use disposable knowledge bases and Git repositories. Cloud
protocol fixtures and local rclone copy/checksum tests use no Google account.
The integrated build, behavior and fourteen Electron UI suites are recorded in
[STATUS](../STATUS.md). This branch does not run a real model turn or establish
Windows/Mac installed-device acceptance.

Google writes, re-consent, distribution signing/notarization and automatic
updating remain separate work. YAML aliases, multiline references, wiki links
and HTML references are not automatically rewritten. Graph writes are guarded
per file, not a multi-file filesystem transaction. See the
[audit and remaining work](../AUDIT-2026-09-22.md).
