# irori 0.2.11 preview 1 — agents know the vault they work in

A vault's agent now hears, at the start of a conversation, what irori is and
how its vault is laid out: that `AGENTS.md` holds the vault's instructions,
which folders are Knowledge and which are Contents (under the names the vault
gave them), and which folders are connected.

- Later messages in the same conversation carry one line instead of repeating
  it. A change to the vault's folders or connections is told in full again.
- The description of the `irori` command is shorter; the agent finds the
  details with `irori help`. This applies to the irori agent too.
- In irori mode, the irori agent hears each vault's Knowledge and Contents
  folders.
- A CLI's own command typed alone, such as `/compact`, reaches the CLI as it
  is again; irori used to put its words before it.

## Verification

`npm run build` and `npm test` pass. Protocol-fixture tests check the
introduction, the one-line form in a continuing session and the full form
after a change. Not tried with a real Claude Code, Codex, OpenCode, Pi or
Hermes Agent session.
