# irori 0.2.99 preview 1 — The irori agent makes vaults on SSH hosts

- In irori mode, the irori agent can now prepare vaults on your SSH hosts. Ask
  it to make a folder there a vault, to start a new vault there, or to clone a
  GitHub repository there: `irori add`, `irori create` and `irori clone` take
  `--host <host>`. Each waits for you to allow it, and the new vault joins the
  workspace you asked from.
- `irori hosts` lists your SSH hosts and, for one host, the folders in a folder
  there, so the agent can find what to add. `irori list` names the vaults on
  SSH hosts too.

## Verification

`tests/remote-hosts.test.ts` stands this machine in for an SSH host and has the
`irori` command list its hosts and folders, add a folder there, create a vault
(a Git repository on `main` with its first commit) and clone a repository
there, and join each to the workspace; a vault agent's command is refused.
`tests/irori-command.test.ts` reads the new forms. Not tried with a real CLI
agent or against a real SSH host.
