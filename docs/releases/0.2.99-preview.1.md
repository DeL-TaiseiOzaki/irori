# irori 0.2.99 preview 1 — The irori agent makes vaults on SSH hosts, and does what the window does

- In irori mode, the irori agent can now prepare vaults on your SSH hosts. Ask
  it to make a folder there a vault, to start a new vault there, or to clone a
  GitHub repository there: `irori add`, `irori create` and `irori clone` take
  `--host <host>`. Each waits for you to allow it, and the new vault joins the
  workspace you asked from.
- `irori hosts` lists your SSH hosts and, for one host, the folders in a folder
  there, so the agent can find what to add. `irori hosts --add` adds a host.
  `irori list` names the vaults on SSH hosts too, and `irori workspace` and
  `irori remove` reach them.
- What the window does for setting up, the irori agent can now do too, each
  as the window does it: move a note into another vault (`irori move`), copy
  with links kept (`irori copy`), stop a routine (`irori stop`), rename, delete
  and group workspaces, rename a connected folder or make it read-only
  (`irori connection`), tidy what no connection names in contents
  (`irori strays`), use an image as a vault's icon (`irori set --icon-image`),
  install uv for routines (`irori install python`), and add or renew its
  standard skills (`irori skills`). Deleting, removing and renewing ask you
  first.

## Verification

`tests/remote-hosts.test.ts` stands this machine in for an SSH host and has the
`irori` command list its hosts and folders, add a folder there, create a vault
(a Git repository on `main` with its first commit) and clone a repository
there, and join each to the workspace; a vault agent's command is refused.
The same test adds a host, groups and removes a vault on the host.
`tests/irori-command.test.ts` reads every new form and runs them: copy and
move across vaults, workspace rename, groups and delete, an icon image,
renaming and locking a connected folder, strays adopted and removed, stopping
a routine, installing uv and renewing the standard skills, with what asks the
person first. Not tried with a real CLI agent or against a real SSH host.
