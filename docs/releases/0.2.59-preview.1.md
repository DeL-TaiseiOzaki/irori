# irori 0.2.59 preview 1 — delete in connected folders that have no trash

- Files and folders in a connected folder can now be deleted where Windows has
  no Recycle Bin for them, such as Google Drive for desktop's drive or a
  network folder. Before, irori stopped with an error and deleted nothing.
- irori still moves what you delete to the system trash when it can. When the
  system refuses, a dialog names the item, says it cannot be restored on this
  computer, and that the sync app passes the deletion to the cloud and to
  anyone it is shared with; the service's own trash may still restore it. Only
  **完全に削除** deletes it.
- The connected folder itself is still removed with **接続を解除**, which keeps
  the folder, and a read-only connection still deletes nothing.

## Verification

`npm run build` and `npm test` pass, with new checks that a refused entry is
kept without an answer or on cancel, that a file and a folder are deleted once
confirmed, and that the connected folder itself is refused. Not yet tried on
Windows with a real Google Drive for desktop or OneDrive folder.
