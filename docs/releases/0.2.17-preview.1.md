# irori 0.2.17 preview 1 — the saved environment carries your routines

- **環境を保存** now also keeps the irori agent's routines (the folders in its
  `routines/`, with every file) in your private `irori-settings` repository,
  even when the irori agent's folder is not on GitHub, and the JavaScript
  switch for routines. A vault's routines still travel with the vault's
  repository.
- **環境を復元** lists the saved routines. The chosen ones are added to the
  irori agent's folder on the new device; a routine folder that is already
  there is left as it is. Each restored routine is reviewed before its first
  run, and secrets are entered again on each device.
- A routine too large to save (about 900 KB in all), or one holding a link, is
  named in 設定 → アカウント.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/environment.test.ts` covers saving a routine's text, binary and
executable files and the JavaScript switch, leaving out a routine with a link,
restoring into a cloned irori agent folder, keeping a routine folder already
there, emptying the saved list, refusing to write where the irori agent is not
set up, and a damaged `routines.json`. `account-ui-smoke` saves a routine on
one device and restores it from the start screen on another. Not tried with a
real GitHub account.
