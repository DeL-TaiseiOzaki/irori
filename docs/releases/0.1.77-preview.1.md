# irori 0.1.77 preview 1 — Make routines from the routines page

The routines page now has **New routine** and **Ask the irori agent** at the
top. **New routine** asks for a name and whether it belongs to the irori agent
or a hibachi, makes the folder with a `routine.yaml` to finish, and opens it
in an editor; the pencil on each routine edits it later. **Ask the irori
agent** starts a request in the irori agent's message box: its new standard
skill `write-routine` and the `irori routines` check let it write a routine
and confirm irori can read it. Older irori agent folders get the skill with
the other missing standard skills.

The JavaScript switch moved to **Settings → Routines**; a routine that needs
it still offers it on its row. Every run still starts only from **Run**, and
a changed routine is reviewed first.
