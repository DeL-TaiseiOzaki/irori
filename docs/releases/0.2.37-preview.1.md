# irori 0.2.37 preview 1 — rename in place

- In the explorer, a file or folder is renamed where its name is shown, as in
  Finder or Explorer. Select a row and press **F2**, or choose **名前を変更**
  from its menu. **Enter** renames, **Escape** keeps the name. A note is
  renamed by its title. In a file's name, the part before the extension is
  selected, so typing replaces the name and keeps the extension.
- A name that cannot be used, or that another item already has, is explained
  just below the field. You can try another name or press Escape.
- Schema's files and folders can be renamed the same way from its file view,
  except `.irori` and `.git`.
