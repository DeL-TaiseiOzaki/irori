# irori 0.2.43 preview 1 — click an image to see it whole

- A click on an image in a note shows it over the page at its own size, or as
  large as the window allows. Escape or another click closes it. This works for
  images written as `![alt](shot.png)` and for Obsidian embeds `![[shot.png]]`,
  in editable and read-only notes.
- The click still selects the image, so Backspace deletes it once the view is
  closed. The resize handle and the caption button work as before.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `images-ui-smoke`
opens an embed with a click and closes it with Escape, then opens an image
block, finds the note's alt text on the enlarged image, and closes it with a
click.
