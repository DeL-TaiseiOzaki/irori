# irori 0.1.73 — remove a hibachi

- **hibachi の設定** has **hibachi を削除**. The hibachi leaves this device's
  list and every workspace, including its rail group.
- Its folder stays as it is unless **フォルダもゴミ箱に移す** is checked; then
  the folder goes to the system trash, where it can be restored. Adding the
  kept folder again brings back the same hibachi.
- Before the folder moves, irori closes the hibachi's terminals and
  disconnects its connected folders; the folders those links point to are not
  touched. A folder that holds another hibachi or the irori agent's folder is
  not moved.
- Conversations and other records kept on this device stay.

## Verification

Unit tests cover the device list, workspaces and groups after removal, the
order of letting go and moving to the trash, a trash failure that leaves the
hibachi as it was, and the folders that refuse the trash. The brain-settings
Electron UI suite removes a hibachi from its sheet and checks the rail, the
stored lists and the kept folder. Moving a folder to a real system trash was
not tried in the test display.
