# irori 0.2.58 preview 1 — edit a sent message, branch a conversation

- **この指示を編集してやり直す**: point at one of your messages and press the
  pencil to edit it. Sending hides what followed it and the conversation goes
  on from just before it, as Claude Code and Codex let you edit a message. The
  hidden part stays in irori's history file. Not offered while the
  conversation runs or has queued instructions.
- **ここから分岐**: at the end of any run, beside 完了, copies the conversation
  up to there into a new conversation and opens it as a tab. The original stays
  as it was; attached files are copied with it.
- Claude Code and Codex branch their own session from that point (Claude Code's
  `resumeSessionAt` with `forkSession`, Codex's `thread/fork`), so the agent
  keeps the earlier context and not the part left out.
- Other CLIs, and any time a new session starts in a conversation that already
  has messages (another computer or folder, a changed access, a session that
  could not be resumed), now receive the conversation so far: your messages and
  the replies, without tool output, newest kept.
- Files an agent changed are not restored by a rewind; use Git for that.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass, with new protocol
fixture tests of a rewind and a copy on Codex and Claude Code, the set-aside
messages leaving the view, and Hermes Agent receiving the conversation so far,
and the irori mode threads smoke editing a message and branching a run in the
irori agent's column and in a vault's. Not yet tried with a real Claude Code or
Codex session.
