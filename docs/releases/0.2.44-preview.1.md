# irori 0.2.44 preview 1 — agents can find Google Docs and Sheets

- Google Docs, Sheets and Slides in a Drive for desktop folder are `.gdoc`,
  `.gsheet` and `.gslides` files that hold only the document's ID. Agents used
  to hear that they could not read them. Now irori tells them where the ID is
  and which docs.google.com address it makes, so an agent with its own Google
  Drive tool (a connector, an MCP server or the gws CLI) reads the document,
  and one without gives the person the link.
- The words go with the connected folders in every request, and into the
  irori agent's connect-folder skill when it is written. An irori agent folder
  made before keeps its skill as it is.
- irori itself still opens these files in their application, as before; it
  does not sign in to Google (ADR 023).

## Verification

`npm run build` and `npm test` pass. `tests/prompts.test.ts` checks the
connected-folder words and the connect-folder skill for the ID and the address.
No real CLI read a Google document in this change.
