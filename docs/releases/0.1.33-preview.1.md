# irori 0.1.33 — Choose English or Japanese for the interface

irori can now show its interface in English. Open the display settings (the
icon beside the version at the top of the sidebar) and choose **English** or
**日本語** under **言語 / Language**. The change applies at once, without a
restart, and is remembered on this device. Japanese remains the default.

The choice covers the application's own text: menus in the sidebar, buttons,
dialogs, notices and the messages irori itself reports, including those from
the desktop side such as file, Git and Drive errors. Your notes, file names and
the templates written into a knowledge base are not translated, and neither are
the instructions irori sends to agents. Messages that come from Git, rclone or
an agent CLI appear as those tools write them.

## Installing

**Windows 11 x64:** download `irori-0.1.33-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.33-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. The button appears only just after an
attempt to open the app, so if it is missing, open irori again and return to
that pane. Later launches behave normally. Keep irori in **アプリケーション**:
the in-app update replaces the app where it is.

## Verification

The published files are the artifacts of the CI run for the commit named under
**Exact package** below, unchanged except for their download names. A new UI
test switches to English, visits the main screens and dialogs with knowledge
bases named in English, and fails if any Japanese interface text remains; it
then restarts to check that the choice is kept and switches back to Japanese.
Settings tests cover the default, persistence and the accepted values.

## Remaining boundaries

Passing CI is not acceptance on an installed device. Text already on screen
when the language changes, such as a message shown a moment earlier, stays in
its language until it is shown again, and the editor's own toolbar labels
switch when the note is next opened. The window menu (File, Edit, View,
Window) is Electron's and follows the operating system.
