# irori 0.2.98 preview 1 — Connections stay connected

- irori links every vault's connected folders and GitHub repositories as it
  starts, before you open a workspace. Home, every tab and CLI agents working
  outside irori find them at `contents/<name>` from the start.
- Closing a tab or a window, or taking a vault out of a workspace, no longer
  disconnects that vault's folders. They stay connected until you disconnect
  them or quit irori.
- A folder that is not there yet at the start, such as one on a drive a sync
  app has not mounted, waits and connects by itself, as before.

## Verification

`tests/local-folders.test.ts` quits a service and starts another: a folder
that is there is linked again, one not there yet waits, and one with no folder
chosen on this device is left. `tests/repository-connections.test.ts` does the
same for a GitHub repository's clone. The renderer change (no disconnect when
a tab closes) is covered by the UI smokes in pull request CI; it was not tried
by hand in a packaged app.
