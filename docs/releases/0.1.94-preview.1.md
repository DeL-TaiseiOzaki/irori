# irori 0.1.94 preview 1 — The irori agent's history per workspace

The irori agent now keeps its conversations per workspace. In each workspace,
**履歴**, the conversation the panel opens on, waiting instructions and new
conversations are that workspace's own; opening another workspace shows its
history instead. A conversation continues only in the workspace it began in.
A routine's irori agent step is kept with the routine's workspace.

Conversations from before this version belong to no workspace and are not
listed; they stay on disk. Each hibachi keeps its one history, as before.

Sending from an irori agent column in the dock now also tells the agent which
workspace it is in, so hibachis it registers from there join that workspace.

## Verification

`npm test`, `npm run typecheck` and `npm run format:check` pass. A store test
keeps conversations of two workspaces and one from before apart in the list,
the conversation on show, the queue and the waiting count, refuses continuing
one in another workspace, and leaves a hibachi's history whole.
