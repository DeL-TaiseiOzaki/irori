# irori 0.1.48 — Hibachi Agent: any CLI, any model, no time limit

The brain's AI panel is now called **Hibachi Agent**. It runs on the CLI you
choose, with the model you choose, and a long run is no longer cut off.

## Hibachi Agent

- **AIに相談** is now **Hibachi Agent**, on the note bar, the Overview and the
  status bar.
- It starts in **フルアクセス** (full access) wherever the CLI offers it. You can
  still switch to the standard mode in the composer. A conversation saved in the
  standard mode starts afresh on its next send in full access; its displayed
  history stays.
- The open note no longer always goes with your instruction. Remove its chip
  with ×, and put it back with **＋ note name**.
- The message "実行時間の上限（10分）に達しました。" is gone. Runs end when they
  finish, when you stop them, or when the CLI exits. irori's 10-minute wait for
  Pi's answer was removed too.

## CLIs and models

- **Hermes Agent** (Nous Research) is the fifth CLI, beside Claude Code, Codex,
  OpenCode and Pi. irori runs the installed `hermes` with your own Hermes
  sign-in and settings; full access adds `--yolo`.
- A **model** pill beside the access setting lists the models your installed CLI
  offers: Codex and Claude Code ask the CLI itself, OpenCode and Pi use their
  model lists, and Hermes takes a typed model name. **CLI の既定** keeps the
  CLI's own choice. Changing the model continues the same conversation.

## Your AI

- Your AI runs on any of the five CLIs, chosen with its model in its panel.
- With Claude Code it still hands each brain's work to that brain's sub-agent,
  and irori keeps each write inside the right folder.
- With the other CLIs there are no sub-agents: your AI works in the brains
  directly, after reading each brain's `AGENTS.md`, in full access where the
  CLI offers it. irori cannot hold those writes to the brains' folders.

## Installing

**Windows 11 x64:** download `irori-0.1.48-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.48-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.

## Verification

- Codex's model list (`model/list`, codex-cli 0.156.1) and Claude Code's
  (`supportedModels()`, 2.1.280) were read from the installed CLIs without
  generating any text.
- Hermes, OpenCode and Pi are covered by protocol fixtures: the Hermes stream,
  the model lists, and each CLI receiving the chosen model.
- Your AI on Pi was run through a fixture, checking the brains it is handed and
  the instructions it is given.
- The full build, unit tests and Electron UI suites passed.

## Remaining boundaries

- Hermes Agent has not been run for real: it was not installed where this was
  built. Real OpenCode and Pi model lists are untested.
- Not yet tried from an installed macOS or Windows 11 app.
