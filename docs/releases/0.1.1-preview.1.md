# irori 0.1.1 — Windows testing preview 1

This unsigned Windows x64 update adds the integrated terminal and includes rclone. Google account login still needs the distributor's Google OAuth client; this package does not enable new Google account connections yet.

## Download and use

1. Close the earlier irori version, download `irori-0.1.1-windows-x64-Setup.exe`, and open it. This preview remains unsigned, so Windows may show an unknown-publisher/SmartScreen prompt.
2. Open a disposable KB or a copy of your notes. Choose **ターミナル** in the bottom bar to start a detected shell in that KB's folder. Windows discovery includes PowerShell 7, Windows PowerShell, Command Prompt and Git Bash when installed.
3. To switch shells, stop the process, select another detected shell and choose **開く**. Closing the pane terminates the shell and its child processes. This is a native shell with your normal permissions.
4. [Git for Windows](https://git-scm.com/downloads/win) and any desired agent CLI/account are separate prerequisites. Node.js/npm and a separate rclone installation are not needed for the installed app.

The terminal reuses xterm.js/FitAddon and node-pty, with default-shell/which for discovery. Windows packaging uses node-pty's official Node-API prebuilds. rclone 1.75.1 is bundled from its official release with pinned archive checksums and its MIT notice. Terminal input, resizing, output flow control, process cleanup and host validation are covered by tests; no model inference was used.

## Google connection status

The system-browser Google flow, account/folder/shared-drive management and read-only mount integration delegate to rclone. Build-time client configuration is wired to the distributor's repository secrets; this release has no client configured. [Distributor setup](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/DISTRIBUTOR-GOOGLE.md) is an owner task, not an end-user Google Cloud requirement. Windows mounts additionally require [WinFsp](https://winfsp.dev/rel/); irori links its installer and can recheck installation.

Real Google consent, refresh and native mounts remain unverified. Cloud writes, provenance, signing, upgrades/rollback and full Windows 11 device/IME/native-agent acceptance remain release work. This continues the owner-authorized Windows testing channel and does not waive the [full release requirements](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/RELEASE-PLAN.md). Mac downloads remain unavailable.

## Support and data

Report the version, OS and exact error through [GitHub Issues](https://github.com/DeL-TaiseiOzaki/irori/issues); do not post private notes, credentials or terminal/provider transcripts. KB files remain in selected local folders. Commands and agents you run can access files with your normal permissions; agent requests may send relevant content to their provider. irori does not persist terminal transcripts, though the selected shell can retain its own history. The download website has no application backend or added analytics; GitHub hosts the downloads.
