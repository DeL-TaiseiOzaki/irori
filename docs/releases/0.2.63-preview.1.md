# irori 0.2.63 preview 1 — a window that shows the work

The window now shows what a note and a conversation need. What sets how irori
behaves, and what only a developer's way of working uses, is in the settings
and joins the window only when turned on there
([ADR 059](../decisions/059-the-window-shows-the-work.md)).

- **表示 → 画面に出すもの** (Display → What the window shows) lists each such
  item with a switch, where it appears and what holds while it is off.
  **すべて出す** (Show all) puts every item back at once; **既定に戻す** (Back to
  default) returns to the list below.
- **Off the window after this update, until turned on:**
  - under the instruction box: the conversation's access, its model and
    thinking level, and whether to tell the agent which lines a person wrote;
  - at the top of a conversation: the buttons that add a column and hide the
    page;
  - along the window's foot: the Git branch, the terminal's button (also on a
    vault's home) and irori's version.
- **Still on the window:** the skill of a request, for a vault that has skills.
  It can be turned off the same way.
- Taking a control off the window does not change what it was set to: a
  conversation keeps its access and its model. A skill and the person's lines
  are not sent while their control is off.
- What is in use stays in view: the access of a conversation in full access,
  the terminal's button while a terminal is open (Ctrl+` still opens and closes
  it), and the button that shows the page while it is hidden.
- The conversation's **会話と接続** menu is gone. Each CLI's version, or that it
  was not found, is under **エージェント → 共通 → この端末の CLI**.
- The skill reach check (到達確認) is on a vault's home under Schema only, no
  longer under the instruction box too.
- These choices are kept on the device and are part of the environment saved
  to GitHub.

## Verification

`npm run build`, `npm run format:check`, `npm test` and `npm run test:ui` pass.
The new `window-items-ui-smoke` opens a new device's window, checks that none
of the items above is on it, turns the terminal on and off from the settings,
shows all and returns to the default, and checks that full access and an open
terminal keep their controls in view. Screens were inspected on Linux under
Xvfb in Japanese, with and without the vault agent. Not seen on Windows or
macOS.
