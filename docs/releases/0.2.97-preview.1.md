# irori 0.2.97 preview 1 — The irori agent knows vaults can work at once

- The irori agent is now told that different vaults can work at the same time,
  and to run its `irori call` hand-offs for independent tasks in parallel.
  irori already allowed this (it refuses only a second hand-off to a vault that
  is still working), but nothing told the irori agent, so a request spanning
  several vaults could wait on each vault in turn.
- A vault still takes one task at a time: the irori agent waits for its report
  before handing it another.

## Verification

`tests/vault-command.test.ts` hands tasks to two vaults in one shell command
through the Pi protocol fixture; each vault agent waits for the other's mark,
so the test passes only when both run at once. `tests/prompts.test.ts` checks
the irori agent's words. Not tried with a real CLI agent, so whether each CLI
chooses to run the calls in parallel is not verified.
