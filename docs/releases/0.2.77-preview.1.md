# irori 0.2.77 preview 1 — Reorder workspace tabs by dragging them

- Drag a workspace tab along the tabs and let go: it takes that place
  ([ADR 065](../decisions/065-tabs-reordered-by-dragging.md)). A short line
  shows the gap it will take while you drag, and the tab follows just under
  the pointer.
- Only the order changes: the tab on show stays on show and no agent stops.
  Let go where the tab already is, nothing changes.
- Dragging a tab below the tabs or out of the window still opens it in a new
  window or joins another window's tabs, as in 0.2.74 and 0.2.76.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb. The
windows smoke drags a tab before the other one with the mouse, checks the mark,
the new order and that the tab on show and the windows stay, then lets a tab go
where it stands and checks nothing moved. Not tried on macOS or Windows.
