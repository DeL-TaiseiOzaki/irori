# irori 0.1.51 — irori mode's own mark

The rail's **irori mode** button now shows irori mode's own mark — people
gathered round a fire on a white tile, cut to the same shape as the app icon —
instead of a generic map glyph.

## The rail

- The mark sits at the top of the rail, the size of a hibachi's tile. It is
  dimmed while a hibachi is open and shown at full strength on hover and while
  irori mode is on show; the bar beside it still marks the current place.
- Nothing else about irori mode changes.

## Installing

**Windows 11 x64:** download `irori-0.1.51-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.51-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.
