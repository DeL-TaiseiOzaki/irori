# irori 0.1.76 preview 1 — Carry your environment with your GitHub account

Settings now has an **Account** section showing the GitHub account irori uses
through the GitHub CLI (`gh`). **Save environment** keeps your GitHub hibachis,
workspaces and display and agent preferences in a private `irori-settings`
repository of that account. On another device, **Restore from GitHub** on the
start screen (or **Restore** in the settings) clones the hibachis, brings back
the workspaces and applies the preferences.

irori keeps no token of its own: it uses `gh`'s sign-in. Folder paths, notes,
conversations and secrets are never saved, and hibachis without a GitHub
remote are left out. Saving and restoring happen only when you press them.
