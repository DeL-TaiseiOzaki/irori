# irori 0.3.2 preview 1 — The contents folder as a folder in Contents

- In a vault whose own files are Contents (a vault without Knowledge, or one
  that chose **vault 直下のファイルも**), the Contents section no longer shows
  a separate `contents` heading below the vault's files. The contents folder
  is now one folder row among them, with a link icon and muted text. Open it
  to reach the work folder and connected folders and repositories; pointing at
  it says it keeps them outside Git.
- It still cannot be renamed, moved or deleted from the explorer, and nothing
  on disk moves. A vault with Knowledge whose own files are Knowledge shows
  Contents as before.

## Verification

`scripts/vault-layers-ui-smoke.ts` checks, in a vault of Schema and Contents,
that the contents folder shows as a `contents` row in the Contents tree and
that no separate heading is drawn. Decision: ADR 071 D3, amendment of
2026-11-28.
