# irori 0.2.90 preview 1 — Minimal session cards, with the rest on hover

- A card on the session board now shows only the vault's icon, the request and
  the CLI. Pointing at it, or focusing it, shows a panel beside the board with
  the whole request, what a waiting request asks, the end of the last reply,
  how long the run has gone on and the model
  ([ADR 069](../decisions/069-session-board.md)).
- A hand-off's card names its task rather than irori's words to the vault agent.

## Verification

`npm run build` and `npm test` pass. On Linux under Xvfb,
`scripts/session-board-ui-smoke.ts` checks the card's contents, the panel
beside the card and its ask, and that dragging the board's handle widens it.
Not tried on macOS or Windows.
