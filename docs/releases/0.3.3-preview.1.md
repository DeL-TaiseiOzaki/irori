# irori 0.3.2 preview 1 — Astryx's look, first stage

irori starts taking the look of [Astryx](https://github.com/meta/astryx),
Meta's open-source design system
([ADR 076](../decisions/076-astryx-design-system.md)). Nothing irori does has
changed; this stage changes how it looks.

- **Colours.** Every colour comes from Astryx's neutral theme: neutral greys
  without a tint, Astryx's status colours for waiting, failing, added and
  removed, and Astryx's hues for vault colours and layers. Hearth keeps its
  dark chrome around a light page; Light and Dark are Astryx's own.
- **Type.** The interface is set in Figtree. Japanese text still uses Noto Sans
  JP or your system's Japanese font. Code and the terminal keep Geist Mono.
- **Shapes.** Buttons, rows, menus and dialogs take Astryx's rounder corners.
  The page's corners are rounded off the panels around it, and the agent's
  instruction box and your messages take Astryx's chat shape.
- **Focus.** The keyboard focus ring and a chosen option are Astryx's accent:
  dark on the page, light on the dark chrome, with no blue.

## Verification

`tests/astryx-tokens.test.ts` checks that `src/app/astryx-tokens.css` is what
the installed Astryx 0.7.17 gives, and that every Astryx token the colour roles
name exists. `tests/window-frame.test.ts` follows the chrome's colours through
to Astryx's values for the window controls. The Electron UI smokes run in pull
request CI, and the screens it renders were looked at in all three themes.
