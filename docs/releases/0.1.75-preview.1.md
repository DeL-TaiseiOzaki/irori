# irori 0.1.75 preview 1 — Routines in the rail

Routines now has its own button between irori mode and the hibachis in the left
rail. Open it directly to configure the device's JavaScript runtime, manage
secrets, review and run routines, and inspect their steps and history. The agent
panel stays beside the page, including in a workspace without hibachis.

irori mode keeps the map and columns, remembering the chosen layout when you
return. The Routines icon was created with GPT Image from the existing icon
family: folded charcoal arrows around an orange flame on an ivory tile.

Routine definitions continue to live in `routine.yaml` and their accompanying
files; this release does not add a visual routine editor or scheduling.
