# irori 0.1.3 — Continuous editing Windows preview

This unsigned Windows x64 testing update addresses the owner's note, image, Git and conversation feedback. Close the earlier app and install `irori-0.1.3-windows-x64-Setup.exe`. Existing KB folders, Google configuration and native CLI accounts remain in place; initial Google client registration is not required again.

## Changes to try

- Paste/drop PNG, JPEG, GIF or WebP into a note, or use the image picker. Files are stored in `_assets/` beside the note with relative Markdown links and reopen from disk.
- Keep writing after saving. Markdown stays in document view; saves preserve the editor, selection and undo history. Notes auto-save after a pause and before navigation or sending. Detected unsupported blocks retain their literal contents within the document.
- Open **変更と履歴**, use **すべて追加** / **すべて解除**, enter a message and **コミット**. Publishing to the remote branch remains a separate action.
- Continue typing in the AI composer during native work. Enter sends, Shift+Enter adds a newline, and **送信待ちに追加** queues the next turn. A failed or stopped turn pauses the queue for explicit resumption. Notes can be edited while a turn runs; external changes retain the conflict/recovery flow.
- **参照に追加** and **資料と成果物** retain source versions, run IDs, manual artifact registrations and recoverable Drive-send preparation. These records stay on this device. Google uploads are still disabled.
- The transparent icon supplied by the owner is used by the app, website and native installer.
