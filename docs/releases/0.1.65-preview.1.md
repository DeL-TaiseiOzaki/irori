# irori 0.1.65 — agents side by side, hibachi agent optional

- irori opens as an editor for knowledge bases and contents. The hibachi agent
  and the Schema layer are turned on in **設定 → エージェント → hibachi agent**;
  until then the explorer shows Knowledge and Contents, and the AI button opens
  the irori agent.
- The pane beside the page holds conversations side by side. **列を追加** adds a
  column, each column has its own tabs, history and composer, and with the
  hibachi agent on each column shows either the hibachi agent or the irori agent.
  The pane has no width limit.
- **本文を隠す** hides the page so only the explorer and the agents show; opening
  a file or **本文を表示** brings it back.

See [ADR 021](../decisions/021-optional-hibachi-agent-and-agent-dock.md).

## Verification

A new Electron suite (`dock-ui-smoke`) checks the default without the Schema
layer, turning the hibachi agent on and off, adding and closing columns with
separate drafts, switching a column to the irori agent, hiding and restoring the
page, and the setting surviving a restart. The existing UI suites that use the
hibachi agent start with it turned on.

Real CLI turns in two columns and installed Windows and macOS builds were not
tested.
