# irori 0.1.16 — Windows and Mac preview, backlinks that land on the link

0.1.15 listed the notes that link to the one you are reading. This preview takes
you to the link itself, lists the links a Windows or Mac disk would follow, and
keeps the list current while it is open. An installed 0.1.15 or earlier on
either platform is offered this by **更新を確認**.

## What changed

**Choosing a note from リンク元 lands on the link.** The note opens with the
link's text selected, even when the same words appear earlier on that line.
When the link's text is not on screen as written — a bold or code-formatted
label, an image, a reference definition — the note still opens and the notice
names the line to look at.

**A link in another case counts where the disk ignores case.** On Windows and on
a default Mac volume, `Overview.md` and `overview.md` are the same file, so a
link written either way opens the note; リンク元 now lists it as well. On a disk
that tells them apart, only the exact name counts, as before. irori asks the
disk rather than assuming from the operating system.

**The list keeps itself current.** A note written or changed while リンク元 is
open appears in it, or leaves it, without pressing anything.

## Installing

**Windows 11 x64:** download `irori-0.1.16-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.16-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. The button appears only just after an
attempt to open the app, so if it is missing, open irori again and return to
that pane. Later launches behave normally.

## Verification

The published files are the artifacts of the CI run for the commit named under
**Exact package** below, unchanged except for their download names. Each package
job launches the packaged application from a different path and exercises SDK
imports, save/undo/redo, native clipboard image paste, the CSV graph, Japanese
note and terminal file saves, private drafts, recoverable note deletion after
restart, single-instance ownership and bundled rclone. On macOS 26 it first
verifies the bundle and the copy inside the disk image. Tests use disposable data
and do not run a real model turn.

For this change, behaviour tests cover the label each kind of link carries and
the ones that have none, nested and escaped brackets, lines crafted to stall the
reading, the comparison in one case beside the disk's own answer, and choosing
the link over earlier identical text. An Electron suite sees a note written
while the list is open join it, opens a formatted link with the notice naming
its line, and opens a plain one with its text selected.

## Remaining boundaries

Passing CI is not acceptance on an installed device. Installation, Japanese
input, real CLI accounts, Git operations and Google connections still need device
trials on Windows and the Mac. The case comparison was exercised on a disk that
distinguishes case; the Windows and Mac behaviour follows from the same check
but has not been seen on those disks yet.

A formatted link is named rather than selected. A change more than six folders
deep, or on a disk that reports no changes, reaches the list when it is opened
again. No link is rewritten when a note moves. Source view does not follow
links, a heading after `#` is not scrolled to, and a missing page is not offered
for creation. Google connections remain read-only. Drive uploads, real OpenCode
and Pi model turns, Developer ID signing with notarization, and cross-device
history remain separate work.
