# irori 0.1.85 preview 1 — Fixes where copied code had drifted

This release carries 0.1.82 to 0.1.85, which were not published on their own.
Code that had been copied between files, and whose copies had drifted apart,
now has one definition each. What changes for a reader:

- A file or folder whose name starts with two dots, such as `..notes`, counts
  as inside its folder again, so the irori agent may write it.
- The hibachi agent's message box takes up to 32,000 characters, the limit irori
  checks on sending. It used to take 100,000 and refuse the longer message
  after it was sent.
- A GitHub answer over 64 KB, such as a large saved environment, is read whole
  instead of being cut short and failing.
- Errors on the irori mode map, the model picker, page properties and the file
  viewer no longer read "Error: Error: …", and comment times follow irori's
  language.
- Registering a hibachi while something runs is refused in irori's language.
- In "Not sent to Drive", after "Save to a folder" the buttons come back once
  the save finishes, while the counts are read again.
- A conversation list that fails to reread with the same message as before does
  not report it a second time.

Everything else is unchanged. The details are in the notes for
[0.1.82](0.1.82-preview.1.md), [0.1.83](0.1.83-preview.1.md) and
[0.1.84](0.1.84-preview.1.md), and for the screens below.

## Screens (0.1.85)

The screens had each written their own copy of a few small steps:

- Running an action from a button or form: showing it as busy, showing its
  error and reporting whether it finished, in about twenty dialogs and panels.
- Reading the conversation list, the deleted notes, a note's referring links
  and what Drive left behind, through the shared reader that ignores late
  answers for something no longer shown.
- Saving a device setting, and undoing the choice on screen when the device
  record refuses it, for the theme, Markdown font, language, code assistance
  and each hibachi's agent.
- A file's name and folder from its path, the file entry the window opens from
  a link, a search result or a backlink, the words for an agent's state, the
  short date and time, and sending an instruction with Enter.

## Verification

`npm run build`, `npm test` and all Electron UI suites pass on the combined
change. Unit tests cover the `..` name, a 146 KB GitHub answer with Japanese
text, the shared file replacement, streamed hash, folder walk and PATH lookup,
and the name and folder helpers. The conversations suite now waits for its last
run to end before restarting irori, which had hung CI. Not tried with real CLIs,
a real GitHub account, Windows or macOS.
