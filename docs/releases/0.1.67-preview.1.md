# irori 0.1.67 — Google Drive through Drive for desktop

- irori no longer signs in to Google Drive or bundles rclone. A Drive folder is
  connected as a folder on this computer: install Drive for desktop, then choose
  the folder under **クラウド接続 → フォルダを選ぶ**.
- A Drive connection made before this version shows as **終了** in the connection
  dialog. **フォルダに切り替える** keeps its name and place in contents.
- If files changed in a Drive connection never reached Drive, the start screen
  shows **Drive の未送信分**, and they can be saved to a folder.

See [ADR 023](../decisions/023-retire-drive-sign-in.md).

## Verification

Unit tests cover:

- retired Drive records and switching them to folders;
- the unsent-change export, using rclone 1.75.1's cache layout;
- the folder connection paths: editing in place, drafts, moves, deletion to the
  system trash and pasted images.

The connection UI suite covers the dialog's single folder source, the retired
connection's switch, and the start screen's unsent notice. A real Drive for
desktop folder and installed Windows and macOS builds were not tested.
