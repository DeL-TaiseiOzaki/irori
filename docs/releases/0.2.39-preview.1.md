# irori 0.2.39 preview 1 — text size and line spacing

- **Settings** now has **文字の大きさ** (small, standard, large, larger) and
  **行間** (compact, standard, relaxed) for notes. Headings grow with the text.
  The standard choices look as before.
- Both choices travel with your saved environment, like the font and margins.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/settings.test.ts` keeps both choices across a restart and refuses
values outside them. `markdown-ui-smoke` chooses large text and relaxed spacing
in Settings and measures the paragraph and heading. It checks that a Mermaid
diagram's labels are unchanged, and returns to the standard look.
