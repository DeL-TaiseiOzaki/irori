# irori 0.1.49 — Schema as settings: instructions, skills, rules and hooks

A brain's **Schema** section no longer asks you to find and edit the files
behind it. It lists what your agents follow, and each item opens as a form.
Everything is still saved as the same files, so every CLI reads it as before.

## The Schema section

- **指示** (Instructions): the brain's `AGENTS.md`, and an `AGENTS.md` in any
  knowledge folder, listed by folder.
- **スキル** (Skills): each skill in `.agents/skills`.
- **ルール** (Rules): Claude Code's rules in `.claude/rules`.
- **フック** (Hooks): Claude Code's hooks in `.claude/settings.json`.
- Each group has **＋** to add one. The folder icon in the heading shows the
  files as before, so nothing is out of reach.

## The forms

- **Instructions:** the text. A new one asks for the folder it belongs to.
- **Skill:** name, description, instructions and attached files. Add a file by
  typing its name and content, or import a text file from disk; edit or delete
  it in place. Renaming the skill renames its folder, and settings such as the
  roles and projects a skill is for are kept.
- **Rule:** name and text.
- **Hook:** the event, an optional matcher and the command. Other settings in
  `.claude/settings.json` are kept as they are.
- Every item can be deleted, after a confirmation.
- A file changed elsewhere meanwhile is never overwritten; the form asks you to
  open it again. While the brain's AI or a Git operation is running, the forms
  wait.

## Installing

**Windows 11 x64:** download `irori-0.1.49-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.49-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.

## Verification

- Unit tests cover which paths a setting may write, the skill form's round trip
  (other frontmatter kept), the hooks JSON, and the host on a disposable KB,
  including refusing a folder that leads outside the brain.
- A new Electron smoke drives every form and checks the files on disk: it edits
  `AGENTS.md`, creates a skill with a typed and an imported attached file,
  renames it, creates and deletes a rule, adds a hook beside existing settings,
  and creates a folder's `AGENTS.md`.
- The full build, unit tests and Electron UI suites passed.

## Remaining boundaries

- Hooks are Claude Code's format only; other CLIs' hooks are edited as files.
- Attached files are text only, up to 2 MiB.
- Not yet tried with a real agent run reading a rule or hook written this way,
  nor from an installed macOS or Windows 11 app.
