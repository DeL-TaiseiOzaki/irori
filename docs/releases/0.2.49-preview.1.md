# irori 0.2.49 preview 1 — quieter file and conversation tabs

- The open-file tabs above the page and the conversation tabs in an agent
  column share one plain style. A tab is its name; the one on show is set in a
  heavier weight with a line beneath it, ember in the column being edited and
  for the conversation on show, gray in another stage column. The filled block
  behind the current tab is gone.
- Conversation tabs no longer pick up the outline and padding of ordinary
  buttons, which framed each tab and its close button in a box.
- A tab's close button shows on the tab on show and when the pointer is over a
  tab or the button has keyboard focus. A running conversation still has no
  close button.

## Verification
