# irori 0.2.50 preview 1 — a vault's GitHub repositories in one list

- The Knowledge section of the explorer and the Knowledge card on a vault's
  home have a **GitHub リポジトリとブランチ** button (the branch icon). It lists
  the GitHub repositories the vault is tied to: the vault's own repository,
  each submodule, and each repository connected in contents, with the branch
  checked out (or, for a connection, the branch it records) and where it sits
  in the vault.
- **GitHub で開く** opens that repository's page at the branch shown in the
  browser. A remote that is not on GitHub is named without the button; a
  submodule or connection not fetched on this computer says so.

## Verification

`npm run build`, `npm test` (`tests/linked-repositories.test.ts`) and
`npm run test:ui` pass. In the CLI test desktop, a vault with a GitHub remote,
a submodule and a GitHub connection in contents listed all three with their
branches, and **GitHub で開く** asked the system to open
`https://github.com/acme/tools/tree/dev` for the submodule. Not tried against
real GitHub repositories or on macOS or Windows.
