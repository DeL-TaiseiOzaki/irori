# irori 0.2.50 preview 1 — the page first, and colours that mean one thing

- The note is the subject of the window. The page is the only lit surface; the
  vault panel, the agent columns, the rail and the status bar sit flat around
  it, joined by thin lines that are also the resize handles. The floating
  panels, their rounded corners and shadows are gone.
- Each colour has one meaning. Orange is irori's mark only. A screen's one
  primary button is solid, without a hue. Blue shows where you are: keyboard
  focus, the column being edited, a chosen option. Running is neutral and
  moves. Amber waits for you (an approval, a conflict, a warning); red is a
  failure or something that cannot be undone. Saved, connected and succeeded
  take no colour.
- Agents are marked with a conversation icon instead of sparkles; skills have
  their own icon. Glows, halos, shimmer, floating map nodes and the dotted map
  are gone, and an empty conversation no longer offers ready-made requests.
- A vault's home reads in order: the changes waiting to be committed, with a
  button to review and commit them, then the notes; the run records, the
  Schema and the contents sit quieter beside them. The start screen is one
  column: open a workspace, combine vaults, add a vault — and on a first
  launch, adding a vault comes first.
- Real data holds up: counts in badges stop at 99+, two open files with the
  same name show their folders on their tabs, long names and paths are cut with
  an ellipsis and keep their full text as a tooltip, and a workspace that lost
  a vault says so.
- The start screen, the website and the READMEs say **irori - IDE for Second
  Brain**.

## Verification

`npm run build`, `npm test` (new `tab-labels` and `display-counts`) and
`npm run test:ui` pass; `npm run build:website` and `npm run test:website`
pass. The main screens were inspected in the hearth, dark and light themes in
both languages with `scripts/ui-screens.ts`, and with a disposable fixture of
long and duplicate names, a lost vault and 150 changes.
