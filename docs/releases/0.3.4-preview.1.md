# irori 0.3.4 preview 1 — Astryx's buttons

The second stage of bringing in [Astryx](https://github.com/meta/astryx)'s
design ([ADR 076](../decisions/076-astryx-design-system.md)): irori's buttons
are now Astryx's own. Every button does what it did before.

- **Buttons.** Primary actions, secondary buttons, quiet text buttons and icon
  buttons across the window, the vault home, the settings, Git, routines, the
  agent columns and irori mode are Astryx's buttons. They take its sizes, its
  press feedback and its focus ring.
- **Hints.** An icon button that had no hover hint now shows its name as one.
- **Not yet.** Text fields, switches, checkboxes, segmented choices, badges
  and menus keep their current look. They follow in the next stages.

## Verification

The Electron UI smokes find buttons by role and name.
- **Linux run against this build.** 42 of the 43 smokes pass. The other one
  stops at the system trash, which that host lacks; it fails the same way on
  0.3.3.
- **Screens.** The main screens were rendered in hearth, light and dark and
  looked at.
- **Pull request CI** runs the whole set, and `npm test` and `npm run build`,
  on its own machines.
