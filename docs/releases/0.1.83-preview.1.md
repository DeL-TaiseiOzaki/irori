# irori 0.1.83 preview 1 — One copy of the host's file checks

irori behaves as before. Checks the host had written out several times now
have one definition each:

- Saving a note, writing the graph index and writing a Schema setting replace
  the file the same way: a temporary file beside it, the hash checked again
  before it takes the file's place.
- Making the folders on the way to a new note or Schema file, refusing an
  alias anywhere on the path.
- Reading an optional declaration such as `.irori/notes.json`, the text size
  limit, the check for text that is not UTF-8 or holds NUL, and finding a
  program on the PATH.
- The checks that wait for runs, Git and connections before a note is moved,
  deleted or restored, a folder renamed or the graph index updated.

The one visible change: the message shown when a hibachi is registered while
something is still running is now in irori's language, as the others are.

## Verification

The type check, the format check and the unit tests of every changed module
pass. New unit tests cover the shared replacement, streamed hash, folder walk
and PATH lookup, including a file that changes while it is hashed.
`npm run build`, `npm test` and all Electron UI suites pass. Not tried on
Windows or macOS.
