# irori 0.2.74 preview 1 — Drag a workspace tab out to open it in a new window

- With two or more workspaces open as tabs, drag one below the tabs, or off the
  window, and let go: it opens in a new window there, on the vault, view and
  level it showed ([ADR 063](../decisions/063-tab-out-to-a-new-window.md)).
- Nothing of the workspace stops. The window it left shows its next tab at
  once and lets go of the moving tab only when the new window shows it; if
  that window cannot, the tab stays and the window says so.
- When the tab on show has a terminal open, irori asks first and closes it, as
  when switching tabs.
- Let go within the tabs, nothing changes. A window's only tab stays.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb; the
windows smoke drags a tab out with the mouse and checks that the new window
shows it on its vault and that the first window no longer has it. Not tried on
macOS or Windows, where the pointer leaving the window is the system's.
