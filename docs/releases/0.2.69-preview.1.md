# irori 0.2.69 preview 1 — unregistered data removable from any vault's connection sheet

- **ゴミ箱に移動** and **リンクを削除** for a vault's unregistered data, and
  the controls of its registered connections, stayed disabled when the
  connection sheet was opened for one vault while an agent ran in another,
  such as from the Overview. The sheet now follows the runs of the vault it is
  for, including the irori agent's hold on a vault handed to it.
- While an agent does run in that vault, the sheet says that connections
  cannot be changed or removed, nor unregistered data removed, until the run
  ends. Before, the buttons were disabled with no reason given.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb.
`scripts/overview-ui-smoke.ts` opens Product's connection sheet from the
Overview while Research's agent runs and finds **ゴミ箱に移動** enabled; it
was disabled on 0.2.68. `scripts/harness-ui-smoke.ts` finds it disabled with
the note during the vault's own run, and enabled without the note after the run
is stopped. Not tried on macOS or Windows.
