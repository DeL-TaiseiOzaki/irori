# irori 0.1.88 preview 1 — Settings on the start screen

The start screen has **設定** beside the language switch. It opens the same
settings as the rail, without opening a workspace first: the theme, Markdown
font, language, hibachi agent, routines and the **アカウント** section. A new
device can now check which GitHub account the GitHub CLI is signed in to and
**環境を保存** before any workspace exists. The save still covers every
workspace on the device, not only an open one.

Schema stays in a workspace's settings, and updates stay in the start
screen's footer.

Restoring the environment from the start screen now also takes the restored
hibachi agent choice into the window at once.

## Verification

`npm run build`, `npm test` and the Electron UI suites pass. The account smoke
saves the environment from the start screen's settings, checks that they leave
out Schema and updates, and then finds the saved state in the rail's settings
of the opened workspace; the language smoke checks the start screen's settings
in English. Not tried with Windows, macOS or a real GitHub account.
