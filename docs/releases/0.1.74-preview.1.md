# irori 0.1.74 — a wider irori agent in irori mode

- In irori mode, the irori agent beside the map and the routines can be
  widened or narrowed by dragging the gap to its left, like the agents beside
  a hibachi. The width stays on this device.

## Verification

The irori agent Electron UI suite drags the handle, sees the island widen and
finds the width saved with the device's layouts. The Overview, routines and
dock suites passed unchanged.
