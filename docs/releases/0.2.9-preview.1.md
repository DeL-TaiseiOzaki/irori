# irori 0.2.9 preview 1 — Two vaults side by side

A second vault can now stand beside the first, and files move between their
knowledge by drag and drop ([ADR 038](../decisions/038-vaults-side-by-side.md)).

- **Open a vault beside** in the vault panel's header opens another vault of
  the workspace next to it. Its name chooses a different vault; × closes it.
- Drag a note, file or folder from one Knowledge onto a folder of the other to
  move it. When links between it and the notes that stay would break, irori
  says how many and asks first. Images pasted into a note go with it, as do its
  comments.
- Opening a file in the vault beside brings that vault to the main panel, and
  the two trade places.
- A workspace tab remembers the vault beside.

Not yet: moves between vaults from the `irori` command, and carrying material
IDs or the record of human-written lines.

## Verification

`npm run build`, `npm run format:check`, `npm test` and `npm run test:ui` pass.
The new `vault-split-ui-smoke` opens a vault beside, swaps it from its menu,
drags notes both ways, cancels and then confirms a move that breaks a link,
checks that the note's image moved and renders, and opens a note beside.
`tests/vault-move.test.ts` covers the link count, images, comments, drafts,
folders and refusals.

Not tried on Windows or macOS, or between volumes.
