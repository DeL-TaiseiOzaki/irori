# irori 0.2.33 preview 1 — skills for Claude Code

- Claude Code now sees the skills irori keeps in `.agents/skills`: a vault's own,
  the irori agent's, and the shared Schema's. Before, Claude Code read only
  `.claude/skills`, so it did not list skills made in irori's settings.
- For each Claude Code run, irori makes a folder of links to those skills in its
  data directory and gives it to Claude Code. The links go when the run ends, and
  nothing is written into a vault.
- The skill reach view shows "irori が渡す" for Claude Code.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/claude-skills.test.ts` checks, with a Claude Code stand-in, which skills
are linked, that a vault's own skill wins a shared name, that `.claude/skills`
names are left alone, and that the links go with the run. It covers both a vault
agent and the irori agent.

A real Claude Code 2.1.295 in standard mode listed and ran a vault skill and a
shared skill, the second time in a resumed session. Not tried on Windows, where
the links are junctions.
