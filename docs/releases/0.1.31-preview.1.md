# irori 0.1.31 — Readable dialogs in the dark theme, and connecting an opened Drive folder

In the dark theme, the cloud connection dialog and the other setting dialogs
drew the theme's light text on a fixed white panel, so headings, labels and
folder names could hardly be read. Every dialog panel now takes the theme's own
surface and text colours, and the device-transfer recovery dialog gains the
panel it was missing.

Connecting a Google Drive folder no longer depends on finding a small radio
button. After opening a folder with **開く**, press **「フォルダ名」を接続先にする**
to choose that folder itself; the chosen row is highlighted, the connect form
scrolls into view and names the folder it will connect, and a hint explains
where the connect button appears before anything is chosen.

## Installing

**Windows 11 x64:** download `irori-0.1.31-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.31-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. The button appears only just after an
attempt to open the app, so if it is missing, open irori again and return to
that pane. Later launches behave normally. Keep irori in **アプリケーション**:
the in-app update replaces the app where it is.

## Verification

The published files are the artifacts of the CI run for the commit named under
**Exact package** below, unchanged except for their download names. The cloud UI
test now opens a shared-drive folder, connects it with the new button, checks
the stored provider identifiers, and measures the dialog's text contrast in the
light and dark themes. With the previous stylesheet the dark theme measured
1.26:1; it must now exceed 4.5:1.

## Remaining boundaries

Passing CI is not acceptance on an installed device. Mounting a real Google
Drive folder still needs a device trial on Windows (WinFsp) and the Mac.

Read [the distribution notes](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/DISTRIBUTION.md)
and [the full release plan](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/RELEASE-PLAN.md).
Report the displayed version, OS and exact error through
