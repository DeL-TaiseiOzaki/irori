# irori 0.2.32 preview 1 — several windows

irori now opens in more than one window
([ADR 051](../decisions/051-multiple-windows.md)).

- **ファイル > 新しいウィンドウ** (Ctrl/Cmd+Shift+N), or the Dock menu on macOS,
  opens another window. Each window has its own workspace tabs.
- What another window has open stays open: closing a tab or a window stops only
  the agents and terminals no other window has, and the start screen does not
  remove a workspace open in another window.
- Closing a window while others stay open asks first when its own agents or
  terminals run. Closing the last window or quitting works as before.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. The new
`windows-ui-smoke` opens a second window from the menu, checks that each window
keeps its own tabs and that the workspace open in the first cannot be removed
from the second, then closes the second and checks that the first window's
terminal still runs. `tests/workspace-tabs.test.ts` covers what each window has
alone; `tests/harnesses.test.ts` sends a queued instruction from two requests at
once. Not tried on Windows or macOS, or with a run stopping when its window closes.
