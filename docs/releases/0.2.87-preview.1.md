# irori 0.2.87 preview 1 — Read files in irori mode

Files can now be read in irori mode while the irori agent's columns stay on
show ([ADR 068](../decisions/068-reading-files-in-irori-mode.md)).

- **ファイル**, after マッピング and 並列, shows a vault's Knowledge and Contents
  trees and the file chosen there. The vault's name above the trees chooses
  another vault of the workspace.
- In irori mode and on the routines page, a path in a reply and a hit of the
  workspace search open there instead of in the vault, at the line or hit.
- The file is read only. It follows changes on disk, so an agent's edits show
  as they are made. **vault で編集** opens it in its vault to edit.
- A workspace tab remembers the layout and the file.

A path in the irori agent's own folder still opens on its screen, and a vault on
the map still opens the vault.

## Verification

`npm run build` and `npm test` pass. `overview-ui-smoke` and
`your-ai-ui-smoke` now cover the files view; they were not run on the
development machine, which has no display server or Electron libraries, and
are left to CI. Not tried on Windows or macOS.
