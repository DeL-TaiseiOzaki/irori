# irori 0.2.47 preview 1 — leftovers in Contents can be registered or removed

- An item in a Contents folder that no connection names now shows as
  **Unregistered** in the explorer instead of **Not connected**. This happens
  when a connection's record goes while its link stays: it was unregistered on
  another computer, a Git pull or checkout replaced `.irori/local-folders.json`,
  or it was unregistered here after the vault had moved.
- The connection dialog lists these items under **Unregistered**. A link can be
  **registered as a connection** under its own name: to the folder it leads to,
  or, when that folder is gone, to a folder you choose. **Remove link** deletes
  only the link, never the folder it leads to. Anything else there can be moved
  to the system trash.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/local-folders.test.ts` covers listing a link whose record went,
registering it again through the same link, registering a link to a missing
folder to a chosen one, removing a link without touching its folder, and moving
anything else to the trash. `cloud-ui-smoke` leaves two links without records,
registers one from the dialog and connects it, and removes the other.
