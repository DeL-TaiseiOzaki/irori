# irori 0.1.68 — agents find files in connected folders

- A hibachi agent's request now names the folders connected in the hibachi's
  contents, and the irori agent hears them for each hibachi it is handed.
  A connected folder appears through a link, and searches that walk the whole
  hibachi (ripgrep, the CLIs' file search) skip links. Agents are told to name
  the folder's path or follow links when they search there.

See [ADR 019](../decisions/019-local-folder-connections.md) and
[ADR 023](../decisions/023-retire-drive-sign-in.md).

## Verification

ripgrep 15.2 skips a linked folder when it searches or lists the hibachi
(`rg PATTERN`, `rg --files`). It finds the folder's files when the link is
named (`rg PATTERN contents/<name>`) or with `rg -L`. Unit tests cover the
wording, the list of connected folders, and a Codex protocol fixture whose
requests carry it. A real Claude Code or Codex search in a Drive for desktop
folder was not run.
