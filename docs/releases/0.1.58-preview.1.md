# irori 0.1.58 — comments on notes

Any Markdown file in a hibachi can now take comments, and the hibachi agent and
the irori agent read them.

## What changed

- **コメント** in the note's bar shows how many comments the file has. Select
  text first to comment on that passage, or comment on the whole note. Choosing a
  comment's quote selects the passage in the note; **解決** removes the comment.
- Comments are kept in the hibachi as `.irori/comments/<file path>.json` and are
  committed with it, so they reach other devices and collaborators through Git.
  The note itself is not changed.
- **hibachi agent**: an instruction sent with a commented note carries its
  comments. Otherwise the agent is told how many comments the hibachi holds and
  where they are.
- **irori agent**: the hibachis handed to it are listed with how many comments
  each carries and where they are kept.
- Moving a note moves its comments.

## Installing

**Windows 11 x64:** download `irori-0.1.58-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.58-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.

## Verification

- The full build, unit tests and Electron UI suites passed, including a new
  comments suite.

## Remaining boundaries

- Not yet tried with a real CLI agent reading the comments.
- Passages are not highlighted in the editor; Drive files take no comments.
- Not yet looked at in an installed macOS or Windows 11 app.
