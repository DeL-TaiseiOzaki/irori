# irori 0.2.93 preview 1 — A routine's latest 3 runs

- An opened routine's history now lists only its latest 3 runs, each with its
  **成功** / **失敗** state. irori still keeps the last 20 runs of each routine
  on the device ([ROUTINES](../ROUTINES.md)).

## Verification

`npm run build` passes. On Linux under Xvfb, `scripts/routines-ui-smoke.ts`
runs a routine four times and checks that its history lists 3 runs with the
newest selected. Not tried on macOS or Windows.
