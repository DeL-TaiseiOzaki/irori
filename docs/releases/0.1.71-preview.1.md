# irori 0.1.71 — the irori agent sets up your hibachis

- Give the irori agent your GitHub repositories and it makes them hibachis:
  it clones each one, registers it, and adds it to the workspace you are in.
  It can also start a new hibachi, register a folder you already have, and
  connect a synced cloud folder (Google Drive for desktop, OneDrive, Dropbox)
  to a hibachi's contents.
- It does this with an `irori` command irori gives it on every CLI. The
  command only adds; it never removes or replaces a hibachi, a workspace or a
  file.
- A new irori agent folder comes with four standard skills for this work:
  `irori-setup`, `add-hibachis`, `new-hibachi` and `connect-folder`. For a
  folder set up before, the + beside Schema on the irori agent's screen adds
  the ones it lacks and leaves your own edits alone.

## Verification

Unit tests cover the command's forms, cloning from a local stand-in for
GitHub, creating and adding hibachis into the request's workspace while runs
are in progress, connecting a folder, the launcher, the standard skills, and
the irori agent on Pi's protocol fixture registering a folder. The irori agent
Electron UI suite now registers a folder through the command and sees it in
the rail and the map. Real CLIs, a real GitHub clone and installed Windows and
macOS builds were not run.
