# irori 0.2.41 preview 1 — notes edited as pages, footnotes and all

- A paragraph, a list or a table with a footnote `[^name]` or a wiki link
  `[[page|label]]` stays as it is shown while you edit it. Before, clicking it
  turned the whole block into Markdown source.
- Footnote marks and wiki links are small pieces of the text, as mentions are
  in Notion: typing `]]` or `]` turns what you typed into one, a double click
  opens it as its text again, and Backspace removes it whole.
- Footnotes at the end of a note are edited as text, their names beside them.
  A callout `> [!note] Title` shows its kind and title and is edited as text.
- Code blocks are a quiet rounded panel; the language and copy buttons appear
  on hover. Quotes are a thin rule beside the text.
- An edit writes lists and dividers the way the note already does (`-` stays
  `-`). The file keeps every footnote mark and link exactly as written. Math,
  HTML and other Markdown the editor cannot write back still show their source
  when you click them.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/editor-pieces.test.ts` reads lists, tables, paragraphs, definitions and
callouts into pieces and writes them back unchanged, keeps math, HTML,
directives and escaped links literal, and reads a note's bullet and divider
style. `markdown-ui-smoke` types into a list item and a table cell with
footnotes without any source showing, types a wiki link and a footnote mark,
edits a mark by double click, and saves the exact text. `comments-ui-smoke`
quotes a passage across a footnote mark as the file writes it.
