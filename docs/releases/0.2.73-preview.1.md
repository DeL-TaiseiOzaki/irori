# irori 0.2.73 preview 1 — SSH hosts chosen from your ssh configuration

- **設定 → vault の場所 → SSH ホスト** lists the hosts your own ssh
  configuration names, under **ssh の設定にあるホスト**, as VS Code's Remote-SSH
  does. **追加** adds one under its name; nothing is typed.
- Where a vault is added (**SSH ホストから** on the start screen, **SSH ホスト**
  in the dialog), choosing such a host adds it, connects and shows its folders
  in one step.
- irori reads `~/.ssh/config`, the files it includes and the system's file
  (`/etc/ssh/ssh_config`; `%ProgramData%\ssh\ssh_config` on Windows), and
  writes nothing there. A host added this way has its `Host` name as its
  destination: `ssh` applies the configuration at each connection, so a later
  change to the file needs none in irori.
- Listed: each name on a `Host` line, with the address, user and port `ssh`
  would use for it, settings from a pattern such as `Host *` counted in. Not
  listed: a pattern (`*`, `?`, `!`), and a host that only a `Match` line names.
  A file named by `Include` is read as `ssh` reads it: one included inside a
  `Host` block gives only the hosts that block matches.
- More than eight hosts get a field that filters them by name, address or
  user; fifty rows show at a time.
- A host that is not in the configuration is added with **接続先を入力して追加**
  (was **SSH ホストを追加**). That form no longer opens by itself where no
  host is added yet.
- Unchanged: irori connects without answering prompts, so a host that asks for
  a password, a passphrase or a host-key answer must first connect with
  `ssh <name>` in a terminal.

## Verification

`npm run format:check`, `npm run build`, `npm test` (774 tests: 768 pass, the
same 6 skipped as before), `npm run test:ui` (40 Electron smokes) and the
website smokes pass on Linux under Xvfb. `tests/ssh-config.test.ts` compares
what is shown for eight hosts of a configuration with includes and patterns
against `ssh -G` (OpenSSH 9.6). Not tried on Windows or macOS, and not with a
real host chosen from a real configuration.
