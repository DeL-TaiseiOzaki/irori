# irori 0.2.46 preview 1 — files in tabs and columns

- Files opened on the page become tabs. **Open beside** in the page's bar
  splits it into up to four columns, each with its own tabs, as the agent
  columns have ([ADR 052](../decisions/052-stage-columns.md)).
- A file opened from the explorer, a link or search goes to the column you are
  working in. A click in another column saves the note and moves the editing
  there; the other columns show each file as saved and follow its changes.
- Each vault keeps its own columns and tabs while irori runs. Tabs follow a
  renamed or moved file and close with a deleted one.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. The new
`stage-columns-ui-smoke` opens two notes as tabs, opens a column beside, sends
a third note to the focused column, edits it and moves the editor by a click
(the edit is on disk and shows in the other column), closes a tab of the other
column, leaves for another vault and comes back to the same columns, stops at
four columns, and closes the focused column to bring the editor beside it.
`tests/stage-columns.test.ts` covers tab order, splitting, closing and how tabs
follow moved and deleted files.
