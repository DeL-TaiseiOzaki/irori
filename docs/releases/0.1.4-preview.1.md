# irori 0.1.4 — Daily workflow Windows preview

This unsigned Windows x64 testing update improves note editing, the assistant
and source control. Close the earlier app and install
`irori-0.1.4-windows-x64-Setup.exe`. The startup screen and workspace now display
**0.1.4 Preview**, so the running version can be checked directly. Existing KB
folders and account configuration use their existing locations; this update does
not require creating a new workspace or registering the Google client again.

## Changes to try

- Keep editing Markdown as a document after saving. A newly reproduced bug where
  an immediate save followed by undo could leave autosave out of sync is fixed.
  Selection and undo history survive saves.
- Paste an image from the system clipboard, wait for autosave, and reopen the
  note. Native Windows package tests now exercise this exact paste path and the
  resulting relative image asset. PNG, JPEG, GIF and WebP remain supported by the
  image host; the automated clipboard fixture uses PNG.
- Use the quieter **AIに相談** panel. Session continuation/reset and CLI details
  are available under **会話と接続の設定**. References and agent selection sit by the
  composer; live requests and pending instructions remain available.
- Open **ソース管理** beside the document. Stage/unstage with the file-row **＋／−**
  or bulk actions, enter a commit message at the top, and review diffs in the
  center. **ノートに戻る** retains the editor. Pull and Push retain explicit
  confirmation; partially staged content and conflict drafts stay protected.
- This update also delivers the source improvements since 0.1.3: bounded local
  KB body search, record/source/artifact navigation and device-local conversation
  recovery. Restored pending instructions require explicit resumption.

## Remaining boundaries

The owner's exact previously installed version remains unknown. The current
clipboard failure was not reproduced on the tested implementation; passing CI
is not confirmation that the owner's Windows installation or upgrade works.
Please check the displayed version, paste an image and continue writing after
saving on the installed update.

The installer is unsigned, so Windows may display its unknown-publisher warning.
Google connections remain read-only and Windows mounting still needs WinFsp.
The existing compiled Google configuration is retained; package OAuth tests
stop before account consent. Windows 11 IME/upgrade, real Google consent/mounts,
real model acceptance, signing and full cloud delivery remain separate work.
Mac downloads remain unavailable.
