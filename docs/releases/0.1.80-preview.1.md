# irori 0.1.80 preview 1 — A shared Schema for every agent

**Settings → Schema** opens every Schema in one place: a new shared Schema,
the irori agent's and each hibachi's. The shared Schema holds instructions and
skills that every agent irori runs follows — the irori agent, each hibachi
agent and routine steps, on every CLI. irori saves it as files in the irori
agent's folder (`.irori/shared/`), so nothing needs preparing by hand.

Each agent hears the shared Schema with its first request in a session and
again whenever it changes. Where it and a hibachi's own Schema differ, the
hibachi's wins. Shared skills appear in each hibachi's skill menu, marked
(shared).
