# irori 0.3.0 preview 1 — Quieter desktop chrome, crisp paper stage, and faster preferences

- **Calibrated slate-graphite and paper palette.** The hearth theme pairs neutral slate-graphite chrome (`#121417` / `#171a1e`) with clean architectural paper (`#fbfbfa`) on the note stage, removing warm yellowish-cream tints and heavy shadows so the open note remains the single bright focal surface. Light and dark themes and native window controls follow the same calibrated tokens.
- **52 px vector rail and aligned 42 px header grid.** The left rail narrows to 52 px with vector icons for `irori mode` and `Routines` and a single subtle hairline separator. The stage bar, agent column header and session board header align to a unified 42 px height.
- **Explorer folder guides and one-click vault settings.** Expanded folders in `BrainPanel` draw subtle vertical indentation guide lines under parent chevrons, as in VS Code and Obsidian, and local vaults offer a direct settings button in the vault header alongside the menu.
- **Searchable flat Settings sheet (`⌘,` / `Ctrl+,`).** Preferences open and close from the keyboard anywhere outside the terminal, add a live filter across sections, summaries and keywords, and flatten nested navigation frames into clean list rows.
- **Rectilinear controls and clearer empty states.** Circular pill-fill buttons and chat-bubble composer rounding give way to crisp 6–10 px desktop controls, ghost property affordances on notes without properties, consistent agent toggle labels, and actionable empty states across startup, vault home, explorer trees and routines.
