# irori 0.2.27 preview 1 — the window no longer scrolls

- A long conversation whose reply had footnotes could make the whole window
  scrollable: a scroll bar appeared at its right edge, and scrolling moved the
  workspace up and left empty space below. The window now never scrolls;
  footnotes and every other part of the workspace stay inside it.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`scripts/conversations-ui-smoke.ts` opens a long conversation whose last reply
ends with a footnote and checks the window cannot scroll; before the fix the
page was 19,222 px taller than the window.
