# irori 0.1.28 — Show or hide code assistance with one button

The document toolbar now has **コード支援 ON / OFF**. It switches syntax
coloring, line numbers, folding, bracket assistance and available completions
together, both in source files and Markdown code blocks. The choice is saved
on this device and restored after restarting irori.

Toggling assistance keeps the same editor, text and Undo history. Source files
use language support selected from their filename. Plain editing, search,
person-line marks and native agent execution remain available with assistance
hidden. A failed settings write returns the display to its previous choice.

This change does not add full language-server diagnostics or project run
buttons. Their future display can follow the same setting.
