# irori 0.1.78 preview 1 — Remove a hibachi from the start screen

Each hibachi under **hibachi を選んで組み合わせる** on the start screen shows a
trash button when pointed at. It opens the same removal as **hibachi の設定 →
hibachi を削除**, so a hibachi can be removed without opening a workspace. Its
folder stays unless **フォルダもゴミ箱に移す** is checked, and the hibachi
leaves every workspace.
