# irori 0.2.36 preview 1 — the Antigravity CLI

- The **Antigravity CLI** (`agy`) joins Claude Code, Codex, OpenCode, Pi and
  Hermes Agent. Choose it for a vault agent, the irori agent or a routine's
  agent step. Install it, run `agy` once in a terminal and sign in with your
  Google account; irori uses that sign-in.
- Its models come from `agy models`. Each model names its own thinking level,
  so no level is offered.
- Standard access lets it edit files in the vault; commands it was not allowed
  to run are named in the conversation. Full access allows everything.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/harnesses.test.ts` drives a protocol fixture in the shape of records
captured from agy: streaming, tools, a saved and resumed conversation, model,
access, refused actions, failures and a missing sign-in. `harness-ui-smoke`
selects the CLI in the panel and runs a turn. A real signed-in agy turn has not
been tried.
