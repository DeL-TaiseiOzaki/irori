# irori 0.2.13 preview 1 — slides as PowerPoint lays them out, and code files

PowerPoint files made from a company template show as they do in PowerPoint,
and code files open in irori.

- A slide's title and text take the size, weight, colour, font and position
  their template gives them. Titles are no longer cut off at the top.
- A box with an outline and no fill is no longer drawn solid black; a shape
  filled by its style keeps its colour.
- `.py`, `.rs`, `.sh`, `Makefile`, `.gitignore` and any other text file open in
  the editor, highlighted for their language. Archives, programs, media and
  other binary files still open in their application, as does a file whose
  bytes turn out not to be text.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `viewers-ui-smoke`
opens a deck whose title takes its size from the master and checks the size,
that the title is not cut and that an outlined box is unfilled, then opens a
Python file in the editor and hands a non-text file to its application.
Not tried with the owner's deck, on Windows or on macOS.
