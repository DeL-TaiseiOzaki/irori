# irori 0.2.42 preview 1 — copy and paste files, fold properties, delete in Schema

- Files and folders in Knowledge and Contents can be copied, cut and pasted,
  from the right-click menu or with Ctrl/⌘+C, X and V on a row. A paste on a
  folder goes into it; on a file, beside it. A taken name keeps both
  (`table 2.csv`), and the original is never replaced.
- A copy goes anywhere a file can be added: another folder, the other layer,
  or a vault opened beside. A note copied within Knowledge still links where
  the original did; copied into another vault, its pasted images come with it.
- A cut row dims until its paste moves it, the same move a drag makes, with
  links following in Knowledge.
- Files copied in Finder or Explorer paste in with Ctrl/⌘+V, as a drop does.
  Copying in irori also puts the file's full path on the clipboard.
- A page's properties fold under its title and description with one click.
  Folded, they stay folded on every page until opened again.
- Schema's files and folders can be deleted from the right-click menu or with
  Delete, to the system trash. `.irori` and `.git` stay, with everything in them.
- Closing the first of several agent columns closes that column only; the one
  beside it takes its place with its conversation. Before, it closed them all.

Hidden files and aliases inside a copied folder stay behind. Pasting from
Finder or Explorer was checked on Linux with the paste event the system sends;
macOS and Windows are not yet checked on a device, and a folder copied there
may not come through a paste (drop it instead).
