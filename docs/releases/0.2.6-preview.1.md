# irori 0.2.6 preview 1 — English first

A new installation of irori now starts in English. Japanese is one click away:
the start screen offers **日本語**, and **Settings → Language** switches at any
time.

- An installation that already has a language keeps it. In practice that is
  every installation that has saved a setting since the language choice
  arrived in 0.1.33, since each save records the language as well.
- Only an installation that has never saved any setting starts in English
  after this update.

## Verification

`npm run build`, `npm run format:check`, `npm test` and `npm run test:ui` pass.
`language-ui-smoke` now starts a new device in English, switches to Japanese
and back, and checks that both choices survive a restart. The other UI smokes
choose Japanese for their test device before starting.

Not tried on Windows or macOS.
