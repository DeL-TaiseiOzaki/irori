# irori 0.1.0 — Windows testing preview 1

This unsigned Windows x64 installer is published for the owner's Windows 11 / Ryzen 9 trial. It is a development preview; installation on that device, Japanese IME and Windows native-agent/account acceptance are still pending. Start with a disposable folder or a copy of your KB.

## Download and start

1. Install [Git for Windows](https://git-scm.com/downloads/win) if Git is not installed.
2. Download `irori-0.1.0-windows-x64-Setup.exe` from this release and open it. Windows may show an unverified-publisher warning because this preview is unsigned.
3. Create a workspace, add a test KB folder and try creating, editing and saving a Japanese note. Node.js/npm are not required to install irori.
4. To use an agent, separately install and configure its native CLI (Claude Code, Codex, OpenCode or Pi). Provider accounts, terms and usage charges apply. Note editing does not require an AI account.

The installer is for Intel/AMD x64, including Ryzen 9. Windows ARM and Mac downloads are not included in this preview. The app's internal version remains `0.1.0`; `preview.1` identifies this distribution channel without changing the tested binary.

## Included and incomplete

Included: local Markdown rich/source editing and recovery drafts, multiple KBs per workspace, Git review/sync controls, CSV table/source editing, declared ontology graphs with hierarchy/group filtering and note links, and native CLI adapters.

This build has no distributor Google OAuth configuration, so new Google account connections are unavailable. Cloud writes, durable source/artifact provenance, complete account onboarding, signing, upgrades/rollback and full native-device acceptance remain release work. This preview does not waive the full release requirements in [RELEASE-PLAN](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/RELEASE-PLAN.md).

## Support and data

Report installation/startup problems through [GitHub Issues](https://github.com/DeL-TaiseiOzaki/irori/issues), including the version, OS and exact error message. Do not post private notes, credentials or provider transcripts. KB files remain in the selected local folders; when you ask an agent to work, relevant content may be sent to that provider. The download website has no application backend or added analytics; downloads are hosted by GitHub.
