# irori 0.1.93 preview 1 — Ask the irori agent to run a routine

Tell the irori agent "run Daily mail" and it starts the routine, as **実行**
on the routines page does. It can start only a routine you have already
reviewed on this device and not changed since; otherwise it tells you what
to do on the routines page (review it, enter a missing secret).

The agent never sees a routine's secrets. They still go only to the
routine's programs, inside irori. The agent learns that the run started and,
when it checks later, how it ended; never what the programs printed. A
routine's own agent steps cannot start routines, and hibachi agents cannot
start them; ask the irori agent.

## Verification

`npm test`, `npm run typecheck` and `npm run format:check` pass. A host test
runs the command against disposable routines: it is refused while a secret
is missing and before the review, then starts the reviewed routine, whose
program receives the secret while neither the command's report nor
`irori routines` contains it. A change to the routine's files, a routine
step and a request from no workspace are refused. Not tried with a real CLI
agent.
