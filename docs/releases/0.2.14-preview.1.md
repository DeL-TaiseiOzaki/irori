# irori 0.2.14 preview 1 — paths in a reply open the file

A file path in a vault agent's or the irori agent's reply is a link, as in
Claude Code and Codex in VS Code: click it and the file opens on the page.

- Inline code that names a file (`wiki/topic.md`, `note.md:12`) and the links
  Claude Code and Codex write (`[a.md](wiki/a.md#L12)`,
  `[a.md](/path/to/vault/a.md:12)`) both open. With a line number, that line
  is selected.
- A relative path is read from the vault whose agent wrote it; a report from a
  vault agent, from that vault. The irori agent's relative paths are read in
  the vault on show. An absolute path opens in whichever vault of the workspace
  holds it. A path outside every vault stays plain text.
- A file irori cannot show, such as a program or an archive, is shown in its
  folder rather than opened, so a reply never gets to launch a program.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass. `tests/path-links.test.ts`
covers the written forms, which vault a path lands in and which line is
selected. `harness-ui-smoke` has the Pi fixture reply name `note.md` in inline
code and link `second.md` by its absolute path and line, clicks both and checks
that each opens on the page and that line 1 is selected. Not tried with a real
