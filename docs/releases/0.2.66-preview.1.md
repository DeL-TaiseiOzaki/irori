# irori 0.2.66 preview 1 — the ontology is what a vault declares

- **オントロジー** (was **グラフ**) now shows a vault's ontology: the page types and
  relations it declares in `.property/property.json`. Each type is drawn with
  its number of pages, and each relation as a line from the types that may
  carry it to the types it points at. Tables below give the meaning of every
  type and relation and how many pages use each.
- irori applies that declaration to the pages and lists the ones that differ:
  a page with no type or an undeclared one, a required property missing, a
  relation with an undeclared name (with the name to use, when the vault's
  `avoid` list gives one), a relation from a type that may not carry it, and a
  relation that points at the wrong kind of target. Each line opens its page,
  and the list follows the files as they change. Nothing is refused and no page
  is changed.
- A relation can say which types it points at:
  `"about": { "from": "any", "to": ["person", "org", "project"] }`. `"page"`
  and `"url"` still mean any page and a URL.
- irori no longer draws the pages as a graph. It no longer generates or reads
  `ontology/entities.csv` and `ontology/relations.csv`, and no longer reads
  `.irori/ontology.json`. **索引を更新** and `irori index` write the folder
  indexes (`index.md`) only.
- A vault that has an `ontology/` folder from an earlier irori keeps it; the
  view says it is there. Nothing reads it now, so you can delete it and press
  **索引を更新**. CSV files, including ones a declaration used to draw, open as
  tables as before.

Decision and reasons: [ADR 060](../decisions/060-the-ontology-is-the-declaration.md).
Reference: [ONTOLOGY](../ONTOLOGY.md).

## Verification

`npm run build`, `npm run format:check` and `npm test` pass on Linux. New and
rewritten tests cover every kind of difference the check reports, declarations
with and without target types, the pages the walk keeps, the folder indexes and
an `ontology/` folder left alone. The view was exercised in a real Electron
under Xvfb (`scripts/ontology-ui-smoke.ts`): a vault that declares nothing, the
diagram, the tables, a finding that opens its page, the list following a file
changed on disk, and the folder indexes. Not seen on Windows or macOS, and not
tried against a vault in real use.
