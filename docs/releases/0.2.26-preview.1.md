# irori 0.2.26 preview 1 — the shared Schema's settings and the irori agent's files

- **設定 → Schema → 共通** now has rules and hooks too, like the irori agent's
  and a vault's Schema. Shared rules reach every agent with the shared
  instructions; shared hooks run on every Claude Code run irori starts, beside
  the folder's own.
- **環境を保存** also saves the irori agent's files, its Schema and the shared
  Schema among them, in `irori-settings/irori-agent.json`, whether or not its
  folder is a repository. Links and files that do not fit are named in the
  account section.
- **環境を復元** offers the irori agent's files this device lacks. A file irori
  set up and nobody changed gives way to the saved one; a file changed here
  stays, and the restore names it
  ([ADR 048](../decisions/048-shared-schema-settings-and-irori-agent-files.md)).

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/environment.test.ts` saves an irori agent folder that is not a repository
on one device and restores it onto a starter folder, an absent folder and a
folder of other files. `tests/shared-schema.test.ts` and `tests/your-ai.test.ts`
check the shared rules in the request text and the shared hooks passed to Claude
Code, against the protocol fixture. Not tried with a real Claude Code running a
shared hook.
