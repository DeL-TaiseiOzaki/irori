# irori 0.1.70 — your own names for Knowledge and Contents

- **hibachi の設定 → 層** names the Knowledge and Contents layers for each
  hibachi: the name the panels and breadcrumbs show, and the folder on disk.
  Both are kept in the KB's `.irori/scope.json`, so everyone who opens it sees
  the same names.
- Renaming a folder moves it and keeps everything pointing at it: links in the
  hibachi's Markdown files (OKF relations and sources included), comments,
  unsaved drafts, the new-note place, and connected folders, which are linked
  again under the new name. Files that could not be updated are listed.
- A folder that does not exist yet is renamed only in the declaration, so a KB
  can name a folder it already has as its knowledge folder.
- The graph index lives in `ontology/` inside the knowledge folder, whatever
  its name.

## Verification

Unit tests cover shown names, renaming each folder with its links, comments,
drafts, person-line records, note places and connected folders, the refused
names, and the graph index in a renamed folder. The brain-settings Electron UI
suite now renames the Knowledge layer and its folder. Installed Windows and
macOS builds were not run.
