# irori 0.2.29 preview 1 — choosing how much an agent thinks

- Beside the model, each composer has a **思考量** pill: the CLI's default, or a
  level the chosen model takes. Codex and Claude Code list each model's levels
  (a Claude model without effort offers none); Pi offers `off` to `xhigh`;
  OpenCode takes one of the model's variants, typed in. Hermes Agent takes no
  level, so it shows no pill.
- The level is kept like the model: per vault and CLI while the window is open,
  and on the device for the irori agent. A level the newly chosen model does not
  take goes back to the default. Routine agent steps that use the panel's model,
  and `irori call` hand-offs, run at the same level.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/agent-effort.test.ts` reads the levels from Codex and Claude Code
stand-ins and checks that the chosen one reaches `turn/start` and `--effort`;
`tests/harnesses.test.ts` checks Pi's `set_thinking_level`, OpenCode's `variant`
and that Hermes Agent gets none; `scripts/harness-ui-smoke.ts` picks a level for
Pi in the composer. No real model was run at a chosen level.
