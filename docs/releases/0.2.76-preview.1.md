# irori 0.2.76 preview 1 — Drop a workspace tab on another window's tabs to join them

- Drag a workspace tab out of its window and let go on another irori window's
  title bar: it joins that window's tabs where you let go and comes on show
  there ([ADR 064](../decisions/064-tab-joins-another-window.md)). While the tab
  is over that window, its tabs show where it will go.
- A window's only tab can now be dragged too. Let go on another window's tabs,
  it joins them and the emptied window closes; let go anywhere else, nothing
  happens. Its drag says **ほかのウィンドウのタブの上で離す**.
- Nothing of the workspace stops while it moves. If the window it joins has a
  terminal open on the tab it shows, irori asks before switching, as when you
  click another tab.
- With two or more tabs, letting go elsewhere still opens a new window, as in
  0.2.74.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb. The
windows smoke drags a window's only tab onto another window's tabs, checks the
mark shown there, the place it joins and that its window closes, then drops a
tab on the title bar of a window at its start screen where it covers the first
window. Not tried on macOS or Windows, where the pointer outside a window is the
system's.
