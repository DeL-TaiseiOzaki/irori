# irori 0.2.4 preview 1 — Published sooner after each change

Nothing in the application changes in this version. It changes how a preview
is built and published, so a change reaches the download page and the in-app
update sooner after it is merged.

- A release reuses the packages its pull request already tested when they come
  from exactly the source that was merged, instead of waiting for a rebuild.
- The download page is built from the published release itself.
- Packaging runs alongside the checks instead of after them.

If 0.2.2 or 0.2.3 was not published before this version, their changes reach
readers with it; see their notes.

## Verification

`npm run build`, `npm run format:check` and `npm test` pass. The new release
and manifest helpers were checked against the published 0.2.0 and 0.2.1
releases and the CI runs that produced them.
