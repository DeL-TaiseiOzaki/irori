# irori 0.2.60 preview 1 — settings you can find your way around

- Settings now list their parts at the left in four frames: **表示**
  (言語とテーマ, ノートの表示), **エージェント** (共通, irori agent, vault agent),
  **自動化** (ルーティン) and **アカウントと更新**. Choose one and only that
  part shows beside the list. Each entry shows its current value under its
  name, such as 日本語・いろり, ゴシック・16px or オン.
- The irori agent and the vault agent each have a part of their own that says
  what the agent does. The irori agent's part holds its working folder for the
  workspace, its Schema, its screen and, when it is not set up yet,
  **用意する**. The vault agent's part holds the switch, what still runs while
  it is off, and a **開く** for each vault's Schema. **共通** holds the access of
  new conversations and the shared Schema.
- Every setting says what it does on screen. On/off settings are switches that
  say オン or オフ; the chosen option is marked with a check, and フルアクセス in
  the attention colour. Buttons that open another view say **開く** with an
  arrow.
- **ノートの表示** starts with a sample in the note's font, size, line spacing
  and side margins, which changes as you choose. Text sizes show their pixels.
- Turning Python on in **ルーティン** says while uv downloads. **更新** names the
  version you use. An account error shows in a frame with its details folded,
  and in the language you switch to.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass, with the smokes now
choosing a part before its settings. The website builds and its tests pass.
On Linux under Xvfb every part was captured in hearth, light and English, from
the start screen and in a workspace, with the note sample following the text
size and margins and staying in view while the choices scroll. Not yet seen
on a Windows or macOS desktop.
