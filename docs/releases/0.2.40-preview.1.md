# irori 0.2.40 preview 1 — add to a vault while its agent works

- While an agent runs, a vault's notes, folders and files can be added again:
  **ノートを作成**, **新しいフォルダ**, **今日のノート**, dropping files and
  **ファイルを追加…** no longer wait for the run.
- A new folder or GitHub repository can be connected to contents during a run.
- Moving, renaming and deleting, the vault's settings, the graph and changes to
  existing connections still wait for the run, so nothing moves under the agent.

## Verification

`npm run build` and the affected Electron UI smokes pass. `harness-ui-smoke`
checks, during a fixture run, that note and folder creation are enabled, that a
note cannot be dragged, and that the connection sheet's folder picker is
enabled; the same check fails on 0.2.39.
