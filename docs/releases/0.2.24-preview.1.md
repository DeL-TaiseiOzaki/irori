# irori 0.2.24 preview 1 — GitHub repositories in contents

- The connection dialog has a **GitHub** source. Enter a repository's HTTPS or
  SSH URL, then **保存先を選ぶ** to have irori clone it there, or
  **手元のクローンを選ぶ** for a clone you already have. It appears at
  `contents/<name>`, read-only unless you allow editing.
- The vault records only the URL (`.irori/repositories.json`). On another
  computer the connection shows **取得**, which clones it where you choose.
- **最新にする** fetches and moves the branch forward. It changes nothing when
  the clone has uncommitted changes or commits of its own, and says so.
  Commits and pushes stay in a terminal or with an agent.
- Agents do the same with `irori connect <vault> <GitHub URL> --into <folder>`
  or `--existing <clone>`; `irori list` names the repository.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/repository-connections.test.ts` clones, connects, updates and refuses
against a local repository that Git reaches for a github.com URL through
`insteadOf`; `tests/irori-command.test.ts` covers the command and another
computer cloning for the record. Not tried against github.com itself, or on
macOS or Windows.
