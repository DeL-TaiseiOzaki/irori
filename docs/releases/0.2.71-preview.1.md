# irori 0.2.71 preview 1 — Schema's Rules and Hooks without explanatory notes

- The Schema section no longer explains, under **ルール** and **フック**, how
  rules and hooks reach each CLI, which CLIs cannot run which hook events, or
  which other settings run code. irori behaves as before: it still gives rules
  to every other CLI, runs hooks with Claude Code's meaning, and asks before a
  run it cannot fully hook or after such settings change. The guide's Schema
  settings page keeps the explanation.
- The **指示** group still says when the instruction search reached its limit.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb.
Not tried on macOS or Windows.
