# irori 0.1.92 preview 1 — Routines open without a Keychain prompt

On macOS, opening **ルーティン** asked for the login password so irori could
use "irori Safe Storage". Listing secrets checked whether the Keychain key was
usable, and that check reads the key. irori now reads the Keychain only when a
secret is saved or handed to a `run` step. Because the Mac build is ad-hoc
signed, those two actions can still ask once per installed version.

If the Keychain is refused while saving a secret, irori says the device needs
the OS keychain instead of showing Electron's encryption error.

## Verification

`npm test`, `npm run typecheck` and `npm run format:check` pass. A host test
lists secrets with a macOS stand-in store and checks the store was not touched
until a value was saved, and that a refused save is reported as a missing
keychain; it fails without the change. Not tried on a Mac.
