# irori 0.1.59 — prompts in one place

The words irori gives CLI agents now live in one folder, `prompts/`, one file
per situation. Before this, they were spread through the code that sends them.

## What changed

- Each situation has its own file: the hibachis handed to the irori agent,
  the hibachi sub-agent definition, a hand-off, the selected note, the
  person's lines, comments, sources, a skill, a routine step, and the reasons
  a tool call is refused.
- `prompts/README.md` lists every situation, its order in the request, and
  how it reaches the agent.
- Agents receive the same text as in 0.1.58. The one exception is a declined
  question: Claude Code now receives "User declined to answer.", with the
  period Codex already received.

## Installing

**Windows 11 x64:** download `irori-0.1.59-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.59-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.
