# irori 0.2.23 preview 1 — routines run Python

- A routine's program step can be a `.py` file. **Python を追加** on the
  routine's row, or **Python** in 設定 → ルーティン, downloads uv into irori's
  data folder; uv then fetches Python and the packages the script lists in its
  own `# /// script` block. Nothing is installed system-wide.
- The download is checked against the size and SHA-256 pinned in irori for
  each system, and refused if it differs.
- The irori agent's `write-routine` skill mentions Python in a newly set-up
  irori agent folder; an existing skill folder keeps its text.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/python-runtime.test.ts` covers the pinned targets, a download through a
redirect, a changed, longer, plain-HTTP or failed download refused with nothing
kept, and uv.exe from the Windows zip. `tests/routines.test.ts` covers what the
row asks for and the uv command line, and, with the real uv, a PEP 723 script
run with Python fetched into the data folder. The download from GitHub was
tried on Linux x64 only; not tried on macOS or Windows.
