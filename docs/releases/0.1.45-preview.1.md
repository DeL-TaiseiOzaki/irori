# irori 0.1.45 — PDF, Word, PowerPoint and spreadsheets in place

irori now shows the materials that sit beside your notes. Click a PDF, a Word
document, a PowerPoint deck, a spreadsheet or an image in a brain's tree and it
opens on the stage, where a note would, instead of in another app.

## Viewing files

- **PDF** (`.pdf`): every page, fitted to the stage's width. Text can be
  selected and copied. Japanese PDFs whose fonts are not embedded display
  correctly.
- **Word** (`.docx`): the document laid out as pages, with headings, lists,
  tables, pictures, headers and footers.
- **PowerPoint** (`.pptx`): every slide at the deck's own proportions, with text,
  pictures, tables, basic shapes and common charts.
- **Spreadsheets** (`.xlsx`, `.xlsm`, `.xls`, `.ods`): one sheet at a time, with a
  tab for each sheet. Values appear as Excel formats them (dates, thousands
  separators, percentages), merged cells stay merged, and long sheets page by
  200 rows.
- **Images** (`.png`, `.jpg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.avif`).
- The bar above the file shows what it is (pages, slides, sheets or size), zooms
  with **−**, **+** and the percentage (back to fit), and offers
  **外部アプリで開く** (Open in an external app) for editing.
- These files are **view only**: the stage bar shows **表示のみ**, and irori never
  writes to them. When the file changes on disk, or in Drive, the view reloads.
- Links in a document open in your browser. Scripts or other active content in
  a file are never run.
- Files in a connected Google Drive folder open the same way.
- Older formats (`.doc`, `.ppt`) and anything else still open in the external
  application, as before. Files larger than 100 MiB do too.

## Installing

**Windows 11 x64:** download `irori-0.1.45-windows-x64-Setup.exe` and run it. The
installer carries no distribution signature, so Windows shows a warning that the
publisher cannot be verified.

**Mac (Apple silicon):** download `irori-0.1.45-macos-arm64.dmg`, open it, and
drag **irori** into **アプリケーション**. Intel Macs are not supported. The first
launch is refused because the package carries no distribution signature. Open
**システム設定 → プライバシーとセキュリティ**, find irori's blocked notice under
セキュリティ, and press **このまま開く**. Later launches behave normally. Keep
irori in **アプリケーション**: the in-app update replaces the app where it is.

An installed 0.1.29 or later offers this version with **更新して再起動**.

## Verification

- A new Electron suite (`viewers-ui-smoke`) opens a PDF, a Word document, a deck,
  a workbook and an image from a disposable KB. It checks:
  - the Japanese PDF page drawn with pdf.js's bundled CMap, and its text layer;
  - zooming;
  - Word pages and links;
  - the slides and their proportions;
  - sheet values, merges, paging and sheets;
  - that a script, an event handler or a `javascript:` link in a file is never
    carried into the page.
- Unit tests cover which formats open in a viewer, the view-only document and
  its version, the 100 MiB limit, and a Word file read through a Drive folder.
- The full build, unit tests and Electron UI suites passed.

## Remaining boundaries

- These are previews. Complex Word layouts, SmartArt, animations and some
  theme effects in PowerPoint, and cell colours, charts or images in
  spreadsheets are not reproduced. Use **外部アプリで開く** when the exact
  look matters.
- Password-protected PDFs open only in the external application.
- Not yet tried on an installed Windows 11 or macOS device.
