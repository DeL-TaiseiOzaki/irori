# irori 0.2.81 preview 1 — Each workspace keeps its own agent columns

- **The agent dock's columns** now belong to the workspace they were added in.
  Splitting the dock into two columns in one workspace showed two columns in
  every other workspace too. Another workspace now shows its own columns, one
  until you add more there, and coming back to a workspace shows its columns as
  you left them, each with its draft. As before, the columns are not kept
  across a restart, and within a workspace they follow the vault on show.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass on Linux under Xvfb.

- The dock smoke now splits the dock in one workspace, opens a second
  workspace from the tab strip and expects one column there, then returns to
  the first and expects both columns with the second one's draft. Before the
  change it fails with two columns in the second workspace; with it, it passes.

Not tried on macOS or Windows.
