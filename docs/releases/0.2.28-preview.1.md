# irori 0.2.28 preview 1 — deleting a routine

- A routine's editor has **削除**; pressed a second time (**削除する**), it moves
  the routine's folder to the system trash. Its review, its runs and its
  `IRORI_STATE` on this device go with it, so a routine made later in the same
  folder starts unreviewed and without history. A running routine, or a folder
  that is a link or leaves its owner's, is not deleted.

## Verification

`npm run build`, `npm test` and `npm run test:ui` pass.
`tests/routines.test.ts` refuses a running routine, deletes a stopped one with
its review, runs and state, and refuses a link and a missing folder;
`scripts/routines-ui-smoke.ts` deletes a routine from its editor. The trash is
the test environment's; not tried on an installed Windows or Mac build.
