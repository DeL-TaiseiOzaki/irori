## Theme and font

Choose an app theme in **Settings**: **Match system**, **Hearth**, **Light**, or **Dark**.

Markdown fonts include system, sans-serif, rounded, serif, textbook, and monospace. Display changes do not alter the Markdown files.

## Japanese and English

Select **日本語** or **English** under **Language**. This changes irori's interface text. It does not translate your notes or AI instructions.

This documentation site also has an **English / 日本語** switch at the top right. It opens the corresponding section in the same article. The site's theme button is independent of the app's settings.

## Updates and routines

Check for a new version under **Updates** in settings. When one is available, choose **Update and restart**.

To use JavaScript in [routines](routines.md), enable it under **Routines** in settings. Choose the AI CLI, model, and access mode in the [AI panel](agents.md).
