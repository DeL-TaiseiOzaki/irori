## Supported formats

| Format                                 | View            |
| -------------------------------------- | --------------- |
| PDF                                    | Document viewer |
| Word `.docx`                           | Document        |
| PowerPoint `.pptx`                     | Slides          |
| Excel `.xlsx`, `.xlsm`, `.xls`, `.ods` | Spreadsheet     |
| CSV                                    | Table or source |
| Images                                 | Image viewer    |

Office, PDF, and image viewers accept files up to 100 MiB. Rendering may differ from the original application.

## Open materials

Select a file in a hibachi's Contents to open it in the center. [Google Drive](drive.md) materials can open while their connection is available.

PDF and Office viewers are for reading. Edit those documents in their original applications. Markdown materials can be edited in irori when their connection permits writing.

## Use materials in notes

Write [Knowledge notes](notes.md) as you read and leave relative links to the materials. Ask an [AI agent](agents.md) to summarize or organize specific source files.

The agent's access depends on its CLI settings and the connection's state. A disconnected folder cannot be read as though it were connected.
