## Add a comment

1. Open a Markdown note.
2. Select a passage if your comment concerns a particular part.
3. Open **Comments** in the note's bar, enter your text, and choose **Add**.

Without a selection, the comment applies to the whole note.

## Review and resolve

Choose a comment's quote to reveal its passage in the text. If edits have removed the quoted text, the comment shows that it could not be found.

Choose **Resolve** when the work is done. This removes the comment; there is currently no retained archive of resolved comments.

## Share with AI or your team

Comments live in the hibachi's `.irori/comments/` and can be shared through Git. The hibachi agent receives comments on the selected note; the irori agent can see each hibachi's comment count.

Ask [AI](agents.md) to “Read the comments and revise this note.” Comments currently cover Markdown files inside hibachis. Drive files and the irori agent's own folder are not supported yet.
