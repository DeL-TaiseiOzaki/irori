## Add a hibachi

A **hibachi** is one knowledge base. You can open an existing Markdown folder or Git repository in its current location.

There are three ways to add one.

| Method             | Action                                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| Use a local folder | **Open a KB folder**, or **Add hibachi → Existing folder**                   |
| Clone from GitHub  | **Clone from GitHub**, then enter a URL, parent folder, and new folder name  |
| Create a new one   | **Create new**, then choose the parent folder, folder name, and display name |

A new hibachi starts as a Git repository. You can also choose to [publish it to GitHub](git.md#section-4).

## Create a workspace

A workspace is a selection of hibachis to use together. Select them on the startup screen, name the workspace, and choose **Create workspace**.

For example, open personal notes, team meeting records, and organization materials together. Each folder and Git history stays independent. Use [irori mode](irori-mode.md) to see the whole workspace.

## Adjust names and appearance

In **hibachi settings**, change its name, category, icon, and color. Categories are personal, team, organization, or none. Changing appearance does not move files.

Removing a workspace registration leaves your note folders intact. See the [three layers](layers.md) before reorganizing a hibachi's contents.
