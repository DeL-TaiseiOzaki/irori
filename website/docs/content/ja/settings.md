## 設定の見方

アプリの **設定** を開くと、左に項目が枠ごとに並びます。項目を選ぶと、その項目の設定だけが右に表示されます。各項目の名前の下には、いまの値（テーマやフォント、vault agent のオン・オフなど）が出ます。前回開いていた項目は、次に設定を開いたときにも表示されます。

| 枠 | 項目 | 設定すること |
| --- | --- | --- |
| 表示 | 言語とテーマ | 画面の言語とテーマ |
| 表示 | ノートの表示 | Markdown フォント・文字の大きさ・行間・左右の余白 |
| 表示 | 画面に出すもの | アクセス・モデル・ターミナルなど、画面に出す項目 |
| エージェント | 共通 | 新しい会話のアクセス、共通 Schema、この端末の CLI |
| エージェント | irori agent | 作業フォルダ・Schema・irori agent の画面 |
| エージェント | vault agent | vault agent のオン・オフと、各 vault の Schema |
| 自動化 | ルーティン | JavaScript・Python の実行環境 |
| アカウントと更新 | アカウント・更新 | GitHub に保存する環境と、アプリの更新 |

選んだ値はすぐに反映されます。起動画面の **設定** には **更新** がなく（起動画面の下に **更新を確認** があります）、ワークスペースが必要な項目には「ワークスペースを開くと設定できます」と表示されます。

## 言語・テーマ・ノートの表示

**言語とテーマ** で **日本語** または **English** を選びます。変わるのは irori の画面の言葉です。ノートの本文や AI への指示は翻訳されません。テーマは **システムに合わせる**・**いろり**・**ライト**・**ダーク** から選びます。

**ノートの表示** では、Markdown フォント（システム・ゴシック・丸ゴシック・明朝・教科書体・等幅）、文字の大きさ（14〜20px）、行間、左右の余白を選びます。上の見本に、選んだ表示がすぐに反映されます。表示の変更で、Markdown ファイルの内容は変わりません。

このドキュメントサイトの右上にも **English / 日本語** の切り替えがあります。同じ記事の対応する節へ移れます。サイトのテーマは右上のボタンで変えられ、アプリの設定とは独立しています。

## 画面に出すもの

irori の画面には、ノートと会話に使うものだけが出ています。会話のモデル・思考量・アクセスは、指示の入力欄の下にある1つのボタンから開くメニューで選びます。それ以外の開発向けの項目は、**画面に出すもの** でオンにしたものだけが画面に加わります。オンにするとすぐに反映されます。

| 場所 | 項目 | 初期状態 | オフのあいだ |
| --- | --- | --- | --- |
| 指示の入力欄のメニュー | アクセス | オン | 新しい会話は **共通** で選んだアクセスで始まります。フルアクセスの会話では、オフでも表示されます |
| 指示の入力欄のメニュー | モデルと思考量 | オン | 最後に選んだもの（選んでいなければ CLI の既定）で動きます |
| 指示の入力欄 | スキル | オン | 依頼にスキルは添えられません |
| 指示の入力欄 | 人の行を伝える | オフ | 人が書いた行は伝えません |
| 会話の上部 | 列の操作 | オフ | 列を増やすボタンと本文を隠すボタンが出ません。本文を隠しているあいだは、戻すボタンが表示されます |
| ステータスバー | ブランチ | オフ | — |
| ステータスバー | ターミナル | オフ | Ctrl+` で開閉できます。開いているあいだはボタンが表示されます |
| ステータスバー | バージョン | オフ | **更新** で確かめられます |

**すべて出す** ですべての項目を画面に出し、**既定に戻す** で初期状態に戻します。この選択は、GitHub に保存する環境に含まれます。

## エージェント

エージェントの枠は、両方に効く **共通**、ワークスペース全体を受け持つ **irori agent**、各 vault の中で働く **vault agent** に分かれています。

**共通** の **新しい会話のアクセス** で、irori agent と vault agent の新しい会話を **標準** と **フルアクセス** のどちらで始めるかを選べます。初期状態は標準です。フルアクセスを選ぶと、新しい会話のエージェントは承認を求めずにコマンドやファイルの変更を行います。今ある会話のアクセスは変わらず、会話ごとに切り替えられます。ルーティンのステップは、それぞれのステップの設定に従います。この選択はこのパソコンだけのもので、GitHub に保存する環境には含まれません。同じ項目の **共通 Schema** から、すべてのエージェントが従う指示とスキルを開けます。**この端末の CLI** には、各 CLI のバージョンか、見つからないことが表示されます。

**irori agent** では、このワークスペースで irori agent が作業するフォルダを選び、irori agent の Schema と画面を開けます。irori agent をまだ用意していなければ、ここで **用意する** を押せます。

**vault agent** のスイッチで vault agent をオンにします。初期状態ではオフです。オフでは vault agent の列と Schema が隠れますが、irori agent からの依頼とルーティンは、vault の中で CLI をその vault のエージェント設定で実行します。オンのときは、各 vault の Schema をここから開けます。

## 更新とルーティン

**更新** には使っている版が表示され、**更新を確認** で新しい版を確認できます。通知が出たら、**更新して再起動** で更新します。

[ルーティン](routines.md)で JavaScript や Python を使う場合は、**ルーティン** で **JavaScript** や **Python** をオンにします。Python をオンにすると uv をダウンロードし、終わるまで「uv をダウンロードして準備しています…」と表示されます。AI の CLI は[AI パネル](agents.md)の上部で、モデル・思考量・アクセスは指示の入力欄の下のメニューで選びます。
