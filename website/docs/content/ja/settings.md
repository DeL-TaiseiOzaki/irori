## 設定の見方

アプリの **設定** を開くと、左に項目が枠ごとに並びます。項目を選ぶと、その項目の設定だけが右に表示されます。各項目の名前の下には、いまの値（テーマやフォント、vault agent のオン・オフなど）が出ます。前回開いていた項目は、次に設定を開いたときにも表示されます。

| 枠 | 項目 | 設定すること |
| --- | --- | --- |
| 表示 | 言語とテーマ | 画面の言語とテーマ |
| 表示 | ノートの表示 | Markdown フォント・文字の大きさ・行間・左右の余白 |
| 表示 | 画面に出すもの | アクセス・モデル・ターミナルなど、画面に出す項目 |
| エージェント | 共通 | 新しい会話のアクセス、共通 Schema、この端末の CLI |
| エージェント | irori agent | 作業フォルダ・Schema・irori agent の画面 |
| エージェント | vault agent | vault agent のオン・オフと、各 vault の Schema |
| 自動化 | ルーティン | JavaScript・Python の実行環境 |
| vault の場所 | SSH ホスト | vault を置く SSH ホスト（[SSH ホストの vault](ssh-hosts.md)） |
| アカウントと更新 | アカウント・更新 | GitHub へのログイン、Git の作成者、GitHub に保存する環境、アプリの更新 |

選んだ値はすぐに反映されます。起動画面の **設定** には **更新** がなく（起動画面の下に **更新を確認** があります）、ワークスペースが必要な項目には「ワークスペースを開くと設定できます」と表示されます。

## 言語・テーマ・ノートの表示

**言語とテーマ** で **日本語** または **English** を選びます。変わるのは irori の画面の言葉です。ノートの本文や AI への指示は翻訳されません。テーマは **システムに合わせる**・**いろり**・**ライト**・**ダーク** から選びます。起動画面の下にも言語の切り替えがあり、いまと違う言語の名前（**English** または **日本語**）で表示されます。新しくインストールした irori は英語で始まります。

**ノートの表示** では、Markdown フォント（システム・ゴシック・丸ゴシック・明朝・教科書体・等幅）、文字の大きさ（14〜20px）、行間、左右の余白を選びます。上の見本に、選んだ表示がすぐに反映されます。表示の変更で、Markdown ファイルの内容は変わりません。

このドキュメントサイトの右上にも **English / 日本語** の切り替えがあります。同じ記事の対応する節へ移れます。サイトのテーマは右上のボタンで変えられ、アプリの設定とは独立しています。

## 画面に出すもの

irori の画面には、ノートと会話に使うものだけが出ています。会話のモデル・思考量・アクセスは、指示の入力欄の下にある1つのボタンから開くメニューで選びます。それ以外の開発向けの項目は、**画面に出すもの** でオンにしたものだけが画面に加わります。オンにするとすぐに反映されます。

| 場所 | 項目 | 初期状態 | オフのあいだ |
| --- | --- | --- | --- |
| 指示の入力欄のメニュー | アクセス | オン | 新しい会話は **共通** で選んだアクセスで始まります。フルアクセスの会話では、オフでも表示されます |
| 指示の入力欄のメニュー | モデルと思考量 | オン | 最後に選んだもの（選んでいなければ CLI の既定）で動きます |
| 指示の入力欄 | スキル | オン | 依頼にスキルは添えられません |
| 指示の入力欄 | 人の行を伝える | オフ | 人が書いた行は伝えません |
| 会話の上部 | 列の操作 | オフ | 列を増やすボタンと本文を隠すボタンが出ません。本文を隠しているあいだは、戻すボタンが表示されます |
| ステータスバー | ブランチ | オフ | — |
| ステータスバー | ターミナル | オフ | Ctrl+` で開閉できます。開いているあいだはボタンが表示されます |
| ステータスバー | バージョン | オフ | **更新** で確かめられます |

ターミナルは表示中の場所で開きます。vault では、その vault のフォルダで始まるシェルです。irori mode・ルーティン・irori agent の画面では、画面の下に引き出す形で開き、irori agent のフォルダで始まります。このターミナルは vault を表示しているあいだも動き続け、戻ると同じものが開いています。SSH ホストの vault には、まだターミナルがありません。

**すべて出す** ですべての項目を画面に出し、**既定に戻す** で初期状態に戻します。この選択は、GitHub に保存する環境に含まれます。

## エージェント

エージェントの枠は、両方に効く **共通**、ワークスペース全体を受け持つ **irori agent**、各 vault の中で働く **vault agent** に分かれています。

**共通** の **新しい会話のアクセス** で、irori agent と vault agent の新しい会話を **標準** と **フルアクセス** のどちらで始めるかを選べます。初期状態は標準です。フルアクセスを選ぶと、新しい会話のエージェントは承認を求めずにコマンドやファイルの変更を行います。今ある会話のアクセスは変わらず、会話ごとに切り替えられます。ルーティンのステップは、それぞれのステップの設定に従います。この選択はこのパソコンだけのもので、GitHub に保存する環境には含まれません。同じ項目の **共通 Schema** からは、すべてのエージェントに届く指示・スキル・ルール・フックを開けます（irori agent の用意が必要です。[Schema の設定](schema.md)を参照）。**この端末の CLI** には、各 CLI のバージョンか、見つからないことが表示されます。

**irori agent** では、このワークスペースで irori agent が作業するフォルダを選び、irori agent の Schema と画面を開けます。irori agent をまだ用意していなければ、ここで **用意する** を押せます。

**vault agent** のスイッチで vault agent をオンにします。初期状態ではオフです。オフでは vault agent の列と Schema が隠れますが、irori agent からの依頼とルーティンは、vault の中で CLI をその vault のエージェント設定で実行します。オンのときは、各 vault の Schema をここから開けます。

## 更新とルーティン

**更新** には使っている版が表示され、**更新を確認** で新しい版を確認できます。通知が出たら、**更新して再起動** で更新します。

[ルーティン](routines.md)で JavaScript や Python を使う場合は、**ルーティン** で **JavaScript** や **Python** をオンにします。Python をオンにすると uv をダウンロードし、終わるまで「uv をダウンロードして準備しています…」と表示されます。AI の CLI は[AI パネル](agents.md)の上部で、モデル・思考量・アクセスは指示の入力欄の下のメニューで選びます。

## GitHub にログインする

**アカウントと更新 → アカウント** には、GitHub CLI `gh` がログインしている GitHub アカウントが表示されます。irori に独自のログインはなく、`gh` のログインを使います。トークンを保存するのも `gh` で、irori はトークンを読みません。

`gh` がまだログインしていなければ、**GitHub にログイン** を押します。irori が `gh auth login --web` を実行し、8 文字のワンタイムコードを表示します。**コードをコピーして GitHub を開く** を押すと、コードがクリップボードに入り、ブラウザで GitHub のページが開きます。コードを貼り付けて承認すると、irori に戻って何かを押さなくても接続が完了し、アカウント名が表示されます。やめるときは **キャンセル** を押します。コードは 15 分で期限が切れます。ターミナルで `gh auth login` を実行しても同じです。`gh` が入っていなければ、そう表示され、**GitHub CLI を入手** からインストールのページを開けます。同じログインは、起動画面の **GitHub から環境を復元** と、vault を **GitHub に公開** するときにも表示されます。

ユーザー名とメールアドレスだけでは GitHub にログインできません。GitHub は、パスワードや 2 段階認証を GitHub 自身のページでしか受け付けないためです。

### Git の作成者

同じページの **Git の作成者** には、commit に記録される名前とメールアドレス（Git の `user.name` と `user.email`）が表示されます。値はこのコンピューターの Git 全体の設定（`git config --global`）に保存され、irori の外でエージェントやターミナルが作る commit にも使われます。リポジトリ自身に設定がある場合は、そちらが優先されます。

irori から GitHub にログインすると、まだ設定されていない項目に、そのアカウントの名前とメールアドレスが入ります。メールアドレスは、プロフィールで公開しているものがあればそれを、なければ GitHub の非公開アドレス（`<ID>+<ユーザー名>@users.noreply.github.com`）を使います。非公開アドレスでも、commit は GitHub でそのアカウントのものとして表示されます。すでに設定されている項目は変わりません。名前とメールアドレスは書き換えて **作成者を保存** で保存できます。

## 環境を GitHub に保存する

**環境を保存** を押すと、このコンピューターの環境を、そのアカウントの非公開リポジトリ `irori-settings` に保存します。保存は押したときだけ行われ、そのたびに新しいコミットになります。自動では同期しません。

| 保存するもの | 保存しないもの |
| --- | --- |
| GitHub にリモートがある vault（リポジトリ名として）、ワークスペース | GitHub にリモートがない vault、フォルダのパス |
| 表示の設定、vault agent のオン・オフ、irori agent の CLI とモデル、ルーティンの実行環境、**画面に出すもの** | 新しい会話のアクセス、SSH ホスト |
| irori agent のルーティンとファイル（その Schema と共通 Schema を含む） | ノート、会話 |
| ルーティンのシークレット（合言葉を入力したときだけ） | `.env` などの認証情報のファイル |

保存すると、保存済みの環境はこのコンピューターの環境に置き換わります。このコンピューターにない vault やルーティンが外れる場合は、**アカウント** にそう表示されます。外れたものも Git の履歴には残ります。

ルーティンのシークレットは、12 文字以上の合言葉を入力したときだけ保存されます。合言葉で暗号化されるのはシークレットの値だけで、シークレットの名前、ルーティン、irori agent のファイル、vault とワークスペースの名前は暗号化されません。合言葉はどこにも保存されません。復元するときに同じ合言葉を入力します。

別のコンピューターでは、GitHub にログインしてから（上の **GitHub にログイン**）、起動画面の **GitHub から環境を復元**、または **アカウント** の **復元** を押します。取り込むもの（vault、irori agent のファイル、ルーティン、シークレット）を選び、**取得先** を確かめて **復元** を押すと、選んだ vault がそこにクローンされ、ワークスペースが取り込まれます。設定は保存したものに置き換わりますが、それ以外は追加するだけです。このコンピューターにある vault やルーティンは変わらず、irori agent のファイルのうちこのコンピューターで変更したものも残り、結果にその名前が表示されます。
