## テーマとフォント

アプリの **設定** からテーマを選びます。**システムに合わせる**・**いろり**・**ライト**・**ダーク** に対応しています。

Markdown フォントは、システム・ゴシック・丸ゴシック・明朝・教科書体・等幅から選べます。表示の変更で、Markdown ファイルの内容は変わりません。

## 日本語と英語

**言語** で **日本語** または **English** を選びます。変わるのは irori の画面の言葉です。ノートの本文や AI への指示は翻訳されません。

このドキュメントサイトの右上にも **English / 日本語** の切り替えがあります。同じ記事の対応する節へ移れます。サイトのテーマは右上のボタンで変えられ、アプリの設定とは独立しています。

## 更新とルーティン

設定の **更新** で新しい版を確認できます。通知が出たら、**更新して再起動** で更新します。

[ルーティン](routines.md)で JavaScript を使う場合は、設定の **ルーティン** から JavaScript を追加します。AI の CLI・モデル・アクセス設定は[AI パネル](agents.md)で選びます。

## データ利用の確認

**データ利用を確認し直す** を選ぶと、次の接続・実行前に Drive・AI CLI・プログラムのデータ利用説明を確認できます。リセットするのは保存した確認の記録だけです。実行中の仕事は停止せず、Google の許可や CLI のツール権限も変えず、キャッシュや履歴も削除しません。切断と削除の操作は[プライバシーとデータの扱い](privacy.md)を参照してください。
