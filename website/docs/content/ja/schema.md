## 設定を開く

Schema は **設定 → エージェント** で hibachi agent をオンにしたときだけ表示されます。

hibachi の **Schema** にある項目を選ぶと、中央に設定フォームが開きます。各グループの追加操作で新しい項目を作れます。フォルダのアイコンで **ファイルとして表示** に切り替えられます。

| 項目   | 保存するファイル                                |
| ------ | ----------------------------------------------- |
| 指示   | `AGENTS.md`                                     |
| スキル | `.agents/skills/<name>/SKILL.md` と添付ファイル |
| ルール | `.claude/rules/*.md`                            |
| フック | `.claude/settings.json` の `hooks`              |

ルールとフックは Claude Code の仕組みです。すべての CLI で同じように働く設定ではありません。

## スキルを作る・使う

スキルには名前、説明、指示を入れます。名前は小文字・数字・ハイフンで、フォルダ名と一致させます。必要なテキストファイルを添付できます。

AI パネルのスキル選択で選んでから送ると、指示がその依頼に添えられます。役割やプロジェクトが定義されている場合は、それらで絞れます。読めないスキルには **要確認** が表示されます。

## ファイルとして共有する

設定は hibachi 内の普通のファイルなので、[Git](git.md)で共有できます。irori agent の Schema も同じ方法で編集できます。

フックはプログラムを実行する設定です。使う CLI とコマンドの内容を確認してから保存してください。削除操作には確認が表示されます。
