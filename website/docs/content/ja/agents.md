## CLI を選ぶ

irori は Claude Code・Codex・OpenCode・Pi・Hermes Agent・Antigravity CLI（`agy`）を、パソコンに入っている CLI とその認証で動かします。先に CLI をインストールし、その CLI のログインを済ませてください。

AI パネルの上部で CLI を選びます。モデルと思考量は、指示の入力欄の下にあるボタン（使っているモデルが表示されます）から開くメニューで選びます。選ばなければ CLI の既定のモデルが使われます。モデルの候補はインストール済み CLI の一覧に従います。Hermes Agent のモデル名は入力します。各 CLI のバージョンは、設定の **共通** にある **この端末の CLI** で確かめられます。

## vault agent に頼む

vault agent は任意の機能です。**設定 → エージェント → vault agent** でオンにします。オフのあいだ、ノートの横の AI パネルは irori agent です。オフでも、irori agent からの依頼とルーティンは、vault の中で CLI をその vault のエージェント設定で実行します。オンにすると、列の見出しの先頭にあるマークで、その列を **vault agent** と **irori agent** のどちらにするか切り替えられます。vault agent は、画面では vault の名前で「Research agent」のように表示されます。「irori」という名前の vault は irori agent と区別できなくなるので、別の名前にしてください。

ノートを開き、AI パネルに依頼を書いて送ります。vault agent は、その vault の Schema と開いているノートを使って作業します。

例えば「この議事録から決定事項を整理して追記してください」「資料を読み、出典付きのノートを作ってください」と頼めます。変更後は本文と[Git の差分](git.md)を確認してください。複数の vault agent を同時に動かせます。

## アクセスを確認する

新しい会話は **標準** で始まり、CLI の設定に従います。Claude Code と Codex は必要なときに承認を求めます。Pi は承認を求めず、Antigravity CLI は編集を自動で許可します。CLI が対応していれば **フルアクセス** に切り替えられます。会話ごとの切り替えは、モデルと同じメニューの **アクセス** で行います。フルアクセスの会話では、ボタンにその旨が表示されます。アクセスは会話ごとに決まり、切り替えた会話はその後の指示も再起動後もそのアクセスのまま続きます。ほかの会話や新しい会話には移りません。新しい会話を始めるアクセスは[設定](settings.md)の **共通** にある **新しい会話のアクセス** で選べます（初期状態は標準）。利用できるアクセス設定は CLI によって異なります。

フルアクセスでは、エージェントはあなたのユーザーアカウントで読み書きできるものすべてに届きます。`irori` コマンドで vault agent が扱えるのは自分の vault だけですが、この制限は CLI 自身のツールには及びません。読み取り専用の接続も、irori と標準アクセスの Claude Code・Codex のファイル編集に対してだけ読み取り専用で、フルアクセス・シェルコマンド・ターミナル・ほかの CLI からは書き込めます。 フルアクセスの会話は、フック・MCP サーバー・プラグイン・プロジェクトの設定のように確認なしで動く設定も確認せずに使い、使った設定を会話のログに記します。標準の会話では、こうした設定を初めて使うときと変わったときに確認します。

エージェントが読んだノートや接続したフォルダの内容は、その CLI の AI プロバイダーに送られます。

許可や質問はパネルに表示されます。内容を確認して回答してください。作業を止めたいときは **停止** を使います。

## 続けて仕事をする

実行中の依頼に続けて送った指示は送信待ちに入ります。順番や再開の扱いは[会話と履歴](conversations.md)で説明しています。

定型の指示は[Schema のスキル](schema.md)として用意できます。vault をまたぐ仕事は[irori agent](irori-mode.md)に渡してください。

## 指示を書く

指示の入力欄には32,000文字まで入力できます。

空の入力欄で `/` を入力すると、その CLI がこのフォルダで使えるものの一覧が出ます。Claude Code は自分のコマンドとスキルを並べ、ターミナルと同じように実行します。Codex は自分のスキルと、これまでの会話を要約する `/compact`、コミットしていない変更をレビューする（続けて書いた指示に従う）`/review` を並べます。Codex では、指示の中の `$name` でもそのスキルを使えます。矢印キーと Enter で選ぶか、続けて入力して絞り込みます。ほかの CLI では一覧は出ません。

**ファイルを添付**（クリップ）で、指示にファイルを添付できます。1回に10個、1ファイル25 MB までです。入力欄へのドロップや画像の貼り付けでも添付でき、文章なしでファイルだけを送れます。どの CLI にも各ファイルの場所が伝わり、Claude Code・Codex・OpenCode・Pi には画像が画像として渡ります。添付したファイルはこの端末に保存され、会話を削除すると一緒に削除されます。

**音声入力**（マイク）は、指示の入力欄で OS の音声入力（macOS の音声入力、Windows の音声入力）を始めます。irori 自身は録音しません。Linux では表示されません。

## 質問への回答とファイルのリンク

エージェントが質問すると、各選択肢がその意味と一緒に表示されます。複数を選べる質問はチェックボックスになり、CLI が認めていれば **その他** で自分の言葉で答えられます。1つだけ選ぶ質問が1問のときは、選んだ時点で回答が送られます。MCP サーバーからの質問も、Claude Code と Codex を通して同じように表示されます。

返答の中のファイルパスを押すと、そのファイルが開きます。`note.md:12` のように行があれば、その行で開きます。`topic.md` のような名前だけのものは、ワークスペースの vault、その接続先と作業フォルダ、irori agent のフォルダから探し、複数見つかればそれぞれを候補に出します。プログラムやアーカイブのように irori で表示できないファイルは、開かずに OS のファイルマネージャーでフォルダを示します。これらのフォルダの外を指すパスは、見つからないと表示されます。

## `irori` コマンドと作業フォルダ

vault agent は、自分の vault に対して `irori` コマンドを使えます。ノートを移動・名前変更する（ノートへのリンクとコメントも追従します）、ノートを irori のゴミ箱に入れる、あなたへの[コメント](comments.md)をエージェントの名前で残して解決する、索引を更新する、vault の名前・分類・色・アイコン・層・接続・作業フォルダを変える、といった操作です。エージェントがフォルダを接続するときと作業フォルダを変えるときは、irori があなたに確認します。

vault の登録・グループ分け・削除とルーティンの実行は[irori agent](irori-mode.md)が受け持ちます。シークレットの値、ルーティンの初回の確認、アカウント、アップデートはあなたが扱います。

各 vault には作業フォルダがあり、エージェントは一時ファイル・途中の結果・ダウンロード・試しのスクリプトを、OS の一時フォルダではなくここに置きます。既定は vault の contents の中の `work` で、Git の管理から外れ、Contents に `work` として表示されます。irori agent も、仕事を渡した vault の作業フォルダに書き込めます。この端末の別のフォルダを使うには、**vault の設定** の **作業フォルダ** で **フォルダを選ぶ** を押します。**既定に戻す** で元に戻り、**開く** で OS のファイルマネージャーにフォルダを開きます。
