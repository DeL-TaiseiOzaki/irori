## CLI を選ぶ

irori は Claude Code・Codex・OpenCode・Pi・Hermes Agent を、パソコンに入っている CLI とその認証で動かします。先に CLI をインストールし、その CLI のログインを済ませてください。

AI パネルで CLI を選び、モデルを選択します。モデルの候補はインストール済み CLI の一覧に従います。Hermes Agent のモデル名は入力します。

## hibachi agent に頼む

hibachi agent は任意の機能です。**設定 → エージェント** でオンにします。

ノートを開き、AI パネルに依頼を書いて送ります。hibachi agent は、その hibachi の Schema と開いているノートを使って作業します。

例えば「この議事録から決定事項を整理して追記してください」「資料を読み、出典付きのノートを作ってください」と頼めます。変更後は本文と[Git の差分](git.md)を確認してください。複数の hibachi agent を同時に動かせます。

## アクセスを確認する

CLI が対応していれば、hibachi agent は **フルアクセス** で始まります。**標準** に切り替えると、CLI の設定と必要なときの承認に従います。利用できるアクセス設定は CLI によって異なります。

許可や質問はパネルに表示されます。内容を確認して回答してください。作業を止めたいときは **停止** を使います。

## 続けて仕事をする

実行中の依頼に続けて送った指示は送信待ちに入ります。順番や再開の扱いは[会話と履歴](conversations.md)で説明しています。

定型の指示は[Schema のスキル](schema.md)として用意できます。hibachi をまたぐ仕事は[irori agent](irori-mode.md)に渡してください。
