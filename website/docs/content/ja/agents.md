## CLI を選ぶ

irori は Claude Code・Codex・OpenCode・Pi・Hermes Agent・Antigravity CLI（`agy`）を、パソコンに入っている CLI とその認証で動かします。先に CLI をインストールし、その CLI のログインを済ませてください。

AI パネルで CLI を選び、モデルを選択します。モデルの候補はインストール済み CLI の一覧に従います。Hermes Agent のモデル名は入力します。

## vault agent に頼む

vault agent は任意の機能です。**設定 → エージェント** でオンにします。オフにしても、irori agent からの依頼とルーティンは、vault の中で CLI をその vault のエージェント設定で実行します。画面では vault の名前で「Research agent」のように表示されます。「irori」という名前の vault は irori agent と区別できなくなるので、別の名前にしてください。

ノートを開き、AI パネルに依頼を書いて送ります。vault agent は、その vault の Schema と開いているノートを使って作業します。

例えば「この議事録から決定事項を整理して追記してください」「資料を読み、出典付きのノートを作ってください」と頼めます。変更後は本文と[Git の差分](git.md)を確認してください。複数の vault agent を同時に動かせます。

## アクセスを確認する

新しい会話は **標準** で始まり、CLI の設定に従います。Claude Code と Codex は必要なときに承認を求めます。Pi は承認を求めず、Antigravity CLI は編集を自動で許可します。CLI が対応していれば **フルアクセス** に切り替えられます。アクセスは会話ごとに決まり、切り替えた会話はその後の指示も再起動後もそのアクセスのまま続きます。ほかの会話や新しい会話には移りません。新しい会話を始めるアクセスは[設定](settings.md)の **新しい会話のアクセス** で選べます（初期状態は標準）。利用できるアクセス設定は CLI によって異なります。

フルアクセスでは、エージェントはあなたのユーザーアカウントで読み書きできるものすべてに届きます。`irori` コマンドで vault agent が扱えるのは自分の vault だけですが、この制限は CLI 自身のツールには及びません。読み取り専用の接続も、irori と標準アクセスの Claude Code・Codex のファイル編集に対してだけ読み取り専用で、フルアクセス・シェルコマンド・ターミナル・ほかの CLI からは書き込めます。

エージェントが読んだノートや接続したフォルダの内容は、その CLI の AI プロバイダーに送られます。

許可や質問はパネルに表示されます。内容を確認して回答してください。作業を止めたいときは **停止** を使います。

## 続けて仕事をする

実行中の依頼に続けて送った指示は送信待ちに入ります。順番や再開の扱いは[会話と履歴](conversations.md)で説明しています。

定型の指示は[Schema のスキル](schema.md)として用意できます。vault をまたぐ仕事は[irori agent](irori-mode.md)に渡してください。
