## アプリを起動できない

Windows 11 の x64 版、または Apple Silicon Mac の配布版かを確認します。検証版は未署名なので、初回の操作は[インストール](installation.md)を参照してください。

すでにインストールできている場合は、表示されたエラーとアプリのバージョンを記録します。データを消してやり直す前に、下の報告先へ状況を送ってください。

## AI が使えない

使う CLI がターミナルから起動でき、認証が済んでいるか確認します。irori はその CLI を使うため、アプリだけを入れても CLI は追加されません。

パネルに許可や質問が残っていれば回答します。送信待ちが停止しているときは **送信を再開** を使います。モデルとアクセス設定は[AI エージェント](agents.md)、再開の条件は[会話と履歴](conversations.md)を参照してください。

## 保存や Drive の接続に困った

保存の競合は、別のアプリや AI が同じファイルを書き換えていないか確認します。相手の内容と下書きを見比べ、必要な文章を残してから解決します。

Drive は接続状態、アカウントの認証、書き込み権限を確認します。Windows では WinFsp が必要です。送信待ちがあれば理由を確認し、復旧後に再接続します。未送信の変更がある間に接続の保存データを削除しないでください。[Google Drive](drive.md)の手順も参照してください。

## 不具合を報告する

[GitHub Issues](https://github.com/DeL-TaiseiOzaki/irori/issues)に、次の情報を添えます。

- irori のバージョンと OS
- 実行した操作と、期待していた結果
- 実際に表示されたメッセージ
- 再現するかどうか

ノート本文、認証情報、OAuth の URL は載せないでください。既知の確認範囲は[実装状況](https://github.com/DeL-TaiseiOzaki/irori/blob/main/docs/STATUS.md)にあります。
