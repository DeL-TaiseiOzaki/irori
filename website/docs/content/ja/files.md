## 対応する形式

| 形式                                   | 表示             |
| -------------------------------------- | ---------------- |
| PDF                                    | 文書ビューア     |
| Word `.docx`                           | 文書             |
| PowerPoint `.pptx`                     | スライド         |
| Excel `.xlsx`・`.xlsm`・`.xls`・`.ods` | スプレッドシート |
| CSV                                    | 表またはソース   |
| 画像                                   | 画像ビューア     |

Office・PDF・画像のビューアは100 MiBまでのファイルを対象とします。元アプリと完全に同じ表示になるとは限りません。

## 資料を開く

hibachi の Contents からファイルを選ぶと、中央に表示されます。[Google Drive](drive.md)の資料も、接続できている場合に開けます。

PDF や Office 文書の閲覧は表示専用です。編集する場合は元のアプリを使ってください。Markdown の資料は、書き込みできる接続であれば irori で編集できます。

## ノートに活かす

資料を読みながら [Knowledge にノート](notes.md)を書き、参照する資料への相対リンクを残します。[AI エージェント](agents.md)にも資料を指定して要約や整理を頼めます。

AI の利用範囲は、その CLI のアクセス設定と接続状態に従います。切断中のフォルダを、接続済みとして読むことはできません。
