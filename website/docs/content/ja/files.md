## 対応する形式

| 形式                                                                              | 表示               |
| --------------------------------------------------------------------------------- | ------------------ |
| PDF                                                                               | 文書ビューア       |
| Word `.docx`                                                                      | 文書               |
| PowerPoint `.pptx`                                                                | スライド           |
| Excel `.xlsx`・`.xlsm`・`.xls`・`.ods`                                            | スプレッドシート   |
| CSV                                                                               | 表またはソース     |
| 画像                                                                              | 画像ビューア       |
| コードなどのテキストファイル                                                      | エディタ（色分け） |
| Google ドキュメント・スプレッドシート・スライド（`.gdoc`・`.gsheet`・`.gslides`） | 元のアプリ         |
| 圧縮ファイル・動画・音声などのバイナリファイル                                    | 元のアプリ         |

Office・PDF・画像のビューアは100 MiBまでのファイルを対象とします。元アプリと完全に同じ表示になるとは限りません。スプレッドシートでは、シートのタブが表の下端に1列に並びます。

`.py`・`Makefile`・`.gitignore` などのテキストファイルは、2 MiB 以下の UTF-8 であれば、言語に合わせて色分けしてエディタで開きます。それ以外は元のアプリで開きます。Google ドキュメント・スプレッドシート・スライドのファイルは文書の ID だけを持つため、irori は元のアプリで開きます。詳しくは[Google Drive](drive.md)を参照してください。

## 資料を開く

vault の Contents からファイルを選ぶと、中央に表示されます。[Google Drive](drive.md)の資料も、接続できている場合に開けます。Knowledge と Contents の一覧は表示中のファイルに合わせて、上のフォルダを開き、その行を選んだ状態にします。ファイルの追加・移動・コピーは[ファイルとフォルダの整理](notes.md)を参照してください。

PDF や Office 文書の閲覧は表示専用です。編集する場合は元のアプリを使ってください。Markdown などのテキストの資料は、書き込みできる接続であれば irori で編集できます。

## ノートに活かす

資料を読みながら [Knowledge にノート](notes.md)を書き、参照する資料への相対リンクを残します。[AI エージェント](agents.md)にも資料を指定して要約や整理を頼めます。

AI の利用範囲は、その CLI のアクセス設定と接続状態に従います。切断中のフォルダを、接続済みとして読むことはできません。

## タブと列

開いたファイルはタブになります。ページのバーの **横に並べて開く** で、ページを最大4列に分けられます。列ごとに自分のタブを持つので、書いているノートの横で PDF を読めます。一覧・リンク・検索から開いたファイルは、作業中の列に開きます。別の列をクリックするとノートを保存し、編集する列がそちらに移ります。ほかの列には、保存された内容が表示されます。

列とタブは、irori を起動している間 vault ごとに保たれます。名前や場所を変えたファイルのタブはそのまま付いていき、削除したファイルのタブは閉じます。
