## 全体を見渡す

左のレールから **irori mode** を開きます。**地図** では、ワークスペースの vault をその順に1行4つずつ並べて見渡せます。**並列** では、それぞれの AI・Schema・Knowledge・Contents を並べて確認できます。

vault の名前・アイコン・色は[vault の設定](workspaces.md#section-3)から変更できます。

## irori agent に頼む

irori agent は、複数の vault を使う仕事の窓口です。例えば「個人の調査ノートとチームの計画を比べて、次の打ち合わせ用のメモを作ってください」と頼めます。

irori agent は依頼を分け、必要な vault の vault agent に渡し、結果をまとめます。渡された仕事の許可や質問も画面で確認します。[SSH ホストの vault](ssh-hosts.md)に任せた仕事は、そのホストで動きます。

## 指示と会話を管理する

irori agent も CLI とモデルを選んで使います。標準のアクセスで始まり、自分の Schema は[同じ設定画面](schema.md)から編集できます。

[会話と履歴](conversations.md)で仕事ごとに会話を分けられます。[設定](settings.md#section-3)の **画面に出すもの** で **列の操作** をオンにすると、**列を追加** で別の会話を並べて進められます（4列まで）。会話と列はワークスペースごとに分かれます。決まった手順を動かす場合は、左のレールの irori mode の下にある **ルーティン** を開いて[実行](routines.md)します。

## vault の準備と引っ越し

irori agent には、vault の準備も頼めます。GitHub のリポジトリを vault として取得する、新しい vault を作る、既存のフォルダを登録する、同期フォルダを接続する、といった操作です。層・名前・分類の変更、ワークスペースの作成、接続フォルダの解除、フォルダを残したままの vault の削除もできます。

Obsidian、orca、エディタ、ただのフォルダから移るときは、そう伝えてください。irori agent は今あるものを調べ、それぞれを vault にするか、vault の資料にするか、移さないかを少しずつ質問します。計画を自分のフォルダに書き、あなたの了承を待ってから設定し、移せたものと移せなかったものを報告します。

irori agent が既存のフォルダを vault として登録する、フォルダを接続する、作業フォルダを変える、vault を削除する、ルーティンを実行するときは、irori が毎回あなたに確認します。こうした手順は irori agent の標準スキルにあります。以前に用意したフォルダに足りないスキルは、irori agent の画面の **標準スキルを追加** で加えられます。
