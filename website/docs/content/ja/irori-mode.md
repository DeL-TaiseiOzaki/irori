## 全体を見渡す

左のレールから **irori mode** を開きます。地図では hibachi を分類ごとに見渡せます。並列の表示では、それぞれの AI・Schema・Knowledge・Contents を並べて確認できます。

hibachi の名前・アイコン・色は[hibachi の設定](workspaces.md#section-3)から変更できます。

## irori agent に頼む

irori agent は、複数の hibachi を使う仕事の窓口です。例えば「個人の調査ノートとチームの計画を比べて、次の打ち合わせ用のメモを作ってください」と頼めます。

irori agent は依頼を分け、必要な hibachi の hibachi agent に渡し、結果をまとめます。渡された仕事の許可や質問も画面で確認します。

## 指示と会話を管理する

irori agent も CLI とモデルを選んで使います。フルアクセスで始まり、自分の Schema は[同じ設定画面](schema.md)から編集できます。

[会話と履歴](conversations.md)で仕事ごとに会話を分けられます。決まった手順を動かす場合は、irori mode の **ルーティン** を開いて[実行](routines.md)します。
