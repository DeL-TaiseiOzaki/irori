## ノートを開く・作る

vault の **Knowledge** から Markdown ファイルを選びます。新規ノートを追加するときは、Knowledge の見出しの **＋** か、フォルダのメニューの **新しいノート** から、名前と保存先フォルダを指定します。ノートは `.md` ファイルとして保存されます。

vault が `.property/property.json` でページの種類を宣言している場合は、**ノートを作成** で **種類** も選びます。新しいノートは、その種類とタイトル、種類に必須のプロパティを持って始まります。必須のプロパティは空欄のまま必須の印が付き、最終変更を記録する vault ではあなたの名前が入ります。種類のないノートは **種類なし** で作ります。詳しくは[プロパティ](properties.md)を参照してください。

## エディタで書く

見たまま編集できるエディタで、見出し、箇条書きとタスク、引用、表、コードブロック、画像を書けます。Markdown のソース表示に切り替えて、記法を直接編集することもできます。

- `mermaid` のコードブロックは図として表示されます。**編集** でコードを表示し、**図だけ表示** で図だけに戻します。
- 脚注（`[^name]`）、ウィキリンク（`[[page|label]]`）、コールアウト（`> [!note] タイトル`）は、読むときの形で表示されます。`]]` や `]` を入力すると、入力した記法がウィキリンクや脚注の印になります。ダブルクリックすると記法の文字に戻して編集でき、Backspace でまとめて消せます。
- ファイルにはこれらの記法が書いたとおりに残ります。数式や HTML など、エディタが書き戻せない記法は、クリックするとソースで表示されます。

## 保存と画像

変更は自動で保存されます。ノートに貼り付けたりドロップしたりした画像は、ノートのあるフォルダの `_assets/` に保存され、本文から相対パスで参照されます。Obsidian 形式の埋め込み `![[shot.png]]` は、ノートの隣か `_assets/` にある画像を表示し、`![[shot.png|300]]` で幅を指定できます。画像をクリックすると全体を表示し、Esc かもう一度のクリックで閉じます。ノートと画像を一緒に管理すると、別のパソコンにも持ち出せます。

外部のツールや AI が同じファイルを変更し、保存が競合した場合は、表示された相手の内容と下書きを確認してください。未保存の下書きを捨てる前に必要な文章を残します。

## ファイルとフォルダを整理する

Knowledge と Contents の一覧は、Finder やエクスプローラーのように使えます。ファイルやフォルダを右クリックするか、行の **⋯** を押します。

| 項目                                                                          | 内容                                                                      |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **新しいノート**・**新しいファイル**・**新しいフォルダ**・**ファイルを追加…** | そのフォルダに追加します                                                  |
| **名前を変更**・**移動**・**削除**                                            | ファイルやフォルダを変更します                                            |
| **切り取り**・**コピー**・**貼り付け**                                        | irori の中で移動・コピーします                                            |
| **パスをコピー**・**相対パスをコピー**                                        | このコンピューター上のパス、または vault のルートからのパスをコピーします |
| **Finder で表示**（Windows では **エクスプローラー で表示**）                 | ファイルマネージャーでその場所を開きます                                  |

読み取り専用の行には、使える項目だけが表示されます。

行を選んで F2 を押すと、その場で名前を変えられます。ノートは `.md` を除いた名前で表示され、ファイルは拡張子の前だけが選ばれます。Enter で変更し、Esc で元の名前に戻します。Delete キー（Mac では ⌘+Delete）を押すと、確認のあとで削除します。

行をフォルダにドラッグすると移動します。Finder やエクスプローラーからファイルやフォルダをドロップすると、コピーして取り込みます。行で Ctrl/⌘+C・X・V を押すとコピー・切り取り・貼り付けができ、Knowledge と Contents の間や[横に開いた vault](workspaces.md)にも貼り付けられます。Finder やエクスプローラーでコピーしたファイルも貼り付けられます。同じ名前があれば `table 2.csv` のように両方を残し、元のファイルは置き換えません。

Knowledge で名前や場所を変えると、そのファイルやフォルダへの[リンク](links.md)も書き換わります。削除したノートは削除済みノートに移り、vault のメニューの **削除したノートを復元** から戻せます。ほかのファイルとフォルダはシステムのゴミ箱に移ります。

vault のエージェントが動いている間も、ノート・フォルダ・ファイルの追加、削除したノートの復元、Schema の編集、vault の名前・見た目・表示名の変更、オントロジーや資料の表示はできます。移動・名前の変更・削除、層のフォルダの変更、索引の更新は、エージェントが使っているファイルを動かすため、実行が終わるまで待ちます。

## 次の仕事へつなぐ

[リンク](links.md)で関連ノートをつなぎ、[プロパティ](properties.md)で種類や状態を添えられます。[コメント](comments.md)で修正してほしい箇所を示し、[AI](agents.md)に続きを頼めます。

変更を記録したいときは[Git の変更画面](git.md)で差分を確認し、コミットします。自動保存と Git のコミットは別の操作です。
