## ノートを開く・作る

hibachi の **Knowledge** から Markdown ファイルを選びます。新規ノートを追加するときは、名前と保存先を指定します。ノートは `.md` ファイルとして保存されます。

見たまま編集できるエディタで見出し、箇条書き、引用、表を書けます。Markdown のソース表示に切り替えて、記法を直接編集することもできます。

## 保存と画像

変更は自動で保存されます。貼り付けた画像はノートの隣の `_assets/` に置かれ、本文から相対パスで参照されます。ノートと画像を一緒に管理すると、別のパソコンにも持ち出せます。

外部のツールや AI が同じファイルを変更し、保存が競合した場合は、表示された相手の内容と下書きを確認してください。未保存の下書きを捨てる前に必要な文章を残します。

## 次の仕事へつなぐ

[リンク](links.md)で関連ノートをつなぎ、[プロパティ](properties.md)で種類や状態を添えられます。[コメント](comments.md)で修正してほしい箇所を示し、[AI](agents.md)に続きを頼めます。

変更を記録したいときは[Git の変更画面](git.md)で差分を確認し、コミットします。自動保存と Git のコミットは別の操作です。
