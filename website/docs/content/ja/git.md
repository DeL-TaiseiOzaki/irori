title: Git と共有
description: 差分を確認して記録し、GitHub などのリモートと共有します。
---

## 変更を記録する

hibachi の **変更** でファイルを選び、差分を確認します。記録する変更をステージし、メッセージを入力して **コミット** を押します。

コミットは手元の履歴に残す操作です。まだリモートへは送られません。別のツールで部分的にステージした内容も保たれます。

## リモートと同期する

**Fetch** はリモートの情報を取得します。**Pull** は作業ツリーがきれいで、履歴を早送りできる場合に取り込みます。

**Push** では hibachi・ブランチ・リモート・送るコミットを確認して送ります。Git の認証は既存の設定を使います。複数の hibachi の履歴はそれぞれ独立しています。

## 履歴と競合を確認する

**履歴** から以前のコミットと差分を開けます。履歴を統合する場合は **その他 → 履歴を統合** を選びます。

競合があれば共通の元・手元・相手の内容を確認し、結果を編集します。解決したファイルをステージし、内容を確認して統合のコミットを作ります。失敗した Push や Pull で、手元の変更が強制的に置き換わることはありません。

## GitHub に公開する

新しい hibachi の作成時に **GitHub にも作成** を選べます。既存のローカル hibachi では **Git を始める**、リモートがなければ **GitHub に公開…** から公開できます。

この操作には GitHub CLI `gh` とそのログインが必要です。公開画面でアカウント・リポジトリ名・公開範囲を確認します。既定は非公開です。irori はアプリ内でプルリクエストを作る機能は持っていません。
