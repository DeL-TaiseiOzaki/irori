## コメントを追加する

1. Markdown ノートを開きます。
2. 特定の箇所について書く場合は、その文章を選択します。
3. ノートのバーの **コメント** を開き、文章を入力して **追加** を押します。

文章を選択しなければノート全体へのコメントになります。

## 確認して解決する

コメントにある引用を選ぶと、本文の該当箇所を表示します。本文が書き換わって引用が見つからない場合は、その状態が表示されます。

対応が済んだコメントは **解決** で取り除きます。現在は解決済みコメントを残す履歴ではなく、コメントの削除として扱います。

## AI やチームに共有する

コメントは hibachi の `.irori/comments/` に保存され、Git で共有できます。hibachi agent は対象ノートのコメントを受け取り、irori agent は hibachi ごとのコメント数を確認できます。

「コメントを読んで、このノートを直してください」と[AI に依頼](agents.md)できます。現在の対象は hibachi 内の Markdown ファイルです。Drive のファイルと irori agent 自身のフォルダへのコメントにはまだ対応していません。
