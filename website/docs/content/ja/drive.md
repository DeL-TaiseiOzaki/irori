## フォルダを接続する

1. 接続先の hibachi を開き、**接続** または **クラウド接続** を開きます。
2. Google アカウントを登録し、システムのブラウザでログインします。
3. マイドライブまたは共有ドライブから、接続するフォルダを選びます。
4. ローカルに表示する名前とアクセス設定を確認し、接続します。

Windows では [WinFsp](https://winfsp.dev/rel/) が必要です。接続したフォルダは hibachi の Contents に表示されます。

## 読む・編集する

新しい接続は編集可能で、読み取り専用にも切り替えられます。以前に読み取り権限だけで登録したアカウントには、**書き込みを許可** から再認証が必要な場合があります。

Markdown は irori で編集できます。他の形式は[ビューア](files.md)で読み、編集は元のアプリを使います。hibachi agent も、マウントされた資料をアクセス設定の範囲で扱えます。

## 送信待ちを確認する

変更は Drive に送られます。**送信待ち** は、手元には保存され、Drive へのアップロードがまだ終わっていない変更です。接続の状態と理由を確認してください。

送信待ちのある接続を切断するときやアプリを閉じるときは、表示される選択を確認します。残した変更は、次にそのフォルダを接続したときに送られます。競合や認証切れは[トラブルシューティング](troubleshooting.md)を参照してください。

> Drive の接続・編集は検証版の機能です。Windows・Mac の実機での受け入れ確認を続けています。最初はコピーした資料でお試しください。
