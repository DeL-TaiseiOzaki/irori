## vault を追加する

**vault** は1つの知識ベースです。既存の Markdown フォルダや Git リポジトリをその場所のまま開けます。

追加する方法は4つあります。

| 方法                 | 操作                                                            |
| -------------------- | --------------------------------------------------------------- |
| 手元のフォルダを使う | **KBフォルダを開く** または **vault を追加 → 既存のフォルダ** |
| GitHub から取得する  | **GitHub から取得** で URL・保存先・新しいフォルダ名を指定      |
| 新しく作る           | **新しく作成** で保存先・フォルダ名・名前を指定                 |
| SSH ホストに置く     | **SSH ホストから** でホストのフォルダを選ぶ（[SSH ホストの vault](ssh-hosts.md)） |

新しく作る vault は Git リポジトリとして始まります。[GitHub への公開](git.md#section-4)も選べます。

## ワークスペースを作る

ワークスペースは、一緒に使う vault の組み合わせです。起動画面で使う vault を選び、名前を付けて **ワークスペースを作成** を押します。

例えば個人のノート、チームの議事録、組織の資料を1つのワークスペースで開けます。それぞれのフォルダと Git の履歴は独立したままです。[irori mode](irori-mode.md)で全体を見渡せます。

## 名前と表示を整える

**vault の設定** で名前・分類・アイコン・色を変更できます。分類は個人・チーム・組織から選ぶか、`研究室` のように自由に入力します。ワークスペースのほかの vault の分類も候補に出ます。分類は `.irori/scope.json` に保存されるため、同じ知識ベースを開く人には同じ分類が見えます。表示を変えてもファイルは移動しません。

左のレールでは、vault を右クリックして **新しいグループ** や **「…」に入れる** を選ぶと、vault をグループにまとめられます。グループはクリックで開閉し、右クリックで **名前を変更** や **グループを解除** を選びます。閉じたグループでも、エージェントが動いている vault や許可待ちの vault は表示されます。グループはワークスペースごとに、このコンピューターに保存されます。

**vault の設定** の **vault を削除**、または起動画面の vault の削除ボタンで、vault をこのコンピューターとすべてのワークスペースから外せます。フォルダは残り、**フォルダもゴミ箱に移す** を選んだときだけゴミ箱に移ります。残したフォルダをもう一度追加すると、同じ vault として戻ります。ワークスペースの登録を削除しても、ノートのフォルダは残ります。vault の中身を整理する前に[3つの層](layers.md)を確認してください。

## 複数のワークスペースとウィンドウ

ワークスペースはウィンドウ上部にタブとして並び、いくつも同時に開けます。タブの端の **＋**（**ワークスペースを開く**）で起動画面を出し、開いたワークスペースが新しいタブになります。すでに開いているワークスペースは、離れたときの vault・ノート・表示のまま戻ります。

表示していないタブのエージェントも動き続けます。エージェントが実行中または許可待ちのタブには点が付きます。タブを閉じると、そのタブだけが開いているエージェントは止まるため、先に確認が出ます。

**ファイル › 新しいウィンドウ**（Ctrl/Cmd+Shift+N）で別のウィンドウを開けます。Windows では、ファイルメニューはタイトルバーの **メニュー** ボタンから開きます。macOS では Dock のメニューからも開けます。ウィンドウごとに自分のタブを持ち、ほかのウィンドウが開いているものは、ウィンドウを閉じても止まりません。

## 2つの vault を並べる

vault のパネルの上にある **横に vault を開く** で、同じワークスペースの別の vault を隣に開きます。名前を押すと別の vault に切り替わり、**横の vault を閉じる**（×）で閉じます。

一方の Knowledge のノート・ファイル・フォルダを、もう一方のフォルダへドラッグすると移動します。残るノートとのリンクが切れる場合は、その数を示して先に確認します。ノートに貼った画像とコメントも一緒に移ります。横の vault でファイルを開くと、その vault がメインのパネルに移り、2つが入れ替わります。
