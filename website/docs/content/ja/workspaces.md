## hibachi を追加する

**hibachi** は1つの知識ベースです。既存の Markdown フォルダや Git リポジトリをその場所のまま開けます。

追加する方法は3つあります。

| 方法                 | 操作                                                            |
| -------------------- | --------------------------------------------------------------- |
| 手元のフォルダを使う | **KBフォルダを開く** または **hibachi を追加 → 既存のフォルダ** |
| GitHub から取得する  | **GitHub から取得** で URL・保存先・新しいフォルダ名を指定      |
| 新しく作る           | **新しく作成** で保存先・フォルダ名・名前を指定                 |

新しく作る hibachi は Git リポジトリとして始まります。[GitHub への公開](git.md#section-4)も選べます。

## ワークスペースを作る

ワークスペースは、一緒に使う hibachi の組み合わせです。起動画面で使う hibachi を選び、名前を付けて **ワークスペースを作成** を押します。

例えば個人のノート、チームの議事録、組織の資料を1つのワークスペースで開けます。それぞれのフォルダと Git の履歴は独立したままです。[irori mode](irori-mode.md)で全体を見渡せます。

## 名前と表示を整える

**hibachi の設定** で名前・分類・アイコン・色を変更できます。分類は個人・チーム・組織、またはなしを選びます。表示を変えてもファイルは移動しません。

ワークスペースの登録を削除しても、ノートのフォルダは残ります。hibachi の中身を整理する前に[3つの層](layers.md)を確認してください。
