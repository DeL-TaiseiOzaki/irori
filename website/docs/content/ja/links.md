## ノートをつなぐ

Markdown の相対リンクで別のノートを参照できます。例えば同じフォルダの `research.md` を開くリンクは次のように書きます。

```markdown
[調査ノート](research.md)
```

リンクを Ctrl+クリック（Mac では ⌘+クリック）すると、対象のノートへ移動します。普通のクリックでは、リンクの文字にカーソルが置かれます。`wiki/` のようにフォルダを指すリンクは、そのフォルダの `index.md` を開きます。

irori の Knowledge でノート・フォルダ・画像・CSV ファイルの名前や場所を変えると、それを指すリンクも書き換わります。変更後は[差分](git.md)で結果を確認できます。ウィキリンク（`[[page]]`）はエディタに表示されますが、irori はそこから移動せず、書き換えもしません。

## 参照元をたどる

バックリンクで、開いているノートを参照している別のノートを確認できます。ノートにリンクを書くと、話題がどこからつながっているかをたどれます。

## ファイルの中を探す

開いているファイルの中の言葉は、**Ctrl+F**（Mac では **⌘F**）か、上部の「…」の **ファイル内を検索** で探せます。ノート、コード、CSV の表、PDF、Word、PowerPoint、スプレッドシートで使えます。スプレッドシートはすべてのシートが対象で、見つかったシートとページに切り替わります。

大文字と小文字、全角と半角の英数字は区別しません。Enter か F3 で次、Shift+Enter で前に移り、Esc で閉じます。ノートでは、閉じたときに見つけた言葉が選ばれた状態になります。画像は文字がないため対象外です。

## ワークスペースを検索する

アプリの検索から、ワークスペースに開いている vault の知識を探せます。結果を選ぶと、そのノートと所有する vault が開きます。

このドキュメントサイトの検索はガイドの記事を対象にしています。パソコン上のノートや AI の会話は検索対象に含まれません。

## オントロジーを確かめる

vault は、ページの種類と種類どうしの関係を `.property/property.json` に宣言できます。これがその vault のオントロジーです。vault のメニュー、Knowledge の見出し、ファイルを開いていないときの Knowledge のカードから **オントロジー** を開きます。種類はページ数とともに、関係はそれを使える種類から指す種類への線として図に描かれます。下の表には、種類と関係それぞれの意味と使われ方が並びます。

irori は宣言をページに当てはめ、宣言と違うページを一覧にします。種類がない・宣言にない種類、必須のプロパティがない、宣言にない関係、その種類からは使えない関係、相手の種類が違う関係が対象です。行を選ぶとそのページが開き、一覧はファイルの変更に合わせて更新されます。ページを拒んだり書き換えたりはしません。ページ同士をグラフとして描く機能はありません。

関係の `to` には、どのページでもよい `page`、URL を指す `url`、または種類のリストを書きます。`avoid` に挙げた名前は、代わりに使う名前と一緒に示されます。

```json
{
  "schemaVersion": 1,
  "relations": {
    "about": { "from": "any", "to": ["person", "org", "project"] }
  },
  "avoid": [{ "name": "depends_on", "use": "uses" }]
}
```

vault agent をオンにしている場合は、**vault agent** を押すと、宣言とページを一緒に見直す依頼が vault agent の入力欄に入ります。送信するまでは何も実行されません。

[irori-templete](https://github.com/DeL-TaiseiOzaki/irori-templete) をもとにした vault では、**索引を更新**（まだ索引がなければ **索引を作成**）で各フォルダの `index.md` を書きます。索引には、サブフォルダ、続いて種類の見出しごとにページが説明付きで並びます。フォルダの説明は残り、索引に書いたほかの文章は置き換わります。共有するには索引をコミットします。vault agent は `irori index` で同じ更新ができます。

以前の irori が作った `ontology/` フォルダは、もう読み書きしません。残っている場合は画面に表示されるので、削除してかまいません。
