## ノートをつなぐ

Markdown の相対リンクで別のノートを参照できます。例えば同じフォルダの `research.md` を開くリンクは次のように書きます。

```markdown
[調査ノート](research.md)
```

リンクを選ぶと対象のノートへ移動します。irori 内でノートの名前や場所を変えると、対応するノートリンクも書き換わります。変更後は[差分](git.md)で結果を確認できます。

## 参照元をたどる

バックリンクで、開いているノートを参照している別のノートを確認できます。ノートにリンクを書くと、話題がどこからつながっているかをたどれます。

オントロジーの CSV を使う vault では、知識の階層やグラフも表示できます。宣言されたオントロジーが対象で、任意の CSV が自動的にグラフになるわけではありません。

## ファイルの中を探す

開いているファイルの中の言葉は、**Ctrl+F**（Mac では **⌘F**）か、上部の「…」の **ファイル内を検索** で探せます。ノート、コード、CSV の表、PDF、Word、PowerPoint、スプレッドシートで使えます。スプレッドシートはすべてのシートが対象で、見つかったシートとページに切り替わります。

大文字と小文字、全角と半角の英数字は区別しません。Enter か F3 で次、Shift+Enter で前に移り、Esc で閉じます。ノートでは、閉じたときに見つけた言葉が選ばれた状態になります。画像は文字がないため対象外です。

## ワークスペースを検索する

アプリの検索から、ワークスペースに開いている vault の知識を探せます。結果を選ぶと、そのノートと所有する vault が開きます。

このドキュメントサイトの検索はガイドの記事を対象にしています。パソコン上のノートや AI の会話は検索対象に含まれません。
