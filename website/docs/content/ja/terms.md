## 検証版の利用

現在の配布は Windows x64 と Apple Silicon Mac 向けの検証版です。機能やファイルの扱いは変わる場合があります。[インストール](installation.md)、[Google Drive](drive.md)、リリースノートを確認し、大切なファイルを編集したりプログラムを実行したりする前にバックアップを取ってください。AI による変更も確認してから使ってください。

## 接続するサービスとアカウント

Drive、Git のリモート、AI CLI は、設定したアカウントとサービスを使います。それぞれ独自の利用条件、権限、提供状況、料金、データ保持のルールがあります。irori をインストールしてもモデルの契約が付属したり、他人のファイルを扱う許可を得たりするわけではありません。

Drive の接続、AI、ターミナル、ルーティンの実行前に[プライバシーとデータの扱い](privacy.md)を確認してください。アプリ内のデータ利用確認は、送信と保持の可能性を説明するもので、提供者のポリシー適合性を検証したり、ツール権限を置き換えたりするものではありません。
