---
title: 会話と履歴
description: AI との仕事を会話ごとに残し、履歴から開き直します。
---

## 会話を作る・開く

vault agent と irori agent は、それぞれ複数の会話を持てます。**新しい会話** で、同じ CLI の空の会話を始めます。最初の指示を送ると記録されます。

**履歴** から以前の会話を開けます。別の CLI を選ぶと新しい会話になり、履歴から開いたときはその会話の CLI に切り替わります。

## 履歴を整理する

会話の名前を変更し、ピン留めし、アーカイブできます。**ノート別** でノートごとにまとめ、**このノート** で開いているノートの会話に絞れます。

削除は irori が保存した会話を取り除きます。CLI 自身の履歴と、実行に使ったノートや資料の控え（irori のデータフォルダ）は残ります。会話はこのパソコンのアプリデータに保存され、現在は保存先の変更や会話本文の検索には対応していません。

## やり直す・分岐する

自分の指示にカーソルを合わせると出る鉛筆の **この指示を編集してやり直す** で、送った指示を直して送り直せます。送ると、その指示から先のやり取りは表示されなくなり、会話はその指示の手前から続きます。実行中や送信待ちがあるときは使えません。

実行の終わりの **完了** の横に出る **ここから分岐** で、そこまでの会話を新しい会話として複製し、タブで開きます。元の会話はそのまま残ります。

Claude Code と Codex は、CLI 自身のセッションもその時点から分岐させます。ほかの CLI では、それまでの会話を新しいセッションに渡して続けます。エージェントが変更したファイルは元に戻らないので、必要なら Git で戻してください。

## 送信待ちと再開

会話ごとに1つずつ実行し、複数の会話を同時に進められます。実行中に送った指示は、その会話の送信待ちになります。

終わるのを待てないときは、送信待ちの指示の **今すぐ送る** を押します。Claude Code と Codex は、実行中の作業を止めずに次の区切りでその指示を受け取ります。ファイルを添付した指示、スキル・モデルなどが実行中と違う指示、ほかの CLI への指示は、実行を止めてから送ります。

失敗や停止で送信待ちは止まります。次の指示を送ると古いものから順に続きます。**送信を再開** でも同じです。再起動した後も指示は残ります。終わったか確認できない実行を自動で繰り返すことはありません。

CLI の会話の続きとして再開できるのは、同じパソコン・フォルダ・アクセス設定の場合です。条件が変わると新しい CLI セッションになり、それまでの会話（指示と返答。ツールの出力は除く）が新しいセッションに渡されます。長い会話では古い部分が省かれます。
