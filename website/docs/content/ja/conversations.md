---
title: 会話と履歴
description: AI との仕事を会話ごとに残し、履歴から開き直します。
---

## 会話を作る・開く

hibachi agent と irori agent は、それぞれ複数の会話を持てます。**新しい会話** で、同じ CLI の空の会話を始めます。最初の指示を送ると記録されます。

**履歴** から以前の会話を開けます。別の CLI を選ぶと新しい会話になり、履歴から開いたときはその会話の CLI に切り替わります。

## 履歴を整理する

会話の名前を変更し、ピン留めし、アーカイブできます。**ノート別** でノートごとにまとめ、**このノート** で開いているノートの会話に絞れます。

削除は irori が保存した会話を取り除きます。CLI 自身の履歴は残ります。会話はこのパソコンのアプリデータに保存され、現在は保存先の変更や会話本文の検索には対応していません。

## 送信待ちと再開

同じ hibachi では1つの実行が進み、実行中に送った指示は送信待ちになります。同じ所有者の会話をまたいで、古い指示から順に実行します。

失敗や停止で送信待ちは止まります。再起動した後も指示は残り、**送信を再開** で続けます。終わったか確認できない実行を自動で繰り返すことはありません。

CLI の会話の続きとして再開できるのは、同じパソコン・フォルダ・アクセス設定の場合です。条件が変わると新しい CLI セッションになり、現在は前の会話の文脈が自動で渡されません。必要な内容を改めて指示してください。
