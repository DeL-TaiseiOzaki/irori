## ルーティンを用意する

ルーティンは `routine.yaml` と必要なファイルを入れたフォルダです。vault の仕事は `.irori/routines/<name>/` に、全体の仕事は irori agent の既定のフォルダ（`~/irori/you`）の `routines/<name>/` に置きます。ワークスペースで irori agent に別のフォルダを選んでも、全体の仕事の置き場所は変わりません。

ルーティン画面の **新しいルーティン** から、名前・置き場所・ステップをフォームで作れます。**YAML** に切り替えると本文を直接編集できます。同じ画面の **irori agent に頼む** を押すと、irori agent の入力欄に「ルーティンを作って：」が入ります。続きを書いて送ると、irori agent が `write-routine` スキルでルーティンを書き、irori が読めることを確かめます。vault の例です。

```yaml
name: Review notes
steps:
  - agent: vault
    access: default
    prompt: |
      Read the notes and write a short review in Knowledge_Base/review.md.
```

## 確認して実行する

左のレールの irori mode と vault の間にある **ルーティン** を開き、対象の **実行** を押します。この画面の上部に **シークレット** があり、横にはエージェントのパネルがあります。初回とファイル変更後には、中身や差分の確認が開きます。**確認して実行** で始まります。

irori agent に「Daily mail を実行して」のように頼んで実行することもできます。始める前に irori があなたに確認します。irori agent が始められるのは、この端末で確認済みで、その後変更されていないルーティンだけです。そうでなければ、確認やシークレットの入力など、ルーティン画面ですることを伝えます。irori agent がルーティンのシークレットやプログラムの出力を見ることはありません。vault agent とルーティン自身の AI ステップは、ルーティンを始められません。

動作中の **停止** は、そのステップを止め、後のステップを実行しません。始めたワークスペースのタブを閉じても、ルーティンは動き続けます。自動スケジュールはなく、irori を閉じている間は動きません。

## ステップを書く

`run` はプログラムを実行し、`agent` は AI に指示します。最大20ステップを順番に実行し、失敗した時点で止まります。AI のステップには `access` と `prompt` が必要です。vault のルーティンは `agent: vault`、irori agent のルーティンは `agent: irori` を使います。

JavaScript ファイルを動かすときは、設定の **ルーティン** で **JavaScript** を有効にします。例えば `- run: collect.js`、または `- run: [gh, api, notifications]` と書けます。Python ファイルは、同じ設定で **Python** を有効にすると uv を取得し、`uv run --script` で動きます。どちらかが必要なルーティンの行には、**JavaScript を追加** または **Python を追加** が表示されます。プログラムのステップが使うシークレットはエディタで追加し、値はエディタ、ルーティンの行、画面上部の **シークレット** のどこからでも入力できます。値はこのユーザーアカウントの OS のキーチェーンで保護して保存し、指定したプログラムのステップにだけ渡します。エージェントには渡しませんが、同じユーザーで動くプログラム（フルアクセスでシェルを使うエージェントを含む）が読み出すことは防げません。

ステップの出力に含まれたシークレットの値は、実行記録では `***` と表示されます。トークンを更新するステップは、`IRORI_SECRETS_OUT` が示すファイルに `NAME=value` の行を書くと、次の実行から新しい値が使われます。書き戻せるのはそのステップが指定したシークレットだけで、ほかの行があるとステップは失敗します。

各ステップは一時作業用の `IRORI_WORK`、継続状態用の `IRORI_STATE`、ルーティンの場所を示す `IRORI_ROUTINE` を使えます。

## 結果を確認する

実行結果には各ステップの状態、出力や AI の報告、変更したファイルが表示されます。履歴はルーティンごとに直近20件が残ります。AI ステップの **会話** から、その仕事の会話を開けます。

実行中にアプリが終了すると、その結果は次回 **不明** になります。自動で再実行しないため、結果を確認してから次の実行を選んでください。

## 編集・削除・持ち運び

ルーティンの行の鉛筆（**編集**）でエディタが開きます。エディタの **フォルダを開く** で、プログラムのステップのファイルを置くルーティンのフォルダを OS のファイルマネージャーで開けます。変更したルーティンは、実行前にもう一度確認します。

エディタの **削除** を押し、続けて **削除する** を押すと、ルーティンのフォルダがシステムのゴミ箱に移ります。この端末での確認・実行履歴・`IRORI_STATE` も一緒に消えるため、後で同じフォルダに作ったルーティンは未確認から始まります。実行中のルーティンは削除できません。

vault のルーティンは vault のリポジトリと一緒に移ります。irori agent のルーティンは[GitHub に保存する環境](settings.md#section-6)に含まれます。ルーティンのシークレットは、12文字以上の合言葉を入れたときだけ、その合言葉で暗号化して一緒に保存されます。復元したルーティンは、新しい端末での初回の実行前に確認します。
