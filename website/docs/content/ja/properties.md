## プロパティを編集する

Knowledge の Markdown ノートは、本文の上にタイトルと説明、プロパティを表示します。各欄で値を変更すると、元の Markdown の YAML frontmatter に反映されます。`index.md` はこの表示の対象外です。

プロパティはノートの一部なので、Git で本文と一緒に共有できます。

## hibachi の定義を使う

hibachi に `.property/property.json` がある場合、その定義に従って選択肢、必須項目、種類ごとの項目を表示します。ファイルがなくてもノートを開けます。

保存時には `auto: last-change` と定義された項目に、変更者と時刻が入ります。種類や選択肢の運用は、使っている hibachi の約束に従ってください。

## YAML を確認する

frontmatter が壊れている場合は YAML のソース表示で開きます。内容を確認して構文を直してください。irori が壊れた情報を自動で置き換えることはありません。

現在は基本的なプロパティの表示・編集に対応しています。資料・出典・関係の専用ピッカーや、種類からノートを作る機能はまだありません。本文の[リンク](links.md)や[コメント](comments.md)も利用できます。
