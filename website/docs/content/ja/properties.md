## プロパティを編集する

Knowledge の Markdown ノートは、本文の上にタイトルと説明、プロパティを表示します。各欄で値を変更すると、元の Markdown の YAML frontmatter に反映されます。`index.md` はこの表示の対象外です。

説明の下の **プロパティ** を押すと、タイトルと説明を残してプロパティの欄を折りたためます。折りたたんだ状態は、もう一度開くまでどのページでも続きます。frontmatter が壊れている場合は、折りたたまずに表示します。

プロパティはノートの一部なので、Git で本文と一緒に共有できます。

## vault の定義を使う

vault に `.property/property.json` がある場合、その定義に従って選択肢、必須項目、種類ごとの項目を表示します。ファイルがなくてもノートを開けます。種類を宣言している vault では、[ノートを作る](notes.md)ときにも種類を選べます。

保存時には `auto: last-change` と定義された項目に、変更者と時刻が入ります。入るのは irori の画面で保存した人なので、エージェントが画面の外で変えたあとも、その人の名前のままです。目安の記録として扱ってください。種類や選択肢の運用は、使っている vault の約束に従ってください。

**関係** の各行は、関係の名前と相手でできています。名前は、vault がこの種類のページに宣言している関係から選びます。相手は、その関係が指す種類のページからタイトル付きで選ぶか、URL を指す関係なら URL を入力します。相手はページからの相対リンクとして書き込まれます。**＋ 関係を追加** で行を加え、名前と相手がそろった時点でページに書き込まれます。宣言にない名前や、この種類からは使えない名前は、書かれたまま残り、印が付きます。関係の宣言については[オントロジー](links.md)を参照してください。

## YAML を確認する

frontmatter が壊れている場合は YAML のソース表示で開きます。内容を確認して構文を直してください。irori が壊れた情報を自動で置き換えることはありません。

`link` と `sources` の項目を選ぶ専用の画面はまだありません。`link` は文字で入力し、`sources` は **YAML で編集** から編集してください。本文の[リンク](links.md)や[コメント](comments.md)も利用できます。
