title: 同期フォルダ
description: Google Drive・Dropbox・Box・iCloud・OneDrive のアプリが同期するフォルダなど、このコンピューターのフォルダを vault の資料として使います。
---

## 仕組み

各サービスの公式アプリは、クラウドのフォルダをこのコンピューターに同期します。irori はその中のフォルダを vault の Contents に表示し、ノートとして編集し、vault agent に渡します。irori はクラウドに直接接続しません。同期はサービスのアプリが行います。同期アプリの外にある、このコンピューターのフォルダも同じ手順で接続できます。GitHub のリポジトリは[Git と共有](git.md#section-6)を参照してください。

## 準備

使うサービスのアプリを入れて、ログインします。

| サービス     | アプリ                                                                            | 主な場所                                                                |
| ------------ | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Google Drive | [パソコン版 Google ドライブ](https://www.google.com/drive/download/)              | Mac: `~/Library/CloudStorage/GoogleDrive-…`、Windows: `G:\マイドライブ` |
| Dropbox      | [Dropbox](https://www.dropbox.com/install)                                        | `~/Dropbox`                                                             |
| Box          | [Box Drive](https://www.box.com/resources/downloads)                              | `~/Box`                                                                 |
| iCloud Drive | Mac 標準・[Windows 用 iCloud](https://support.apple.com/ja-jp/103232)             | Finder の iCloud Drive                                                  |
| OneDrive     | Windows 標準・[Mac 版](https://www.microsoft.com/microsoft-365/onedrive/download) | `~/OneDrive`                                                            |

使うフォルダは、ファイルをこのコンピューターにも保存しておく設定にします（Google ドライブの **ミラーリング**、各サービスのオフライン設定など）。クラウドにだけあるファイルは、ダウンロードされるまで読めないことがあります。

## フォルダを接続する

1. vault の **接続** を開きます。
2. **フォルダを選ぶ** から、同期フォルダの中のフォルダを選びます。
3. Contents に表示する名前を確認し、**登録して接続** を押します。**編集を許可** をオフにすると、読み取り専用で接続します。

フォルダは、その vault を含むワークスペースを開くと自動で接続し、irori を終了するか、その vault を含むワークスペースのタブやウィンドウがすべて閉じると Contents から外れます。元のフォルダとファイルはそのまま残ります。別のコンピューターでは、**フォルダを選び直す** でそのコンピューターの同じフォルダを選びます。

フォルダがまだないとき（irori のあとにパソコン版 Google ドライブが起動したときなど）は、接続が **フォルダを待っています** と表示され、フォルダが現れると自動で接続します。

## 注意

- 一つのフォルダを複数の同期サービスで同時に同期しないでください。競合やデータの破損の原因になります。
- vault 自体や、vault を含むフォルダは接続できません。
- irori で削除したファイルは、システムのごみ箱に移ります。ごみ箱がない場所（Windows のパソコン版 Google ドライブのドライブ、ネットワーク上のフォルダなど）では、確認のうえ完全に削除します。同期アプリは、その削除をクラウドと共有相手にも反映します。クラウド側の履歴やごみ箱は各サービスの機能です。
- 編集を許可した接続には、エージェントも書き込めます。書き込んだ内容は同期アプリがクラウドに同期します。読み取り専用の接続でも、フルアクセスのエージェント・シェルコマンド・ターミナル・ほかの CLI からは書き込めます。
- エージェントが読んだファイルは、使う CLI の AI プロバイダーに送られます。[AI エージェント](agents.md)を確認してください。
- 会社のアカウントでは、管理者が同期アプリを制限している場合があります。

Google アカウントで直接つなぐ接続は終了しました。以前の接続の扱いは [Google Drive](drive.md) を参照してください。

## 未登録のデータ

Contents のフォルダの中で、どの接続にも当たらないものは、エクスプローラーで **未登録** と表示されます。別のコンピューターで接続の登録を解除したときや、Git の Pull で vault の接続の記録が置き換わったときなどに起こります。vault の **接続** を開くと、これらが **未登録** の下に並びます。

- リンクは、もう一度登録できます。**接続として登録** でリンク先のフォルダに接続します。リンク先がないとき（**リンク先なし**）は、**フォルダを選んで接続** で選んだフォルダに接続します。**リンクを削除** はリンクだけを削除し、リンク先のフォルダは残します。
- それ以外のものは、**ゴミ箱に移動** でシステムのごみ箱に移せます。

その vault でエージェントが実行中のあいだも、接続の追加や再接続、フォルダやクローンの選び直し、接続していないものの名前やアクセスの変更、登録の解除はできます。実行中のエージェントが使っているかもしれない接続中のフォルダの解除とアクセスの変更、リポジトリの **最新にする**、未登録データの削除は、実行が終わるまでできません。接続の画面にその理由が表示されます。
