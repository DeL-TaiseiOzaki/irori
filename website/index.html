FAQ

Good to know.

Is irori a web app?

No, it's a desktop app for Windows and Mac.

Do I need an AI account?

Only for agents. irori uses the CLI you already signed in to; it has no account or API key of its own.

Where are my notes?

In your folder, as plain Markdown.

Which computers?

Windows 11 (x64) and Apple silicon Macs. On Linux, run from source.
