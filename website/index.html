The hibachi

One folder. Three layers.
An agent that knows its place.

A hibachi is a knowledge base: an ordinary folder of Markdown you open in irori. Its agent starts inside it, with the hibachi's own instructions already loaded.

Schema

How the work is done

Instructions, skills and rules for AI — AGENTS.md, .agents/skills and friends.

Knowledge

What you know

Your notes, linked to each other, with properties, backlinks and an ontology you can see.

Contents

What you work from

Materials and outputs: PDFs, slides, spreadsheets — or a connected Google Drive folder.

irori mode

One agent across every hibachi.

Combine personal, team and organization hibachis into a workspace and see them on a map. Ask the irori agent for work that spans them: it splits the request, hands each part to that hibachi's own agent, and reports back.

  • Several hibachi agents can run at once
  • Search runs across every hibachi
  • Queue instructions while an agent works; conversations survive a restart

Notes

Write it down. Watch it connect.

A what-you-see Markdown editor that saves as you type. Follow links, see what links back, and edit a page's properties above its body. CSV opens as a table and an ontology as a hierarchy or a graph.

  • Renaming or moving a note rewrites the links to it
  • Today's note opens from your template, where you want it
  • Pasted images land in _assets/ next to the note

Records

Every change, on the record.

Whether you or an agent made it, every edit is a Git diff you can read before you commit. Clone from GitHub, or start empty and publish to GitHub when you're ready.

  • Diffs, commits and history in the Changes tab
  • irori never force-overwrites and never stashes on its own
  • A built-in terminal opens in the hibachi's folder

This is a testing preview.

The installers are not signed for distribution yet, and acceptance on real Windows 11 and macOS devices is still in progress. Start with a new folder or a copy of your notes.

First launch on Windows

Windows may warn that the publisher cannot be verified. If SmartScreen stops the installer, choose More info, then Run anyway.

First launch on Mac

macOS blocks the first launch. Open System Settings → Privacy & Security, find the message about irori and press Open Anyway. After that, irori opens as usual.

Get started

Up and running in four steps.

  1. Prepare

    Install Git. To use AI, also install and sign in to the CLI you want. Writing notes needs no CLI.

  2. Add a hibachi

    Open a KB folder, Clone from GitHub, or Create new. Existing files stay where they are.

  3. Make a workspace

    Tick the hibachis you want and press Create workspace.

  4. Write, then ask

    Open a note, write, and press AI to hand the next step to an agent.

Starting from scratch? irori-templete is the recommended layout for a hibachi.

FAQ

Good to know.

Is irori a web app?

No. irori is a desktop app you install on your computer. This page introduces it and links to the installers.

What do I need to use AI?

Install the CLI you want — Claude Code, Codex, OpenCode, Pi or Hermes Agent — and sign in to it as usual. irori uses that CLI's own sign-in and settings, so it needs no account or API key of its own. Each service's terms and pricing apply. You can try notes without setting up any AI.

Where are my notes stored?

In the folder you chose, as ordinary Markdown files. When you ask an agent for work, what it needs may be sent to the AI service behind that CLI.

What can the agents do?

A hibachi agent starts in full access where its CLI offers it; switch to standard (the CLI's own settings, asking when needed) at any time. When an agent asks for permission, the request appears in the panel. Every change it makes shows up as a Git diff.

How do I connect Google Drive?

Connect a Drive folder as a hibachi's Contents, from the hibachi's cloud connection. Your browser asks you to approve access with Google. On Windows, opening the folder needs WinFsp; a Mac needs nothing extra.

Which computers are supported?

Windows 11 on x64 (Intel or AMD) and Macs with Apple silicon (M series). Windows on ARM and Intel Macs are not supported. On Linux, you can run irori from source.

Something went wrong. Where do I report it?

Open a GitHub issue with the version shown in the app, your OS and the exact message. Please don't post note contents, credentials or sign-in URLs.
