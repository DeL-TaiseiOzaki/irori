ノートを書く時間と、何かをつくる時間。
その間を、irori がつなぎます。

01 / WRITE

いつものノートが、出発点。

見たまま書けるエディタと、Markdown のソース編集。手元の KB フォルダを開いて、自分のファイルで作業できます。

02 / WORK WITH AI

相談から、実際の編集まで。

Claude Code・Codex が、選んだ作業場所で実際に動きます。ノートの整理や編集、ツールの実行を、AI パネルから依頼できます。

03 / STAY IN CONTROL

変更を、確かめながら進める。

エージェントの実行状況や確認依頼をパネルに表示。編集中のノートと外部の変更が競合したときは、両方を確認できます。

GOOD TO KNOW

はじめる前に。

ブラウザで使うアプリですか？

irori はパソコンにインストールして使うデスクトップアプリです。このページは、アプリの紹介とダウンロードの入口です。

AI を使うには何が必要ですか？

現在の開発版では、Claude Code または Codex のインストールと、それぞれのアカウントでのログインが必要です。配布版に向けて、初回設定をアプリから案内できるようにする予定です。

ノートはどこに保存されますか？

選んだ KB フォルダに、Markdown ファイルとして保存されます。エージェントへの依頼では、処理に必要な内容が利用する AI サービスに送信されることがあります。

すべての機能が使えますか？

現在は開発プレビューです。ノート編集とローカルエージェントの実行が最初の実装です。クラウド連携や成果物の履歴管理などは、今後の実装対象です。
