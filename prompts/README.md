# Prompts

Everything irori says to a CLI agent (Claude Code, Codex, OpenCode, Pi,
Hermes Agent) lives here, one file per situation. Code that gives an agent
words imports them from `prompts/` (`import { … } from '../../prompts'`) and
does not write its own. A new situation gets a file here and a row below.

What stays out: error messages that report a failure (a missing file, a bad
argument) stay with the code that raises them. So do the files and wire
formats irori writes for a CLI (a sub-agent definition's YAML or TOML
wrapping, hook scripts). The words inside those formats come from here.

Every prompt is English. Each file's header says when it is sent and through
which channel.

## The request

irori builds one request text per instruction. Its parts come in this
order; a part is left out when it does not apply.

| #   | Part                              | File                                                                                                                                  | Who gets it  | When                                                                                                                                                                                                                                                                                                                                                           |
| --- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0   | Shared Schema                     | [shared-schema.ts](shared-schema.ts) `sharedSchema` / `sharedSchemaPointer`                                                           | every agent  | The irori agent is set up and its shared Schema has instructions or skills (ADR 027). Whole on a native session's first request and after a change, otherwise one line. It goes before a skill's wrapping too.                                                                                                                                                 |
| 1   | Handed vaults                     | [irori-agent.ts](irori-agent.ts) `brainsPreamble` / `brainsCommandPreamble`                                                           | irori agent  | The person hands it vaults. The first form is for CLIs with file-defined sub-agents, the second for Pi and Hermes Agent (`irori call`). Each vault's line names its knowledge and contents folders, connected folders and comment count.                                                                                                                       |
| 2   | The vault and the `irori` command | [vault-intro.ts](vault-intro.ts) `vaultIntro` / `vaultIntroPointer`, with [irori-command.ts](irori-command.ts) `vaultCommandPreamble` | vault agent  | Every request (ADR 039): what irori is, that AGENTS.md says where the rest of the Schema is, the Knowledge and Contents folders, the connected folders ([connected-folders.ts](connected-folders.ts) `connectedFolders`) and, when the run has it, the command's essentials. Whole on a native session's first request and after a change, otherwise one line. |
| 2   | The `irori` command               | [irori-command.ts](irori-command.ts) `iroriCommandPreamble` / `iroriCommandPointer`                                                   | irori agent  | Every request that has the command. Whole on a native session's first request, otherwise one line (ADR 039).                                                                                                                                                                                                                                                   |
| 3   | Connected folders                 | [connected-folders.ts](connected-folders.ts) `handedConnectedFolders`                                                                 | irori agent  | A handed vault has folders connected in contents: how to search inside them, said once within part 1.                                                                                                                                                                                                                                                          |
| 3   | Work folder                       | [work-folder.ts](work-folder.ts) `workFolder` / `handedWorkFolders`                                                                   | either agent | Always: where the vault's agents keep scratch files, `.irori/work` in the vault unless the person chose another folder. In the vault agent's introduction; for the irori agent, each handed vault's line names it and `handedWorkFolders` follows once.                                                                                                        |
| 4   | Selected note                     | [note.ts](note.ts) `selectedNote`                                                                                                     | vault agent  | The instruction goes with the open note.                                                                                                                                                                                                                                                                                                                       |

| 6   | Comments                          | [comments.ts](comments.ts) `commentsSummary` / `commentsPointer`                                                                      | vault agent  | The note has comments (summary). Otherwise, if the vault has comments at all, a pointer to them.                                                                                                                                                                                                                                                               |
| 7   | Selected sources                  | [sources.ts](sources.ts) `selectedSources`                                                                                            | vault agent  | The instruction names source observations.                                                                                                                                                                                                                                                                                                                     |
| 8   | Routine step                      | [routine-step.ts](routine-step.ts) `stepPreamble`                                                                                     | either agent | The run is an agent step of a routine.                                                                                                                                                                                                                                                                                                                         |
| 9   | Attached files                    | [attachments.ts](attachments.ts) `attachedFiles`                                                                                      | either agent | The person attached files. Each is named by its absolute path in irori's data directory; images also go to Claude Code, Codex, OpenCode and Pi as pictures.                                                                                                                                                                                                    |
| 10  | The person's words                | —                                                                                                                                     | either agent | Always, and always last.                                                                                                                                                                                                                                                                                                                                       |
| —   | Skill                             | [skill.ts](skill.ts) `promptWithSkill`                                                                                                | either agent | The person picks a skill, its own Schema's or a shared one. It wraps parts 1–10.                                                                                                                                                                                                                                                                               |

A hand-off from the irori agent through `irori call` starts a
vault agent run. That run's words are
[vault-agent.ts](vault-agent.ts) `handedTask`, and they go through the
same assembly.

## Files irori writes for an agent

| File                                                              | What                                                                | When                                                                                                                                        |
| ----------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| [vault-agent.ts](vault-agent.ts) `subAgentPrompt`                 | The description and instructions of a vault's sub-agent definition  | A request hands the vault to the irori agent on Claude Code, Codex or OpenCode and no definition exists. The person may edit it afterwards. |
| [irori-agent-starter.ts](irori-agent-starter.ts) `yourAiStarter`  | The irori agent's own `AGENTS.md`                                   | The person creates the irori agent's folder.                                                                                                |
| [irori-agent-skills.ts](irori-agent-skills.ts) `iroriAgentSkills` | The irori agent's standard skills, `.agents/skills/<name>/SKILL.md` | The person creates the irori agent's folder, or adds the missing ones on its screen. A present skill folder is never replaced.              |
